# R175：公开影像空间核验

核查日期：2026-09-14。范围是现有 KMaps、高德检索入口和 2012 年选文／2024 年转载等公开空间材料；不新增人物档案、现行政策或学院内部平面。

## 完成

1. 在 `16_地图建筑与功能空间/08_照片全景与视频导览/README.md` 增加影像、地图和历史文字的证据矩阵。
2. 统一影像卡字段：拍摄／反映时期、发布主体、方向、可见对象、原始标题、定位依据、版权限制和未知项。
3. 规定“对象可见—名称可追溯—时期相容”三项检查；未满足时只作影像线索。
4. 将地图点位、历史建筑名称、影像可见物和当前功能分开，避免生成未经核验的现行导览图。

## 结论

公开影像适合建立带时期的观察索引，不能单独证成建筑编号、现行用途、内部平面、开放规则或统一仪式。后续若取得学院或公共测绘机构的带日期总图，再把候选建筑卡升级为确定实体。

- 2012 年选文所述建筑与后续年份的名称、位置和功能是否相同。
