# R059｜《不忘》双语 PDF 文件核验

核查日期：2026-09-14。范围为索达吉堪布官网公开的《Always Remember》藏文与中文 PDF；本批只做文件级核验，不新增人物档案。

## 本批交付

1. 临时下载并核验藏文 PDF 166 页、中文 PDF 86 页、文件大小和 SHA-256。
2. 使用 Poppler `pdfinfo`、`pdftotext`，并渲染两份 PDF 首页做视觉抽查。
3. 将“可下载”“有文字层”“文本可可靠提取”三个状态分开登记；PDF 本体不入库。

## 结果

- 藏文 PDF：可打开，166 页；`pdftotext` 未得到可用文字层，需 OCR 或逐页视觉核验。
- 中文 PDF：可打开，86 页；提取触发 Adobe-GB1 映射和字体标签错误，输出乱码，不能用于段落级引用。
- 两份文件的页数、字节数和校验值已写入作品条目及 editions 登记。

## 证据边界

- 文件核验只证明核查日期的公开可取得性和容器元数据，不证明全文内容完整、版本互译或观点已校勘。
- 视觉封面抽查不代替逐页内容核对；不根据提取乱码做观点归纳。
- PDF 版权和再发布条件仍按官网页面与文件版权页核对，本批不重新发布文件。
