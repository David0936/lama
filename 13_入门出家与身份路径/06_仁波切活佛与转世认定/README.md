## 本专题的边界

仁波切、活佛、祖古等称谓涉及尊称、传承身份和转世认定等不同语境。本专题不把它们当作堪布／堪姆考试后的下一等级，也不据一个人的称号反推其具体学习经历。

后续每个条目分别记录：原称谓和藏文、使用传统、由谁认定或如何叙述、认定时点、与寺院或学院的关系、公开来源及争议。宗教传统中的认定叙述、历史文件和现代行政制度分栏呈现。

当前没有在本批建立任何具体转世认定的结论。称谓比较、法王如意宝相关传记和喇荣人物关系继续依各自来源核查。
