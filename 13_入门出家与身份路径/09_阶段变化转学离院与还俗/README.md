## R170：学习后路径的证据边界

本页记录路径类型，不制作“毕业后必然去哪”的流程图，也不替代人物传记：

| 路径类型 | 公开资料可支持的登记方向 | 当前不能确认 |
| --- | --- | --- |
| 继续同一项目学习 | 研究时期课程、考试、论文和委员会关系 | 全院统一年限、晋级条件或今天仍有效的项目规则 |
| 教学助理／任教 | 研究材料中的教学助理课程与授课分工 | 任教资格、聘任程序、薪酬、任期或现行名册 |
| 闭关／专修 | 公开课程将修习与课程框架并列；个别作品或页面可能提示传承条件 | 闭关地点、时间、许可、指导者和完成标准 |
| 转往其他寺院或继续深造 | 个人传记或研究访谈可作为单独个案 | 任何学习者都有同样转院路径、机构互认或学分制度 |
| 回乡教学／社会服务 | 个案或机构项目若明确记载，可登记为后续去向 | 普遍的毕业分配、服务年限或学院派遣制度 |
| 离院、还俗或改变身份 | 只有当事人或可靠传记明确说明时才记录 | 从离校、返乡或停止公开活动推断还俗或身份变化 |

Liang 与 Taylor 的研究可用于理解 2017—2019 年项目中的教学助理、考试和委员会；它不提供 2026 年全院的就业、闭关、转院、还俗或学籍规则。真实人物路径另见[人物案例目录](../10_真实人物路径案例/README.md)，本页不复制人物细节。

来源：[Liang & Taylor, *Tilling the Fields of Merit*](https://blogs.dickinson.edu/buddhistethics/files/2020/08/Liang-and-Taylor__20_F-1.pdf)，PDF 印刷页 237—250。
