# 13_入门出家与身份路径

状态：v0.4。第02、04—06项已有公开资料入口与身份边界；其余仍为研究框架，不代表已核实本院现行制度。

- [01_藏汉在家者的不同入口](01_藏汉在家者的不同入口/README.md)：分别研究藏语背景与汉语背景、已有师承与无师承、男性与女性、在家与已出家者的入口；语言和既有训练是独立维度，不从民族自动推断修学资格。
- [02_皈依受戒出家入学与常住](02_皈依受戒出家入学与常住/README.md)：早期僧团准入研究记录与现行制度缺口；皈依、受戒、剃度、学习和常住逐项核查。
- [03_寻找师长与学习关系](03_寻找师长与学习关系/README.md)：了解如何建立师生关系、教学指导与传法关系怎样区分、推荐与引介是否适用；避免把所有授课老师都写成同一种师承。
- [04_僧尼与在家身份](04_僧尼与在家身份/README.md)：按来源解释僧尼、在家持戒者与学习者的不同维度；不假定所有受戒类别均能在本院取得。
- [05_堪布堪姆与教学资格](05_堪布堪姆与教学资格/README.md)：研究学习要求、考核、授予者、授予时间、教学职责和不同机构的称谓用法；不编造固定学制或保证毕业即获称号。
- [06_仁波切活佛与转世认定](06_仁波切活佛与转世认定/README.md)：区分尊称使用、转世身份叙述、认定程序、传承内地位及适用的行政制度；各自依来源记录，不作为考试后的升阶。
- [07_上师喇嘛格西住持与其他称谓](07_上师喇嘛格西住持与其他称谓/README.md)：逐词解释所属传统、语境、资格或职责，标注本院适用性；不能把不同教派称谓直接换算为职级。
- [08_院长副院长与管理角色](08_院长副院长与管理角色/README.md)：说明教学资格、宗教尊称和行政职务如何交叉；具体任职事实链接机构目录的唯一主档。
- [09_阶段变化转学离院与还俗](09_阶段变化转学离院与还俗/README.md)：研究继续深造、闭关、转往他寺、回乡教学、离院与还俗等不同路径，记载来源所述流程及时代差异。
- [10_真实人物路径案例](10_真实人物路径案例/README.md)：选有可追溯传记的人物，以时间线展示入门、受戒、学习、任教等经历；个案不当普遍招生规则。
