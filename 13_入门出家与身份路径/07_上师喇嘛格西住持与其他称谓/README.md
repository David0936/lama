## R184｜称谓、教学学位与行政角色分栏

公开教育资料显示，同一个藏文称谓可能有不同传统和制度语境，不能直接翻译成现代职位或“等级”。Study Buddhism 的词汇页把 **མཁན་པོ། mkhan-po（堪布）** 分为两种常见用法：藏传佛教寺院的住持，以及噶举、宁玛传统中完成僧院教育体系的僧人称号。其专题文章又把格西与堪布放在学术训练／学位语境，并提醒这类称号本身不能保证教学能力或精神导师资格。

FPMT 的公开术语页则把以下词条并列说明：`lama` 可作高阶精神教师或部分传统中的尊称；`rinpoche` 通常与转世认定有关，也可能在特定语境中作为对具卓越品质教师的尊称；`khenpo` 在宁玛、萨迦、噶举语境中可与格西学位相比较，在格鲁寺院语境中又可指住持；`khensur` 指卸任住持，`khenrinpoche` 是对现任住持的尊称。

这些是跨传统公开教育材料的**术语入口**，不是喇荣学院的现任职务表、学位认证或个人身份判定。喇荣条目必须另用机构公告、课程／考核记录或当事人可靠传记确认适用时期和具体用法。

| 维度 | 公开材料可支持的最小表述 | 本库不作的推断 |
|---|---|---|
| 教学／学术称号 | 格西、堪布在不同传统可与系统学习和考核相关 | 统一学制、年限、证书或自动任教 |
| 行政职务 | 堪布在部分资料中也指住持；住持是机构职务语境 | 所有堪布都在任住持，或住持必有同一学位 |
| 精神导师称谓 | 上师／喇嘛的含义依传统、师承和使用场景变化 | 任何被称为喇嘛者都具同等传法资格 |
| 转世／尊称 | 仁波切可与转世认定或尊称语境相关 | 仁波切是堪布之后的更高等级，或可由考试取得 |
| 任期状态 | `khensur`／`khenrinpoche`在FPMT材料中用于区分卸任与现任住持 | 将该术语直接套用于喇荣现行组织 |
