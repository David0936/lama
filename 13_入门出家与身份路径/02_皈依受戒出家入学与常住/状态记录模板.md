# 学习与身份状态记录模板

用于记录公开资料中的个人或制度路径；不把下列状态解释成线性晋升阶梯。

| 状态 | 必须回答的问题 |
|---|---|
| 普通参访 | 谁发布接待信息？日期、地点和对象范围是什么？ |
| 短期听课 | 课程时长、报名条件、旁听/公开范围是否明确？ |
| 长期学习 | 是否有学期、课程、考核或注册证据？ |
| 皈依/受戒 | 仪式由谁主持？戒别、时间和文本依据是什么？ |
| 出家 | 剃度、僧籍、常住和学习是否分别记录？ |
| 常住 | 住宿、管理和退出条件是否有公开制度来源？ |
| 离院/还俗 | 仅记录来源明确的个案或制度说明，不推导普遍流程。 |

每条记录还应标注：资料类型、适用时期、适用机构、来源定位、当前性和未核问题。缺少现行规则时写“公开资料未核实”，不以历史材料代替今天的招生或常住制度。
