## 公开资料中的堪布与堪姆

学院相关公开讲座将 Khenpo／Khenmo 描述为教授佛法的称号，并将其类比为大学教师或教授；同一讲座提到，堪姆资格涉及口试、笔试和背诵考试，内容主要是佛法及部分世间知识。该说明可用于理解“教学资格”这一维度，但不能据此写出喇荣学院今天固定不变的考试大纲或学制。

2015 年公开讲座还记录，法王如意宝在 1988 年为包括门措在内的六位女修行者授予堪姆称号，1992 年又有第二批堪姆。这是具体历史记录，不等于所有女性学习者都会取得堪姆资格。

## R194｜学习资格、教学资格与行政职务分层

不同来源显示，“堪布”至少有两种常见语境：部分传统把它作为完成僧院教育体系后的学术／教学称号，部分语境则指寺院住持。Study Buddhism 还提醒，格西或堪布的学术资格本身不保证教学能力、品格或禅修成就。FPMT 的术语页则把堪布描述为宁玛、萨迦、噶举传统中与格西相当的教育称号，但给出的年限只是机构传统概述。

一个具体学院案例可展示“资格授予不是单一考试”：Minling 公开学院页写明，教授职位需先担任 `Chorpoen`，并获得学生投票和行政决定；其堪布／住持标准还列出九年经论学习、至少三年教学经验、比丘戒和纪律等条件。该页是单一宁玛学院的制度案例，不能改写成喇荣或所有学院的统一规则。

| 维度 | 例子 | 不能自动转换 |
| --- | --- | --- |
| 学术训练 | 格西／堪布教育体系毕业 | 立刻拥有所有场合的授课资格 |
| 教学任命 | 课程、试教、投票或行政任命 | 学术称号自动等于教职 |
| 住持职务 | `Khenpo`、`Khen Rinpoche` 在部分语境指住持 | 住持职务自动等于格西或堪布学位 |
| 尊称／转世 | 仁波切、喇嘛等另按传统与认定记录 | 与学术训练或行政职位排成一条晋升阶梯 |
