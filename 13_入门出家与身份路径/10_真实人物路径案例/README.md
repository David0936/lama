## 案例一：索达吉堪布（公开传记叙述）

官方传记记载：他童年放牧并学习祈祷、咒语和经文；后来进入师范学校。在师范学习的最后一年，他因希望成为僧人而放弃教师道路，跟随堪布德巴受戒；之后在道明寺学习和修行一年。1985 年，堪布德巴安排他到喇荣五明佛学院，在法王如意宝指导下继续学习，随后取得堪布学位。

这是一条有明确叙述来源的个人经历链：世俗教育 → 由师长引介受戒 → 寺院学习 → 进入喇荣深造 → 学术资格。它不能证明所有人都必须先在道明寺受戒，也不能证明今天仍采用相同安排。

来源：[索达吉堪布官方传记](https://www.khenposodargye.org/about/biography/) · [道明寺官方介绍](https://www.khenposodargye.org/about/domang-monastery/)
