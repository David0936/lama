# 01_藏汉在家者的不同入口

分别研究藏语背景与汉语背景、已有师承与无师承、男性与女性、在家与已出家者的入口；语言和既有训练是独立维度，不从民族自动推断修学资格。

## R079 公开资料能确认的入口层级（2026-09-14）

| 入口 | 公开资料能支持 | 当前不能确认 |
| --- | --- | --- |
| 普通参访／朝圣 | 公开公告曾强调学院和天葬台具有宗教、教育性质，不应按普通旅游景点理解 | 当日开放时间、预约方式、可进入区域 |
| 短期听课／线上学习 | 官网有公开课程、讲解和数字出版入口 | 线下旁听资格、注册手续、是否计入长期学籍 |
