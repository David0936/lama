# 03_寻找师长与学习关系

了解如何建立师生关系、教学指导与传法关系怎样区分、推荐与引介是否适用；避免把所有授课老师都写成同一种师承。

## R162 学习关系的层级

公开资料支持几种不同强度的关系入口，但它们不能互相替代：

| 层级 | 公开资料可确认 | 不能据此推出 |
|---|---|---|
| 公开讲座／线上课程 | 课程公告、讲解页面和公开媒体显示某位教师面向不特定学习者讲授 | 已建立个人师徒关系、获得口传或拥有学院学籍 |
| 长期学习指导 | 研究材料可记录特定项目中的教师、学生、课程和委员会关系 | 任何外来者都能按同一方式申请、由同一老师收徒 |
| 历史引介／作保 | 早期研究记录过既有成员为新加入者品行作保的叙述 | 2026年仍有介绍人制度、保证录取或连带惩处 |
| 传法／灌顶许可 | 个别公开书目页会注明需合格教师许可或特定灌顶条件 | 可以从书目页推导具体仪轨、寻找老师的方法或资格认证 |
| 行政与常住确认 | 当前需要带日期的机构公告、住宿或任命文件 | 授课、尊称、受戒和行政职务自动相等 |

本页把“能听课”“有人指导”“成为弟子”“获得传法许可”“获准常住”作为不同字段。没有明确主体、日期、适用对象和原文定位时，只登记为线索或缺口；不替读者设计拜师、求灌顶或绕过机构审核的操作路径。
