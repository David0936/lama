# 每批发布检查清单

- [ ] 本批正文条目、审校单和登记文件齐全。
- [ ] JSONL 可解析，ID 唯一，所有对象/来源引用存在。
- [ ] Markdown 相对链接存在；外部 URL 可访问或已记录失败状态。
- [ ] `git diff --check` 通过，未混入人物或其他并行任务文件。
- [ ] PDF 记录页数、大小、SHA-256 和文本抽样状态；音视频记录平台、时间码和语言。
- [ ] “现任”“正式合作”“全文已取得”“人体材料”等高风险表述已人工复核。
- [ ] 未解决问题、冲突和访问限制已写入正文或审校单。
- [ ] 提交后复核 commit、远端 `main` 和工作树状态。

清单是发布门槛，不代表条目内容已经全部达到 `metadata_checked`；`review_required` 仍需人工审校。
