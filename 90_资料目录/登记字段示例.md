# JSONL 登记字段示例

以下是最小可复核结构；实际条目可增加字段，但不能省略对象 ID、来源定位和审校状态。

```json
{"id":"W-example","type":"work","title_zh":"作品名","path":"04_经典与文献/作品名/README.md","status":"review_required"}
{"id":"S-example","title":"来源标题","url":"https://example.org","accessed_at":"2026-09-15","source_type":"official_page","access_status":"public"}
{"id":"E-example","work_id":"W-example","language":"zh-Hans","source_id":"S-example","status":"metadata_checked"}
{"id":"Q-example","subject_id":"E-example","statement":"可核验主张","evidence":[{"source_id":"S-example","locator":"章节或页码"}],"review_status":"metadata_checked"}
{"id":"X-example","subject_id":"W-example","predicate":"has_public_edition","object_id":"E-example","evidence":[{"source_id":"S-example","locator":"版本定位"}],"review_status":"review_required"}
```

提交前检查：ID 唯一；`subject_id`、`object_id`、`work_id`、`edition_id` 和 `source_id` 均能在目录中找到；网页、PDF、音视频和馆藏定位分别使用章节、页码、时间码或馆藏号。
