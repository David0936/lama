## R366｜机构主档的三层事实结构

| 层次 | 示例 | 处理方式 |
|---|---|---|
| 公开定位 | 机构名称、地点、创建叙述、学习／居住功能 | 保留来源原词和访问日期 |
| 历史研究 | 某时期的组织、课程、作息、建筑或群体观察 | 标明时期、作者和证据类型，不改写成今天 |
| 当前制度 | 招生、常住、职务、课程表、访问规则 | 只接受带日期且主体明确的公告或制度文件 |

公开定位能建立检索入口，不能自动证明现行组织；历史研究能解释变化，不能替代当前公告；找不到当前制度来源时，统一标记“公开资料未核实”。

## R391｜机构主档的标准字段

每个机构主档至少保留：规范名称、原文名称、别名与异译、机构类型、地理位置、成立／变更时间精度、功能描述、关联传统、关联人物或作品 ID、来源主体、来源日期、证据层级、当前状态和未解决问题。名称相同的寺院、学院、聚落或项目先消歧，再建立关系。

“关联传统”表示来源明确的历史或教育语境，不自动表示行政隶属；“关联人物”只建立可定位的任职、讲学、访问或传承关系；“当前状态”没有带日期机构来源时保持未知。跨机构比较使用相同字段，避免把某一学院的组织模式外推到其他学院。
