# 色达喇荣五明佛学院

待研究机构主档。职务与具体人物分开，尊称和行政称谓分开记录。

## 公开资料基础卡

学院官网英文介绍称，喇荣五明佛学院于 1980 年由法王如意宝创建，位于四川省甘孜州色达县喇荣沟，包含学习、修行与居住功能，并有藏族、汉族的僧尼和在家修学者。官网还以高原山谷和红色居所描述其空间形态。

这段只作为公开来源的起始摘要。学院的历史阶段、现行组织、建筑功能区、学习与出家入口，以及副院长等职务，必须分别按时间和来源核查。
