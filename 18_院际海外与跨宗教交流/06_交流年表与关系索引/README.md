## R159 关系索引补充

同一时期出现的海外讲座、线上课程和翻译项目不能合并成一条“学院国际合作”事件。当前关系索引按以下字段拆分：

1. **主体**：个人、喇荣公开课程、虚拟项目或独立翻译机构。
2. **活动**：讲座、课程、译介、讨论／禅修或正式协议。
3. **证据**：主办方页面、讲题页、课程公告、项目目录或双方机构公告。
4. **状态**：已登记、日期待核、机构关系待核、版本进度待核。

本批不把个人海外活动升级为学院正式合作，也不把WCDU的“virtual university”称谓改写成实体大学、出家教育或学历项目。
