# 02_海外访问与公开讲学

人物出访、邀请方、日期、主题和成果；个人行程与学院正式项目分别标记。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

## 首批公开讲学事件

### 2013：哥伦比亚大学相关讲座（人物活动）

索达吉堪布官方网站收录了其在哥伦比亚大学语境下谈论藏传佛教、喇荣学院和当代中国的讲座页面。当前证据支持“受邀讲学／人物活动”，不支持写成喇荣学院与哥伦比亚大学的正式合作项目。

### 2013：马希隆大学《Faith and Times》讲座（人物活动）

官方网站记录索达吉堪布在泰国马希隆大学的公开演讲，并介绍其个人经历。该条作为个人出访与公开讲学登记，邀请方和活动日期应以主办方档案进一步核对。

### 2019：面向海外学习者的《入菩萨行论》英语线上课程（公开课程）

既有课程公告显示喇荣教师以英语讲授《入菩萨行论》。它是可公开访问的教学项目线索，不等于与某所海外大学建立长期合作关系。
