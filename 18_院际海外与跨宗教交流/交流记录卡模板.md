# 院际与海外交流记录卡模板

| 字段 | 要求 |
|---|---|
| 事件名称与日期 | 保留原文题名、发生日期和时区/地点 |
| 参与主体 | 学院、寺院、大学、基金会、个人或媒体；逐一列出 |
| 活动性质 | 访问、讲学、课程、翻译、出版、法会、公益或对话 |
| 证据层级 | 机构公告、活动主办方页面、出版物、视频或个人叙述 |
| 机构关系 | 仅在双方正式文件或公告明确时写“合作”；否则写“个人参与/公开活动” |
| 成果与范围 | 讲题、译本、项目产出和公开对象，绑定来源定位 |
| 当前性 | 历史事件、单次活动、持续项目或待核 |
| 未解决问题 | 邀请方、授权、持续性、学院代表身份和后续成果 |

海外地点、英文页面或共同宗教主题本身不能证明学院正式合作，也不能把个人活动改写为机构关系。
