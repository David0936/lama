# 18_院际海外与跨宗教交流

状态：v0.6。已建立公开外语数字入口和交流主体分层，并补充关系强度与成果字段；其余条目仍待检索审校。

- [01_与其他佛学院寺院的交流](01_与其他佛学院寺院的交流/README.md)：以学院为中心，记录有据的访问、教学、学习、法会或资料交换；不从共同师承推断机构合作。
- [02_海外访问与公开讲学](02_海外访问与公开讲学/README.md)：人物出访、邀请方、日期、主题和成果；个人行程与学院正式项目分别标记。
- [03_大学学术与翻译合作](03_大学学术与翻译合作/README.md)：大学讲座、研究、翻译和出版活动；一次邀请不能称为长期合作伙伴。
- [04_海外学习群体与传播](04_海外学习群体与传播/README.md)：公开课程、译本与外语数字学习入口；语言不证明学习者所在地或学院隶属，正式合作另证。
- [05_跨宗教对话与公益往来](05_跨宗教对话与公益往来/README.md)：有出处的宗教间会面、对话及公益活动；其他机构案例只作背景，不移植为本院经历。
- [06_交流年表与关系索引](06_交流年表与关系索引/README.md)：各事件的时间、参与者、主体层级、活动性质、资料入口；历史事件不自动表示当前关系。

## R357｜交流关系的主体分层

| 记录层 | 最小证据 | 可以写 | 不能写 |
|---|---|---|---|
| 个人活动 | 主讲人、邀请方、日期、地点、公开记录 | 某人曾在某地讲学或访问 | 学院与该机构正式合作 |
| 公开课程／翻译 | 项目名称、出版方、语言、版本和页面 | 公开传播或翻译项目 | 学员取得院内身份或项目属于学院教务 |
| 学术研究 | 大学／研究机构、项目、出版物、档案号 | 研究或出版关系 | 传承关系、行政隶属或长期合作 |
| 机构合作 | 双方正式名称、公告、协议或共同项目页 | 在限定时期内的机构级合作 | 由共同教师、共同尊格或单次活动推导合作 |

交流条目必须注明主体层级、时间范围和来源定位；“海外”“国际”“合作”等高强度词只有在机构级证据明确出现时使用。

## R377｜交流事件的关系强度与成果字段

交流事件再记录：关系主体、活动性质、发起方、日期范围、地点或平台、参与者身份、共同产出、后续延续证据和终止／未知状态。单次讲座、个人访问、公开视频、译本出版、共同研究、签署协议分别建档；没有共同项目页、协议、双方公告或连续活动记录时，关系强度保持“单次公开活动”或“待核”。

成果字段只写已公开的书目、视频、会议记录、课程页或项目报告，不把合影、致辞、共同使用场地或共同尊格当作合作成果。
