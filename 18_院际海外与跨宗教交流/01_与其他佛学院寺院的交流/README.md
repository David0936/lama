# 01_与其他佛学院寺院的交流

以学院为中心，记录有据的访问、教学、学习、法会或资料交换；不从共同师承推断机构合作。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

## R177：跨机构思想交流的首个案例

目前找到的较明确案例不是“佛学院之间签署合作协议”，而是一次带日期的僧侣—学者对话。Khenpo Sodargye 与 Dan Smyer Yü 合著的 2017 年论文说明：双方在 2013 年 8 月于喇荣举行 Buddhism–Social Science Dialogue Session；作者还记录了在喇荣和中国、欧洲、北美大学之间进行讲座、访谈与思想交流的过程（PDF 印刷页 92—93）。

这条材料可以登记为**跨机构学术／思想交流事件**，但不能升级为学院与大学的长期联合项目：论文没有给出协议、联合学位、固定交换名额、正式合作办公室或持续课程清单。参与者的个人邀请、研究准入和公开讲座也要与学院整体关系分开。

| 关系层 | 可登记 | 不能直接推出 |
|---|---|---|
| 事件 | 2013 年 8 月喇荣对话活动、论文作者与场景 | 该活动代表全院长期对外交流制度 |
| 个人活动 | Khenpo Sodargye 与学者在不同机构讲学、访谈和讨论 | 喇荣与每所大学签署正式合作 |
| 传统开放叙述 | 2015 年公开讲座中转述创办者欢迎不同传统和宗教的学习者 | 今天的门禁、旁听、访问资格或机构合作 |

后续“与其他佛学院／寺院交流”应优先寻找双方机构同时发布的访问、课程、法会或出版记录；仅有共同师承、同一讲师、同一出版物或个人友谊时，保留为关联线索。
