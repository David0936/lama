# 03_大学学术与翻译合作

大学讲座、研究、翻译和出版活动；一次邀请不能称为长期合作伙伴。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

## 当前登记

现有公开材料主要是人物受邀讲座和公开翻译课程，尚未找到足以证明长期联合培养、共同研究或正式协议的机构级文件。后续应分别记录主办单位、讲题、时间、是否有录音/文字稿，以及学院是否作为机构主体出现。

## R067 翻译出版不等于机构合作

官网作品页提供《A Journey to the West》的藏、英、繁中版本和公开讲解入口，可登记为数字出版与翻译传播记录。该页面没有显示大学、出版社或学院之间的长期协议；本目录因此把它放在作品传播层，不写成大学联合项目。

## R159 海外交流主体层级矩阵

现有公开资料可以确认“公开讲学、线上课程、虚拟大学、翻译项目”四类活动，但它们的主体层级不同：

| 记录 | 公开主体 | 可以写什么 | 不能写什么 |
|---|---|---|---|
| 2013 哥伦比亚大学相关讲题 | 索达吉个人官网讲题页 | 个人海外公开讲学线索 | 喇荣学院与哥伦比亚大学正式合作 |
| 2013 马希隆大学 *Faith and Times* | 索达吉个人官网演讲页 | 个人受邀或公开演讲记录，日期待核 | 长期访问、联合培养或学院协议 |
| 2019《入菩萨行论》英语线上课程 | 喇荣教师／公开课程 | 面向海外学习者的远程课程 | 学籍、出家资格或大学学分 |
| 2016起 WCDU | 官方页面称虚拟大学 | 英语学习者的定期直播、讨论和引导式禅修入口 | 喇荣实体学院招生、常住、学位或资格授予 |
| MDTH翻译项目 | 独立翻译项目页面 | 晋美彭措文集的当代英译与传播进度 | 全部文集已完成、学院官方授权或正式联合项目 |

因此，本目录将海外交流按“个人活动”“公开数字教学”“独立译介项目”“机构级合作”分层。只有出现双方机构的公告、协议、项目页面或共同出版物，才升级为机构级合作；共同师承、同一译者或讲座场地不能单独证明合作关系。
