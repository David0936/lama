# 02_藏传汉传与南传的关联

按历史传播、文本、语言、戒律与修学侧重做简明比较；共有经典与直接传承分别论证。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

## 比较原则

藏传、汉传和南传都属于佛教历史传统，但“共同根源”不等于每一部经论、戒律或仪轨都直接相同。比较时应分开记录：印度文本来源、译入语言、戒律传承、哲学解释、修行制度和近现代交流。公开资料支持藏传佛教与汉传佛教同属大乘佛教广泛谱系，也支持三者在历史传播路径和现行制度上存在差别；具体文本关系需逐部核对。

达赖喇嘛公开讲话把汉、日、韩、藏等佛教传统追溯到那烂陀传统，同时强调藏传内部各派有不同观点。这里作为跨传统背景，不作为喇荣学院的直接传承证明。
