# 藏传、汉传与印度佛教比较矩阵模板

用于后续写作时拆开“共同来源”“历史传播”和“现代交流”。本页不处理基督宗教比较。

| 维度 | 记录方法 | 证据要求 |
|---|---|---|
| 历史区域 | 标出时期、地点和传播路线 | 史料、碑铭、研究专著 |
| 语言与文本 | 区分梵文、巴利、藏文、汉文及译本 | 原典、目录、可追溯译本 |
| 戒律与制度 | 分别记录律藏传统、受戒制度和寺院组织 | 律典、寺院规章、历史研究 |
| 教义与修学 | 按具体论典或传承描述，不用单一标签 | 论典章节、传承自述、学术研究 |
| 传承关系 | 区分直接传承、文本共享、思想影响和相似主题 | 师承谱系、译经史、引文或研究结论 |
| 当代交流 | 记录大学、寺院、出版和公开活动 | 双方机构公告或活动原页 |

“同一佛经”“相似术语”或“共同尊格”只能提出比较线索，不能单独证明直接传承、同源或机构合作。
