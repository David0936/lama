# 05_基督宗教与佛教的异同和接触

基督宗教下按必要范围区分天主教、新教、东正教；分开教义比较、历史接触和当代对话，不以相似性证明同源。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

## 有限比较

| 主题 | 佛教资料可概括的方向 | 基督宗教资料可概括的方向 | 写作边界 |
| --- | --- | --- | --- |
| 终极关怀 | 不同佛教传统以解脱、觉悟和离苦等概念组织修行 | 基督宗教以与上帝的关系、救赎和基督信仰组织教义 | 不能把“解脱”和“救赎”当作同义词 |
| 修行实践 | 戒律、禅修、诵经、布施等依传统而异 | 祈祷、礼拜、圣礼、慈善等依宗派而异 | 只比较公开文本明确涉及的实践 |
| 对话方式 | 以不同传统的自述和参与者记录为准 | 以教会文件、对话声明和参与者记录为准 | 对话不等于教义融合或共同起源 |

梵蒂冈《我们的时代》承认佛教内部多种形式的解脱与觉悟追求，并倡导谨慎、相互尊重的对话与合作；2024、2025 年宗教对话文告继续以和平、和解和共同责任为主题。这些是天主教方面的自我表述，不能代表所有基督宗派，也不能移植为喇荣学院的正式立场。

目前未找到喇荣学院与基督教机构的公开机构级合作证据；相关内容仅作为外部背景。
