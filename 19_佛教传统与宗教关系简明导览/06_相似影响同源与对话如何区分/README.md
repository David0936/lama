# 06_相似影响同源与对话如何区分

给外人一张关系说明表：共同源流、文本传承、历史影响、机构合作、当代对话、主题相似；各自需要不同证据。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

## 证据层级表

| 问题 | 需要的证据 | 目前写法 |
| --- | --- | --- |
| 共同源流 | 早期文本、译史、谱系研究 | 可写“共享印度佛教根基”，不可直接写成同一教派 |
| 文本传承 | 原文、译本、目录和版本关系 | 逐部建立版本链，不凭书名相似判断 |
| 历史影响 | 有日期的传播、译经或制度记录 | 说明路径与时期，避免跨世纪跳跃 |
| 机构合作 | 双方正式公告、协议或项目档案 | 人物受邀讲座只记为个人活动 |
| 当代对话 | 双方公开发言、活动记录 | 只说明发生过对话，不推断教义融合 |
| 主题相似 | 概念和实践的并列比较 | 明确“相似”不等于“影响”或“同源” |
