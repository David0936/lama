# 06_相似影响同源与对话如何区分

给外人一张关系说明表：共同源流、文本传承、历史影响、机构合作、当代对话、主题相似；各自需要不同证据。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

## 证据层级表

| 问题 | 需要的证据 | 目前写法 |
| --- | --- | --- |
| 共同源流 | 早期文本、译史、谱系研究 | 可写“共享印度佛教根基”，不可直接写成同一教派 |
| 文本传承 | 原文、译本、目录和版本关系 | 逐部建立版本链，不凭书名相似判断 |
| 历史影响 | 有日期的传播、译经或制度记录 | 说明路径与时期，避免跨世纪跳跃 |
| 机构合作 | 双方正式公告、协议或项目档案 | 人物受邀讲座只记为个人活动 |
| 当代对话 | 双方公开发言、活动记录 | 只说明发生过对话，不推断教义融合 |
| 主题相似 | 概念和实践的并列比较 | 明确“相似”不等于“影响”或“同源” |

## R172：传统关系登记矩阵

面向外来读者，先给关系句加上类型，再决定要找哪类来源：

| 关系类型 | 可写的最小句式 | 需要的定位 | 不能自动升级为 |
| --- | --- | --- | --- |
| 共同源流 | “均可追溯到某段印度佛教文本／思想背景” | 译史、原典、谱系或考古研究 | 同一教派、同一戒律或同一寺院 |
| 文本传承 | “某藏／汉版本与某原文或异译存在可核关系” | 目录、版本、译者、页码与异文 | 现代机构之间的合作 |
| 历史影响 | “某时期人员、文本、艺术或制度出现传播路径” | 带日期的史料、题记、旅行记或研究 | 跨世纪连续继承 |
| 个人交流 | “某位教师／研究者在某地公开讲授或对话” | 活动页、讲稿、视频时间码 | 学院正式合作、全派立场或学籍关系 |
| 机构合作 | “两机构共同发布项目／协议／课程” | 双方机构公告或项目档案 | 只因同一人物参与就成立 |
| 主题相似 | “两个传统对某主题有可比较表达” | 双方原文或可靠译文 | 证明一方影响另一方 |

本项目当前优先处理藏传、汉传和印度佛教的历史与文本关系；缺少双方一手材料时，保持“比较入口”或“待核”，不写教义融合、正式传承或机构合作。
