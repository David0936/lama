- [02_藏传汉传与南传的关联](02_藏传汉传与南传的关联/README.md)：按历史传播、文本、语言、戒律与修学侧重做简明比较；共有经典与直接传承分别论证。

- [06_相似影响同源与对话如何区分](06_相似影响同源与对话如何区分/README.md)：在佛教内部比较中区分共同源流、文本传承、历史影响、机构合作和主题相似；各自需要不同证据。

范围说明：本百科当前不展开基督宗教比较；跨宗教内容如需恢复，另立专题并重新确认范围，不混入藏传、汉传与印度佛教主线。
