# 善财参访善知识与普贤行愿

## 故事入口（R247）

84000 的公开中文导读把《华严经·入法界品》（*The Stem Array*，Gaṇḍavyūha）介绍为善财为求真理而展开的参学旅程：他参访五十多位善知识，导师身份包含天神、儿童、妓女、医师和普通劳动者等。英文学术导读则将其概括为通过跨越时间、空间和社会身份的相遇，扩展对现实与智慧来源的理解。

叙事在公开导读中以普贤的发愿偈收束。这里登记的是“作品导读—故事关系”层：它可帮助读者理解善财、文殊、弥勒、普贤与善知识的关系线索，但不把每一位善知识的出现次序、身份和对话当作已经完成的汉藏逐段校勘。

## 边界

- “五十多位”与身份举例是公开导读层，不作为本库的经文逐段计数。
- 不把善财的参访旅程套成“普通人→堪布→仁波切”的统一晋升阶梯；两者属于不同资料问题。
