# 月光童子与佛陀入舍

## 故事入口（R254）

84000 对《三摩地王经》的导论称，月光童子（Candraprabha）是经中的主要问答者之一，并与另一部经中的叙事相互参照：他邀请佛陀到家中并为来访作准备。这里登记的是导论层的人物关系，不把月光童子当作可核的历史人物传记。
