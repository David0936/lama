# 普贤行愿与善财回向

## 故事入口（R255）

84000 将《普贤行愿品》作为独立的 Toh 1095 文本，并说明《入法界品》（Toh 44）第 45 章也包含同名 Prayer of Good Conduct。现有《入法界品》条目已登记善财参访善知识与普贤行愿；本页只建立两个文本入口的关系，不把它们压成同一版本。

## 关系表

| 节点 | 关系 | 证据层 |
| --- | --- | --- |
| 普贤菩萨／普贤行愿 | 作为 63 颂发愿文本的核心 | 84000 Toh 1095 导论 |
| 善财 | 与《入法界品》末章及普贤行愿入口相连 | 84000 Toh 44–45 目录／章末关系 |
| 七支供与回向 | 愿文的结构性修行语言 | 84000 Toh 1095 导论 |

## 边界

- Toh 1095 与 Toh 44 第 45 章是版本／文本关系入口，不能直接判定为完全相同的底本。
- “往生净土、净化业障、成佛”等功德语句属于经典内部宗教表述，不作可验证的现实承诺。
- 本批不写喇荣学院具体诵本、法会安排或音频出处。
