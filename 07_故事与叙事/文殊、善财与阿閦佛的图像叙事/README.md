# 文殊、善财与阿閦佛的图像叙事

## 对象入口

大都会艺术博物馆登记一件中国17—18世纪绢贴作品，题名 **Manjushri, the Bodhisattva of Transcendent Wisdom**，馆藏号 **15.95.154**。馆方说明文殊骑蓝狮，手持剑与经书；画面上方出现阿閦佛，左下方出现善财。馆方还指出，善财被置于接受文殊教导的理想信众位置。

对象页：[The Met 15.95.154](https://www.metmuseum.org/art/collection/search/58896)

## 如何阅读这条“故事”

这里的“文殊—善财—阿閦佛”首先是一条**馆方对象的图像关系**：剑与经书提示智慧属性，善财提示求法者／信众位置，阿閦佛是画面中的上方尊格。它可以作为后续查找《华严经》善财求法叙事、文殊相关经典和藏传图像学研究的线索，但不能把馆方展签直接当作经文原文，也不能据一幅绢贴断言所有传统都采用同一组合。

## 证据边界

- 年代、材料、题名和馆藏号来自 The Met 对象页。
- “理想信众接受文殊教导”是馆方图像学说明；经文出处、具体章节和藏传仪轨尚待补证。
- 阿閦佛在画面上方的出现是对象构图信息，不自动表示与文殊存在教义上的固定等级关系。
- 本条不把善财、文殊和阿閦佛写成学院法会或喇荣传承的现行故事。
