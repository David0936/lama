# 莲花生与八世纪入藏传统：馆方展签中的叙事版本

此条登记博物馆公开展签所采用的一种叙事版本，供阅读路线使用；它不是经过独立史料论证的唯一时间线。

## 叙事内容

大都会艺术博物馆在《The Spiritual Master Padmasambhava》（馆藏号 **2012.459**）展签中称，莲花生是来自印度的密教大师，据信应吐蕃王赤松德赞邀请于八世纪后期入藏，并在西藏传播密续佛教、参与桑耶寺建设，后来被尊称为 Guru Rinpoche。展签同时说明这是“believed to have”式的传统叙述，应与藏文传记、碑铭和其他学术研究分层。

来源：[The Met 对象目录](https://www.metmuseum.org/art/collection/search/78192)。

## 图像叙事与法器

展签把金刚杵（vajra）与嘎巴拉（kapāla）作为图像中的持物，并给出象征性解释。这里登记的是馆方对一件具体图像的描述，不推导所有莲花生像都必须具有同样持物，也不推断喇荣学院的实际仪轨。

史密森尼同馆藏对象 **S2014.18a-b** 则把八世纪入藏、伏藏和宁玛传统写入教育性展签。两件馆藏都属于现代机构的编目和解释，不能代替原始文献版本。

来源：[史密森尼 Padma Sambhava](https://asia.si.edu/explore-art-culture/collections/search/edanmdm%3Afsg_S2014.18a-b/)。

## 证据层级

- **馆藏事实**：馆藏号、年代、材料、尺寸、馆方题名。
- **展签叙事**：博物馆面向公众的传统背景说明。
- **待核史料**：藏文传记、桑耶相关碑铭、早期汉藏文献与现代学术研究。
