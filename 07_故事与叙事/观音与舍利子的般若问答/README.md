# 观音与舍利子的般若问答

## 故事入口（R250）

《心经》的核心叙事是观音菩萨向舍利子说明般若波罗蜜多。84000 的作品导论指出，观音作为对话者在般若文献中具有独特位置；该关系应登记为经典内部的问答结构，不改写成历史人物会谈记录。
