# 金刚藏宣说十地

## 故事入口（R257）

《十地经》是《华严经》Toh 44 的第 31 章，也有独立流通版本。公开译本入口将十地教法与金刚藏（Vajragarbha）相连；本页登记其作为菩萨道法会的叙事节点，不把它改写成现实人物履历。

## 关系表

| 节点 | 关系 | 证据层 |
| --- | --- | --- |
| 金刚藏菩萨 | 作为十地教法的主要说法者 | 84000 Toh 44-31 作品入口 |
| 十地 | 组织菩萨从发心到成佛的经典结构 | 84000 作品与章节说明 |
| 《华严经》 | Toh 44 第 31 章与独立流通本的文本母体 | 84000《华严经》甘珠尔分组说明 |

## 边界

- 本页只登记作品入口与章节关系，不补写十地名称、各地功德或修行次第的逐章解释。
- “说法者”是经典叙事角色，不等同于现代学院教师、堪布或行政职务。
- 独立流通本与 Toh 44 章本的异文和汉译关系待版本批次核对。
