# 多宝佛塔与一乘授记

## 故事入口（R252）

84000 对 Toh 113 的公开摘要提到：释迦牟尼佛在灵鹫山说法，地下涌出菩萨，多宝佛虽已久入涅槃却乘浮空佛塔现身听经；作品以此类叙事承载一乘、方便与究竟教法，以及佛陀持续教化的主题。
