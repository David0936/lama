# 难陀出家与“出家”概念

## R190｜经典叙事案例

84000 的 *The Sūtra of Nanda’s Going Forth*（Toh 328）叙述释迦牟尼在迦毗罗卫附近向难陀解释“出家”（Skt. *pravrajyā*；藏文 *rab tu byung ba*）的意义与利益。难陀起初犹豫，佛陀以难得的人身、遇佛和修行机会作譬喻，最终难陀剃发、着染衣，从家出家。

页面引言还说明，这一故事在多个经典和律藏文本中出现，细节并不完全相同；汉译同题文本与藏文版本也“相似但差异明显”。因此，本条只建立叙事与术语入口，不把难陀的故事当作现代学院的招生、剃度、受戒或常住制度。

## 对理解现实路径的帮助

这条故事可以帮助读者区分三个层次：

1. **宗教叙事层**：佛陀说明出家、离家和解脱的价值。
2. **身份术语层**：*rab tu byung ba* 指从在家生活进入出家生活的概念，不等于某个学院职位。
3. **制度层**：现代入学、剃度、受戒、学籍、常住和教学资格必须另找当代机构来源。

## 版本与限制

84000 页面说明：现存藏文版本收入各类甘珠尔，汉文有一部题名相近但与藏文译本差异较大的文本；目前登记的是公开英译网页，不是藏汉原文文件。故事中的难陀、佛陀、阿难是经典叙事角色，不作为现实人物档案。
