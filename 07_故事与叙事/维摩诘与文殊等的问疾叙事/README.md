# 维摩诘、弟子、菩萨与文殊的问疾叙事

## 公开课程摘要入口（R245）

学院关联官网的《维摩诘经》讲解页把课程导航分成十四章，并将第三至第五品概括为佛弟子、菩萨和文殊探访维摩诘的对话；页面还列出第七品“观众生”、第九品“不二法门”、第十一品“菩萨行”和第十二品“见阿閦佛”等章节。这里可以建立一个“问疾—对话—不二—菩萨行—阿閦佛”的故事检索框架，但页面只提供讲授团队摘要，不是经文全文或逐段校勘。

## 关系图（工作层）

| 角色／主题 | 当前可记录关系 | 证据边界 |
|---|---|---|
| 维摩诘 | 在家居士、问疾对话的中心人物 | 课程摘要与作品题名层；不据此推导喇荣在家人身份规则 |
| 佛弟子 | 第三品相关的探访与对话角色群 | 页面未逐项给出所有弟子与段落，需回到译本核对 |
| 菩萨 | 第四品及后续菩萨行主题的关系节点 | 不把“菩萨”一词改写为学院身份或资格 |
| 文殊 | 第五品问疾对话的关键人物 | 不据章节摘要推断特定传承仪轨或历史人物身份 |
| 阿閦佛 | 第十二品的章节关系节点 | 不把章节出现等同于与文殊、维摩诘的固定等级关系 |

## 阅读方法

先把课程摘要当作导航，再分别查 T0474、T0475、T0476、84000 藏／英／简／繁版本的对应品名和段落。不同译本的品名、卷数和章节编排必须单独登记；故事叙述、馆方图像学和学院讲授摘要也要分层保存。
