# 千佛与贤劫发心故事

## 故事入口（R256）

84000 对《贤劫经》的摘要称：经中列出当前贤劫将出现的一千零四位佛，并说明他们的出生、觉悟、说法及最初发菩提心的因缘。故事将许多佛放进同一贤劫时间框架，适合作为佛之间关联的经典入口。

## 边界

- “一千零四位”是经文叙述的数量；不同版本中的名单和编号待逐条核对。
- 不把未来佛叙事写成历史考证或现实人物预测。
- 安多“三经”关系来自区域文化记录，不外推为喇荣学院课程或法会安排。
