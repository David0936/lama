# 须菩提与佛陀的般若问答

## 故事入口（R253）

公开目录把《金刚经》（Toh 16）置于舍卫城祇园精舍，并把须菩提列为般若问答的重要 interlocutor。Tsadra/Bodhicitta 书目进一步把作品描述为通过佛陀与须菩提的对话，说明进入菩萨乘、无我与空性的修行视角。
