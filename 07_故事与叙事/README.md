## R360｜故事叙事的证据分层

| 叙事层 | 记录方式 | 不应改写成 |
|---|---|---|
| 经文故事 | 作品编号、版本、章节和原文／译文定位 | 历史事件或现实制度 |
| 传记／传统叙述 | 作者、传统、年代和异说 | 已证实的现代人物事实 |
| 馆方图像说明 | 馆藏号、图像元素和馆方解释 | 经文唯一版本或寺院实际仪轨 |
| 历史事件 | 日期、地点、史料类型和争议 | 由故事寓意推导的历史结论 |

“佛之间的关联故事”先按叙事来源建立关系，再按经典、传记、图像或历史证据分栏。共同出场、互相授记或同一图像组合，不能自动证明现实师承、教派归属或学院实践。
