# 不可思议光明童子被弃与授记

## 故事入口（R251）

84000 将 Toh 103 概括为一位被遗弃的孩子在舍卫城废屋中独坐、受到野兽舔舐和围观者注视；佛陀派阿难查看，并揭示孩子是即将净尽业障的大菩萨。随后，孩子与佛陀以偈颂讨论空性与慈悲行动，帝释供养天衣，孩子又劝母亲向佛供养并发菩提心；波斯匿王询问其清净色身的业因，佛陀最后宣说五组四法并授记其未来成佛。
