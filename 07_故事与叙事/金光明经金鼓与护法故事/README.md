# 《金光明经》金鼓与护法故事

## 作品摘要层（R246）

84000 对 Toh 556 的摘要记录：如意宝（Ruciraketu）梦见一面发光的金鼓，从鼓声中听到忏悔偈并向佛陀复述；随后多位天神发愿护持这部经及其听闻、持诵者。摘要还提到医师 Jalavāhana 救护鱼群，以及王子 Mahāsattva 舍身救虎母子两则前生故事。

## 关系阅读

| 节点 | 故事关系 | 证据边界 |
|---|---|---|
| 如意宝 | 梦见金鼓，成为忏悔偈的叙事转述者 | 摘要层，不代替 Toh 556 正文段落 |
| 金鼓与忏悔偈 | 以声音和光明连接忏悔、听闻与清净主题 | 不把“功效”扩展成现代医疗或保证性承诺 |
| 诸天与护法 | 发愿保护经文及其持诵者 | 具体尊名、章节和仪轨须逐版本核对 |
| Jalavāhana | 救鱼、祝福鱼群的前生叙事 | 传统故事，不作历史人物传记 |
| Mahāsattva | 舍身救虎母子，连接布施与慈悲主题 | 传统故事，不改写为现实行为指令 |
