## 公开背景入口

史密森尼弗里尔与赛克勒馆的术语页把格鲁（Geluk）列入藏传佛教主要传统，并与噶举、萨迦一起归入后来出现的“新译”传统。该页另通过宗喀巴条目展示格鲁的公共艺术史入口；此处不据一页教育性材料推导格鲁全部制度、哲学解释或学院关系。

来源：[Smithsonian Sacred Spaces：four schools of Tibetan Buddhism](https://asia.si.edu/interactives/sacred-spaces/key-terms.html#four-schools-of-tibetan-buddhism) · [Tsongkhapa术语页](https://asia.si.edu/interactives/sacred-spaces/key-terms.html#tsongkhapa)。
