### 关系记录规则

“四大传统”是便于检索的公共分类，不是一棵互不往来的树。后续关系至少分成：共同印度佛教／那烂陀资源、译传史、文本或修持相似性、跨派人物活动、机构级合作。前三类不能自动升级为最后一类；学院是否开设某课程或邀请某位教师，必须回到带日期的学院页面或正式公告。

本目录不把博物馆教育页的分类改写成教派自述，也不把公开比较页当作任何寺院的现行制度说明。

## R385｜教派关系图的边与节点

教派关系图将“传统”“支系”“寺院”“人物”“作品”“仪轨”“学院活动”作为不同节点；边必须带关系谓词、时间范围、证据来源和方向。可用关系包括：源流、译传、注疏、修持相似、师承、跨派活动、共同出版、正式合作和“编辑导航”。

共同使用某尊格、同一部印度经典或相近图像，只能建立文本／主题层关系；没有传记、谱系、协议、双方公告或共同项目记录时，不建立师承或机构合作边。关系图展示研究假设和已核事实时，分别标注 `verified`、`reported`、`inferred`、`disputed` 和 `unknown`。
