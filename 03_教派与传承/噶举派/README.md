本条目用于记录噶举派的传承、人物、文本与修持资料。当前仅在 `19_佛教传统与宗教关系简明导览` 登记简明背景；具体支系和喇荣相关活动待来源核实。

## 公开背景入口

史密森尼弗里尔与赛克勒馆的术语页把噶举（Kagyu）列入藏传佛教主要传统，并将其与宁玛的早期传播相对照，归入后来出现的“新译”传统。这里仅记录馆方教育性分类；噶举内部的支系、祖师、密续和大手印文本需分别建档。

来源：[Smithsonian Sacred Spaces：four schools of Tibetan Buddhism](https://asia.si.edu/interactives/sacred-spaces/key-terms.html#four-schools-of-tibetan-buddhism)。
