## 公开背景入口

史密森尼弗里尔与赛克勒馆的教育性术语页把宁玛（Nyingma）列为藏传佛教主要传统之一，并以“古译／古老”语境说明其源头与西藏七至八世纪的早期传播相关；页面进一步将莲花生置于该叙事中。此处记录的是博物馆面向公众的背景说明，不替代藏文传记、寺院谱系、教派自述或学术史研究。

来源：[Smithsonian Sacred Spaces：four schools of Tibetan Buddhism](https://asia.si.edu/interactives/sacred-spaces/key-terms.html#four-schools-of-tibetan-buddhism)。

## 需要继续拆分的层次

- **历史分期**：早期传播、后弘期和不同译经传统需分别找史料。
- **传承与文本**：伏藏、大圆满、密续和寺院谱系不可由一页展签概括。
- **机构关系**：宁玛背景不等于所有学院课程、教师或法会都只属于单一传统。
- **图像与法物**：与莲花生相关的博物馆对象另见[莲花生尊格条目](../../06_佛菩萨与尊格/莲花生/README.md)。
