## 公开背景入口

史密森尼弗里尔与赛克勒馆的术语页把萨迦（Sakya）列入藏传佛教主要传统，并与噶举、格鲁一起归入后来出现的“新译”传统。该分类是博物馆面向公众的简明背景，不足以概括萨迦寺院网络、道果传承、文本版本或现代机构关系。

来源：[Smithsonian Sacred Spaces：four schools of Tibetan Buddhism](https://asia.si.edu/interactives/sacred-spaces/key-terms.html#four-schools-of-tibetan-buddhism)。
