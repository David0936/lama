## “人皮唐卡”称谓

本项目当前没有找到带可复核馆藏号、材料检测或馆方材料字段的“人皮唐卡”公开对象。因此，“人皮唐卡”仅作为待核检索词，不能据图片说明、商品标题或二次转载判断材料为人体皮肤。

对于人体材料对象，至少应分别登记：馆藏号、馆方题名、材料判断的来源、年代／地区、来源流转和展示／研究状态。材料未确认时写“待核”，不得使用“人皮”“人骨”等确定性标签。
