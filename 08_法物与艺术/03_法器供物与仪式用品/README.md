## 馆藏卡：Dril-bu 与 Dorje 成对法器

大都会艺术博物馆登记一组成对的藏传法器，题名 **Dril-Bu and Dorje**，馆藏号 **89.4.1443a,b**，馆方标为西藏19世纪、青铜，地理字段写作 **Derge?，Tibet**，问号保留。对象页称二者用于藏传佛教仪式念诵，通常成对使用：铃（dril-bu）持于左手，金刚杵（dorje）持于右手，手势与念诵相互配合。

馆方把这对法器解释为方法与智慧、直觉与慈悲的两面，并指出杵端形制与印度神话中因陀罗的雷霆杵有关。这里的“方法／智慧”和神话关联属于馆方图像与宗教艺术解释；不自动等于所有传承的仪轨用法，也不证明喇荣学院在某场法会使用该件对象。

对象页：[The Met Dril-Bu and Dorje 89.4.1443a,b](https://www.metmuseum.org/art/collection/search/502009)。另有单件金刚铃对象页：[The Met Dril-Bu 89.4.69](https://www.metmuseum.org/art/collection/search/500698)，附馆方音频但当前无文字稿。

### 记录边界

- **可核**：馆藏号、材料、年代、地理字段、左右手持法和馆方解释。
- **待核**：藏文术语的地区发音、具体仪轨文本、不同教派手势差异、学院现场使用。
- **许可**：对象页提供馆方数字资源入口；下载或再利用前仍需按页面许可核对。
