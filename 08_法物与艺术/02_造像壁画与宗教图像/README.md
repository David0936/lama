## 跨区域艺术史阅读入口（R101）

大都会艺术博物馆的艺术史文章指出，藏传佛教艺术的风格与印度、克什米尔、尼泊尔、中国及中亚等相邻区域的互动有关。其分期性概述为：11世纪末至12世纪初，帕拉时期印度艺术是重要影响来源；13世纪以后，尼泊尔艺术家也受西藏委托创作绘画和造像；14世纪后，尼泊尔与中国的影响更突出，并在15世纪形成具有藏地特征的综合。

同一文章还将许多造像、绘画说明为禅修观想的辅助物，并指出委托图像可能与纪念、祈愿或功德等语境有关。这些是该馆的通史性艺术史解释，适合用来提出“图像从何而来、如何流动、怎样被使用”的研究问题；不应把它压缩成单一路线，也不能据此认定某件作品的作者、寺院归属、开光状态或当代仪轨用途。

来源：[The Met｜Tibetan Buddhist Art](https://www.metmuseum.org/de/essays/tibetan-buddhist-art)

## 记录方法

1. **对象层**：题名、馆藏号、年代、地区、材料、尺寸、来源流转，优先馆方目录。
2. **图像层**：尊格、手印、持物、眷属和构图，保留馆方或研究者的原有解释者。
3. **实践层**：观想、礼敬、供养、开光和法会必须另有仪轨、田野或机构资料支持，不能由图像外观推导。
4. **传播层**：将风格影响、文本翻译、艺术家流动与政治赞助分别建证，不把“受影响”写成单向传承或正式合作。
