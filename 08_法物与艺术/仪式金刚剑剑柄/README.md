# 仪式金刚剑剑柄（The Met 2017.161）

## 馆藏记录

大都会艺术博物馆将这件对象题名为 **Hilt of a Ritual Sword**，文化归为西藏，年代16—17世纪，材质为铜合金，长度约10.5厘米，馆藏号 **2017.161**。对象目前未展出；馆方页面标注图像为 Public Domain。

来源：[The Met 对象目录](https://www.metmuseum.org/art/collection/search/747976)。

## 象征与仪式语境

馆方说明将其称作“智慧之剑”的剑柄，解释为切断精神和世俗无明，并指出此类剑在与文殊、莲花生和吉祥天女相关的仪式、唐卡、壁画和雕塑中出现。剑身已经缺失，因此本条只登记剑柄及馆方语境，不把它复原成一件完整法器，也不据此推断任何具体寺院的使用方法。

剑柄顶部的三叶形构件被馆方谨慎解释为“三眼宝”（藏文转写 *nor bu mig gsum pa*）的可能表现；护手为类似吉祥面（*kīrttimukha*）的形象，握柄饰莲瓣。以上均是馆方图像学说明，仍需与藏文法器文献和地区实物比较。
