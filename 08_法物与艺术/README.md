# 08_法物与艺术

状态：v0.5规划目录。以下是收录范围，尚未完成专题检索，不代表对任何具体实物或习俗普遍性的确认。

- [01_唐卡绘画与织绣](01_唐卡绘画与织绣/README.md)：唐卡的题材、制作媒介、流派、用途、图像识读与传承；具体对象逐件建卡。
- [02_造像壁画与宗教图像](02_造像壁画与宗教图像/README.md)：造像、壁画等作品与建筑、尊格和故事的关联。
- [03_法器供物与仪式用品](03_法器供物与仪式用品/README.md)：用途、形制、材料、来源与不同传统的使用语境。
- [04_人体材料相关器物](04_人体材料相关器物/README.md)：为人骨、人皮等材料的历史器物、记载与研究预留入口；材料确认、年代、流转与用途需分别取证。
- [05_材料工艺与象征](05_材料工艺与象征/README.md)：实际材料、仿制材料、图像中的象征性表现分别描述，不由外观判断人体材料。
- [06_馆藏实物与来源履历](06_馆藏实物与来源履历/README.md)：优先记录馆藏号、机构、目录链接、定名、材质判断依据与流转史；馆藏说明也保留其不确定性。
- [07_争议称谓与误传辨析](07_争议称谓与误传辨析/README.md)：图像误读、误标、现代复制品与来源不明说法；逐项核查，不预设全部为真或全部为假。
