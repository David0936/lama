# 03_人骨器物与相关记载

收录人骨材料器物的候选资料，逐件核对部位、材料认定、年代、功能与出处；未证实项保持未知。

状态：研究入口，尚无已核验个案。

## 首批馆藏卡（大英博物馆）

### 1. Shanmudra 人骨仪式围裙（1930,0306.1）

- **馆方对象名**：shanmudra；bead
- **材料／年代／地点**：人骨、玻璃珠、丝织物；馆方标为可能的19世纪；西藏
- **馆方功能说明**：馆方策展评论将其与 Chöd／Cham 语境联系，并记录“移动时的声音、视觉和其他感官”在仪式中的意义；该段属于馆方评论，不能替代仪轨原文。
- **收藏与展览**：1930年捐赠；曾于2015—2016年在 Wellcome Collection 的 *Tibet's Secret Temple* 展出；现未展出。

对象页：[British Museum 1930,0306.1](https://www.britishmuseum.org/collection/object/A_1930-0306-1)

### 2. Shanmudra 人骨仪式围裙（2003,0929.1）

- **馆方对象名**：shanmudra；bell
- **材料／年代／地点**：人骨、皮革及金属铃；馆方标为可能的19世纪；制作族群 Tibetan，地点字段为西藏
- **馆方描述**：对象包括人骨围裙、项链（？）和腕饰，围裙下缘有无簧片小铃；馆方没有在该页给出完整的仪式归属结论。
- **收藏信息**：2003年遗赠；现未展出。馆方记录的遗赠链条属于收藏史资料，不等于原始制作或使用者身份。

对象页：[British Museum 2003,0929.1](https://www.britishmuseum.org/collection/object/A_2003-0929-1)

### 证据边界

两件对象的“人骨”来自馆方材料字段；年代、地点和功能按馆方原词保留。它们可以作为人体材料器物的可核对象入口，但不能证明喇荣学院、某一具体传承或当代寺院仍在使用同类法物，也不能据馆藏记录推断材料取得过程是否符合当地伦理。后续应补馆方图像、出版目录、相关展览文字稿和来源流转研究。
