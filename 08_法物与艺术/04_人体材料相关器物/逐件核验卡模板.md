# 人体材料相关器物：逐件核验卡模板

“人皮唐卡”“人骨法器”等称谓先作为待核线索，必须逐件核实。

| 字段 | 要求 |
|---|---|
| 对象 ID 与馆藏号 | 优先使用馆方目录或出版物编号 |
| 馆方题名 | 保留原文；与网络俗称分栏 |
| 材料字段 | 记录馆方材料描述、检测报告或历史题记原文 |
| 年代与地区 | 标注估年方法、地点和不确定性 |
| 来源流转 | 馆方 provenance、收藏史和入藏方式 |
| 图像/器形 | 只描述可见形式，不由图像猜材料 |
| 证据等级 | 馆藏目录、检测、历史文字、学术研究、网络转载 |
| 展示与访问 | 当前展示、研究限制、版权和访问条件 |
| 未解决问题 | 材料、真伪、年代、来源或称谓冲突 |

没有材料字段、检测报告或逐字历史记载时，统一写“材料待核”；不得从照片、商品标题或二次转载写成“人皮”“人骨”等确定结论。
