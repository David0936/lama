## R107 材料、工艺与象征：四层证据法

“看起来像骨、皮、金属或织物”不是材料鉴定。本库把涉及材料的陈述拆为四层，并在对象页、图像说明和仪轨叙述之间保持距离：

| 层次 | 可以怎样写 | 需要什么证据 | 不能推出什么 |
| --- | --- | --- | --- |
| 1. 馆方材料字段 | “馆方材料栏登记为人骨／人颅骨／丝织物等” | 有馆藏号的目录字段 | 来源人的身份、取得方式、伦理评价或当代使用 |
| 2. 工艺与构成 | “馆方描述为双面鼓、围裙、铃、冠或装饰套装” | 目录的 Object Type、Description、Materials | 未列出的部件、制作技术或完整仪轨 |
| 3. 图像与策展解释 | “馆方评论将对象置于某展览或仪式语境” | 策展文字、展签、图录并注明解释者 | 全体传统、特定学院或历史事实的统一结论 |
| 4. 实验／修复分析 | “某报告以何种方法得到何种结果” | 可定位的检测报告、实验室、样本与方法 | 未检测对象的材料、整类器物的普遍结论 |

目前本库已具备第1—3层的若干馆藏入口，尚未登记可公开回查的实验室检测报告；因此不能把“馆方材料字段”升级为科学鉴定，也不把网络图片、商品标题或二手转述写成材料事实。

## 可核对象的示例与边界

大英博物馆目录将康铃 **2016,3040.2** 的材料字段登记为人股骨、金属、绿松石和珊瑚；将嘎巴拉供碗 **1926,1209.1** 的材料字段登记为人颅骨、青铜和绿松石。它们支持的是**两件具馆藏号对象的馆方元数据**。有关Chöd的策展语境、制作和使用者、来源人、取得过程、伦理或学院关联，必须另有相应证据。

## “人皮唐卡”及其他高风险称谓

没有馆藏号、材料字段、检测报告或可追溯出版记录时，“人皮唐卡”“人皮法器”等只能作为**待核检索词**。图像恐怖感、社交媒体标题、照片说明或与人体材料器物并列出现，都不能证明材料为人体皮肤。相关线索统一进入[争议对象清单](../04_人体材料相关器物/04_证据与争议对象清单/README.md)，并将“材料”“功能”“来源流转”“当代解释”分栏。

## 待核

- 公开可复查的材料检测、修复报告及其方法、样本和局限。
- 每件对象的来源流转、采集和收藏史；不由馆藏地推断伦理结论。
- 藏文原称谓、各地区用法和仪轨语境；不以汉语译名替代。
