# 全球馆藏与历代演变规划 v0.7

## 收录方向

欧美等地博物馆中的藏传佛教文物、历史记录、图录、档案和公开研究纳入百科。新增22目录作为机构与资料入口；11目录按时期扩编，同时保留跨地区与藏地自身分期。这里只规划研究范围，不预填某馆藏有某物或某朝代的完整结论。

当前继续以网上公开信息检索、整理、审校；未来私有化预留不影响本阶段。

## 目录之间怎样连接

机构登记：博物馆、图书馆与档案馆在22目录建立简明入口，统一机构ID；同一机构不重复建立实体。

对象正文：法物和艺术品保留08目录主档；经卷及书籍保留04目录作品与版本；档案和旧照片登记来源与媒体ID。22目录展示跨馆索引与收藏史。天葬、人体材料器物等特殊专题继续引用同一对象，不复制正文。

历史关系：文物 → 制作/使用时期 → 人物/寺院/地区 → 流转事件 → 当前收藏机构。每条连接独立有据，馆藏所在地不是制作地，入藏日期不是制作年代。

## 馆藏卡最低内容

机构名称、国家地区、馆藏号、馆方题名及原文、藏汉英名称或待核译名、官方目录链接、对象类型、尺寸与材料、定年及精度、归属地区、题记、图像、来源流转、研究文献、访问日期。

当前所属机构与当前展出地点分开；尚未查询展出状态时不声称可以现场看到。归属、材质或年代有疑问时保留馆方原限定语。后续优先使用公开馆藏目录、档案原件、检测报告和研究出版物；搜索摘要和转载只作线索。

网页有图片不等于可自由再分发；保留图片许可和原始链接。数字化缺失的对象可先收书目，不将其算作已读全文或已取得图像。

## 各朝代页面使用同一组问题

1. 这一时期藏地、周边地区和中国各政权处于什么背景？
2. 有哪些可证实的人物、寺院、教派与传承变化？
3. 与政治制度、封授、资助、管理的具体关系是什么？
4. 经籍、翻译、教育和修持发生哪些有据的变化？
5. 有哪些实物、建筑、档案可直接帮助读者理解？
6. 不同语言史料怎样记载，哪些问题仍有争议？

按唐、五代及宋辽金西夏、元、明、清、民国、中华人民共和国时期组织导航；这些是阅读入口，不把同一时代的并存政权排成前后继承。早期背景与藏地自身分期另有入口，不把尚未形成的教派概念倒推到更早时期。

各时期先形成约800–1200汉字概述与5–10个关键事件，再链接具体人物、经典、器物和研究记录。与学院及其相关传承联系密切的部分可以深入，其他背景保持概览；不扩展为所有中国朝代的通史。

## 多线时间轴

未来显示四条并行时间线：地区与政权、宗教与传承、文献与艺术、机构与人物。展示日期精度、年代区间和争议定年；不将“大约某世纪”补成确定某年。现代地域标签只用于导航，历史地名与范围另存。

示例阅读路线（关系均待对象证据确认）：清代时期概述 → 一件有据的宗教艺术品 → 题记与制作背景 → 已知流转事件 → 欧美馆藏目录 → 相关尊格或经典。

## 收藏史与历史争议的处理

区分已记录的交易、赠与、发掘、带离和未知流转环节。涉及掠夺或返还主张时记录提出者、原始证据、机构回应和日期；不从“在海外”推断取得方式，也不以馆藏合法登记消除来源争议。不同研究结论并列出处，明确编辑判断依据。

## 第一轮样本

选择3–5家有公开可检索目录的欧美机构，取得最多10件候选对象；尽量覆盖图像艺术、法器、经卷和历史记录，某类不足如实说明。先核实目录和来源，不现在预定必然存在的藏品清单。

另选择两个史料较充足的时期，试作概述、5个事件与2件文献/实物关联。验证跨目录链接、日期精度和来源定位后，再扩充其余时期。
