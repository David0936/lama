# 习俗、生命礼仪与人体材料专题 v0.5

## 收录范围

天葬、唐卡、人皮唐卡相关说法、人皮及人骨材料法器均在百科研究范围。新增21目录研究藏族社会习俗与生命礼仪，扩展08目录研究艺术和物质文化。此轮建立入口，不生成未核实的历史结论。

## 分类和主档

- 天葬主档在21目录，关联生命观、仪轨、历史与地域；如有本院关联，须另附证据。
- 唐卡、法器及具体器物主档在08目录，关联尊格、图像、仪轨、馆藏与材料。
- “所谓人皮唐卡”保留为检索入口；待逐件确认原称谓、对象类别及材料后，再决定正式定名，不预先认定真伪。
- 宗教修持原文在04/09目录，法会在10目录，器物不复制成多份正文。人体材料来源与天葬之间如有具体关联，必须有直接证据，不按目录相邻推断。

## 单件对象的证据结构

每件候选器物分别回答：它是什么、谁如何命名、实际材料是什么、年代与地区是什么、由谁收藏、经历怎样的流转、如何使用、哪些解释存在分歧。

| 资料性质 | 可以支持的内容 | 仍需注意 |
|---|---|---|
| 馆藏登记与检测报告 | 机构对具体对象的定名、记录或检测结果 | 材质、年代和用途可能各有不同把握程度 |
| 历史文献 | 某时某人记录了某种说法或实践 | 不自动证明眼前实物或普遍实施 |
| 学术研究 | 对来源与对象的研究解释 | 保留作者结论与争议，不替代原证据 |
| 口述与传统叙述 | 讲述者在特定语境中的说法 | 标明身份、时间与记录方式 |
| 网络图文 | 后续检索线索 | 不能由图片或标题直接判定材质和真伪 |

人皮、人骨、动物材料、仿制材料以及图像中象征性的皮骨表现必须区分。即使某实物确为人体材料，也不能仅由此推断取得方式、死因、年代、使用者或当地社会普遍做法。

## 扩编的社会背景

补入出生取名、家庭、婚姻、待客、饮食服饰、节庆、临终与纪念、其他葬俗、朝圣、禁忌与口述传统。每篇先限定地域、时代和群体，不把文化习俗、宗教规范和学院现行制度混写。对有争议的事件和器物保留证据，不作猎奇式标题或无据美化。

## 未来私有系统中的呈现（当前不启用）

延续老师授权策略。文字、图像、来源及衍生摘要可分别设访问范围；涉及遗体或人体材料的真实细节图像增加media_sensitivity标记，阅读界面先显示中性文字说明，是否展开由读者选择并受原权限约束。普通题材的唐卡或材料不因进入本专题自动被标为机密。

本轮不搜集或展示相关图像，不接触本地机密资料。当前继续按公开来源进行研究与内容审校，不要求老师授权。
