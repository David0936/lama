# 学院运转与空间扩编 v0.2

2026-09-13。此文件是内容架构与后续研究规格，不是现行招生、出家申请指南或实测地图。

## 面向外人，要回答的六个问题

1. 我是什么身份、为什么来：参访、朝圣、听课、长期学习、出家分别通向哪些入口？
2. 怎样进入、由谁接纳：向谁了解，什么条件适用于谁，入学、受戒、常住是否由同一主体安排？
3. 进来以后怎么生活和学习：住哪里、学什么、每天做什么，生活与教学怎样衔接？
4. 如何获得某种资格或承担某种职责：谁评定、依据什么、何时生效，有哪些非线性的去向？
5. 这里谁负责什么、资源怎么流动：教学、宗教指导、行政协调、后勤服务、供养与外界往来？
6. 这些活动在什么地方发生：地图、功能区、建筑和道路如何支持日常生活与大型活动？

## 身份不是一把梯子

以多维身份表呈现同一个人，避免“普通人→僧人→堪布→仁波切→院长”的预设。至少分开：

| 维度 | 待核内容 | 不能默认推导 |
|---|---|---|
| 参与/居住 | 听课、入学、短住、常住 | 能听课不等于获准常住 |
| 受戒身份 | 在家戒、出家戒及当地适用类别 | 入学不等于已受戒 |
| 学习和教学资格 | 课程、评核、堪布/堪姆等称谓的具体语境 | 学习年数不自动等于授予资格 |
| 尊称和传承身份 | 仁波切、上师、转世系统中的身份与认定 | 不与某一学历或职级作自动换算 |
| 管理职责 | 院长、副院长、其他有依据的职位 | 宗教称谓不自动意味着行政任职 |

现有基础来源：[关于教育与堪布/堪姆称谓的2013年对谈](https://www.khenposodargye.org/talks/2013/04/buddhism-todays-scientific-age-conversation-professor-gayley/)可用于研究教学语境；[2015年女性修学讲座](https://khenposodargye.org/talks/2015/10/the-status-of-female-practitioners-in-tibetan-buddhism/)可用于研究女性教育；[Lotsawa House顾问介绍](https://www.lotsawahouse.org/about/advisors)包含具名人物的教育和认定经历，可作为区分身份维度的个案线索。它们不是当前申请条件的证明，完整资格和称谓比较仍待研究。

## “一步一步”如何写得可信

每一条具体路径先限定机构、时间、群体与来源，再依次描述：起点 → 了解/申请入口 → 条件 → 确认主体 → 学习或身份变化 → 后续选择。每一步都允许“来源未说明”。

优先完成四种路线：汉语背景在家求学者、藏语背景在家求学者、已出家转来学习者、女性求学与教学路径。每种路线再区分短期与长期，不依民族推定宗教经历。对一个人的传记可以画完整时间线；对通用流程，必须有制度材料或足够明确的来源才能归纳。

不预设几年成为堪布、不承诺能在本院直接出家。仁波切、活佛、堪布、格西、住持等逐词建卡，注明传统与语境；其他传统的称谓用于比较时明确标记“非本院制度介绍”。

## 空间资料应做到什么程度

第一层区域位置与地形；第二层学院及聚落总览；第三层有出处的功能区；第四层建筑主档；第五层建筑的公开平面/形制资料。缺少实测图纸时仅做文字说明或明确标注的示意图。

每幅地图保存底图来源、许可、制作日期、反映时期、坐标系、精度与图例。历史图不能覆盖成当前状态；功能区边界若未证实，不画成确定界线。现实访问状态与地理位置分开记录。只收录公开公共空间和有依据的建筑信息，不登记个人住处、房间或日常行踪。

建筑条目记录名称与异名、用途及变化、所属机构、所在地、图像、建筑形制、修建/改建时间（可未知）、资料出处。教学空间、宗教活动空间、生活服务空间是功能标签，同一建筑可以多功能。未来地图点击建筑后，可进入这里发生的教学、仪轨、法会和历史事件。

## 学院主页怎样聚合

学院机构主档成为“如何运转”的总入口，链接人物任期、参与路径、教育、组织生活和空间专题。新增主题目录保存说明，具体人物、经典、仪轨及法会继续引用原有唯一主档。学院今后扩展为多所机构时，每个事实注明 institution_id，防止把喇荣的材料写成整个藏传佛教的统一制度。

## 额外纳入的容易遗漏内容

女性师资与堪姆；藏汉翻译与语言门槛；转学、离院与回乡任教；出版档案如何形成；志愿协作；饮食住宿和能源供水；公开医疗消防设施；供养和物资；周边社区；历史建设变化；线上与在家学习；来访者与长期学习者的差别。均先列问题与检索任务，有资料再写答案。

## 后续最小可验收样本

一份有时点的求学路径材料；一份堪布/堪姆资格或经历材料；一份身份多维对照；一组有日期的空间来源；三座可核实公共建筑卡；一个有明确观察时点的日常学习案例。不存在足够资料时，用缺口报告替代，不能为了完成数量编造。
