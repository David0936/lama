# 交流背景与藏语入门规划 v0.3

## 主次与阅读量

学院仍是主线。18、19目录提供简明背景，不扩成另一个世界宗教百科：每篇背景概述目标400–800汉字，加一张对照表或3–5条可靠出处；每个交流事件约150–300汉字。先收与本院直接相关的材料，背景案例明确说明不是本院活动。语言工具作为重点，可持续扩充。

## 学院对外关系怎样记录

[18目录](../18_院际海外与跨宗教交流/README.md)覆盖院际、海外、大学、翻译与跨宗教交流。每项记录时间、地点、实际参与者、派出/邀请主体、活动内容、来源与可见成果。分别标注个人活动、机构活动、所属未核实，不因师长受邀演讲就写成学院签订合作协议。

关系区分访问、授课、求学、翻译、出版、共同举办和正式合作。正式或持续合作必须有相应证据；共同出席一次活动仅记录该事件。来源未查到写“本批未找到”，不声称历史上没有交流。

## 宗教关联怎样讲得简明

[19目录](../19_佛教传统与宗教关系简明导览/README.md)回答用户关心的“有没有关联”，但每一条先说明是哪种关联：

| 关系 | 要找的证据 | 写法边界 |
|---|---|---|
| 共同源流与传播 | 年代、传播路径、人物与历史材料 | 不把所有传统画成整齐单线树 |
| 文本及译传 | 具体经典、版本、译者和引用 | 相近汉译词不必然是相同概念 |
| 历史影响 | 有证据的接触和接受过程 | 不能由相似仪式推断借用 |
| 当代交流 | 会面、合作或对话记录 | 不等于教义相同或组织隶属 |
| 主题比较 | 各传统的一手文本与自述 | 相似关怀与实质差异都需呈现 |

佛教传统的比较先分清时期、地域、教派和修学系统，当前主线聚焦藏传、汉传与印度佛教。共同源流、文本译传、历史影响、修学制度和当代交流分别记录；各方词义先在自身语境中解释，不把不同传统的概念强行互译。上述是编辑边界，具体教理正文待各方来源核查。

藏传派别在03目录保留主档；19目录只放简表与相互关系导览，不重复长篇。宁玛、噶举、萨迦、格鲁等不是按高低排列；觉囊与其他传统保留入口。苯教单列背景，身份归属依据来源解释。

基础检索入口示例：[传统关系公开讲话](https://kr.dalailama.com/news/2010/his-holiness-the-dalai-lama-in-new-york-ny-may-19-2010)可提供带主体的跨传统背景案例，但不能作为喇荣学院交流史或具体经论传承证明。后续比较必须补齐相应传统的一手资料。

## 300词的实际目标

目标是帮助初学者打招呼、介绍自己、询问课程和地点、听懂部分常用回应、请求重复或翻译，进而开展简短交流。它不是“背完300词即可讨论佛法”的承诺。词表必须搭配基本句法、敬语、听力与常见回答。

先做30词、12句的小样本，核实选音、表达自然度与敬语；通过后扩为100词、30句；再到300词、60句、12段短对话。词数是学习词条数：同一个词的不同译名不重复计数；变体挂主词条，必要的不同词义单独释义；句子不计入300词。

| 场景 | 目标词条数 |
|---|---:|
| 称呼、问候与礼貌 | 35 |
| 自我介绍与语言沟通 | 30 |
| 提问、否定、请求与常用动词 | 45 |
| 数字、时间与课程安排 | 35 |
| 地点、方向与建筑 | 30 |
| 听课、阅读与学习用品 | 35 |
| 基础佛教与修学概念 | 30 |
| 饮食、住宿与生活 | 25 |
| 身体状况与求助 | 20 |
| 告别、约定与复习交流 | 15 |
| 合计 | 300 |

这是选词配额，最终需按实际场景材料调整，任何调整保持总数与去重说明。基础功能词不可被冷僻佛教名词挤掉。12段对话建议覆盖见老师、自我介绍、说明语言程度、请重复、确认理解、问课时、找教室、借书、请教词义、生活请求、身体不适求助、致谢告别。

## 藏语发音的制作约定

藏文书写、Wylie转写、面向学习者的音标/注音、真人音频分栏。Wylie用于还原拼写，不直接当发音。先核实目标场景常用口语和教师背景；标明录音实际变体，不将所有康区发音或某种拉萨口语都称为“学院标准音”。口语、书面诵读与仪轨念诵分别标识。

[THL术语资源](https://thlib.org/terms/)可作词典与转写工具入口，自动转换结果不能直接标记为当地语音。每条目标包含：藏文、中文、English、释义、使用场景、敬语等级、Wylie、经核对的发音标记、正常速度/慢速音频、例句与常见回应、来源及审校状态。

汉字谐音若保留，只能作明确标注的近似辅助，不作为唯一发音依据。没有可靠音频时保留缺音状态；合成音频须标 synthetic，不能当真人母语示范。真人录制与审校需要实际可用人员或授权语料，当前仅规划，不预设已经具备。

## 符号分三类

1. 文字符号：藏文字母、组合、数字、分节点、句读和常见书写标记。
2. 宗教图像：例如法轮、莲花及常见图案的识读候选；每种解释注明传统、对象和出处，不假定只有一种意义。
3. 场景标识：地图图例、建筑名称牌与公开指示标记；不把编辑制作的图例误称当地传统符号。

符号条目记录形状/Unicode或合法来源图片、藏汉英名称、出现语境、解释与出处。宗教对象的详细内容引用06/08目录，地图图例引用16目录，12只负责识读入口。

## 验收与后续交付

背景部分：每条关系有类型与出处，外部事件不归入本院史。语言部分：词条去重，三语语义对应，发音标记与音频对象一致，敬语和语境有核查记录；分别统计词义、语音和使用语境的审校状态。由熟悉目标口语的人员或可靠既有语料确认后，才能标为已核准实用表达。

最终可导出300词手册、场景口袋卡、音频索引与复习卡；目前先存Markdown/JSONL，等小样本验证后再制作交互页面。合格目标是能完成具体的听说任务，不是文件里凑足300行。
