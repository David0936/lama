# 释迦牟尼佛

本条只提供与萨嘎达瓦阅读路线有关的最小公共背景，不试图覆盖各传统的完整佛传或教理。

## 公开背景线索

索达吉堪布官网的“Life of the Buddha”页面以“十二行”介绍佛陀从诞生到般涅槃的叙事框架。其解释属于该教学页面的表达，应与不同佛传文本、地方传统和历史研究分开阅读。

来源：[Life of the Buddha](https://khenposodargye.org/talks/2014/11/life-of-the-buddha/)。

## 公开馆藏对象

史密森尼国家亚洲艺术博物馆登记的释迦牟尼像，馆藏号 **S2015.28.2**，定年 11—12 世纪，地域为西藏西部古格，材料为铜合金并可能原有嵌饰。馆方将其列于 Tibetan Buddhist Shrine Room 展示语境。它是有馆藏号的图像对象，而不是对任何学院现行供奉或节庆用物的证据。

来源：[Smithsonian 对象目录](https://asia.si.edu/explore-art-culture/collections/search/edanmdm%3Afsg_S2015.28.2/)。

## 与萨嘎达瓦的关系

萨嘎达瓦发布页将佛陀诞生、成道和般涅槃作为该月纪念主题；馆藏像与佛传教学页则分别提供图像、材料和叙事入口。三者是可检索的阅读关系，不表示这一件馆藏像参与了任何节期仪式。
