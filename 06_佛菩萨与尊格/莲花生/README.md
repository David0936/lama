# 莲花生（Padmasambhava／Guru Rinpoche）

本条把“莲花生”“莲花生大师”“咕噜仁波切”作为同一尊格的常用名称入口；历史叙述、宗教传统和博物馆展签分别记录，不把传统信仰叙述直接写成已证实史实。

## 传统定位

史密森尼国家亚洲艺术博物馆的馆方说明称，Padma Sambhava（“莲花生”）在藏传佛教传统中被尊为 Guru Rinpoche，并把其在八世纪入藏、传授密续教法及伏藏叙事列为传统背景。馆方页面同时明确该对象的年代、地域和材质；这些是馆藏编目事实，不能证明某一学院现行供奉或法会安排。

来源：[史密森尼 Padma Sambhava，S2014.18a-b](https://asia.si.edu/explore-art-culture/collections/search/edanmdm%3Afsg_S2014.18a-b/)。

## 图像与法物线索

该馆藏像定为18世纪或更晚、喜马拉雅地区，鎏金铜合金、绿松石、珍珠和颜料，馆藏号 **S2014.18a-b**。大都会艺术博物馆另有一件14世纪西藏西部或拉达克的莲花生像（**2012.459**），展签记录其手持金刚杵与嘎巴拉，并说明这些图像属性的象征解释来自馆方策展语境。

来源：[大都会艺术博物馆《The Spiritual Master Padmasambhava》](https://www.metmuseum.org/art/collection/search/78192)。
