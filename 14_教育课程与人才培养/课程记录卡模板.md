# 课程记录卡模板

用于将公开课程介绍、研究材料和具体讲义分开登记。

| 字段 | 要求 |
|---|---|
| 课程/项目原名 | 保留原文、译名和机构称谓 |
| 机构与时期 | 记录发布主体、教学地点和日期范围 |
| 学习对象 | 在家者、僧尼、公众或未说明 |
| 内容范围 | 五明、闻思修、经论、密续、语言、辩论等；按来源原文填写 |
| 教学方式 | 讲授、背诵、辩论、讨论、闭关或线上；不得混为同一形式 |
| 考核/资格 | 仅在来源明确时记录考试、证书或称谓授予 |
| 作品与版本 | 链接 04 目录作品卡，不复制正文 |
| 证据定位 | 网页章节、PDF 页码或视频时间码 |
| 当前性与缺口 | 历史案例、当年项目、持续传统或现行公告；列出未核项 |

课程记录卡不生成统一学制，也不把一次公开讲座解释为入学、受戒或取得教学资格的证明。
