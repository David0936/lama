## R180：学习后路径的教育证据矩阵

学习完成后的去向必须按活动和资格分开登记。Liang 与 Taylor 对 2017—2019 年研究项目记录了教师、教学助理、学生、考试和委员会关系；学院公开介绍则只提供学习社区与课程概览。两者都不能生成“毕业后自动任教”的规则。

| 路径 | 公开材料能支持 | 仍不能推出 |
|---|---|---|
| 教学助理 | 研究时期的课程辅助、讲解或延伸课堂 | 当前任教名单、聘任程序、薪酬、任期 |
| 任教／教学责任 | 特定研究项目中教师与教学委员会的关系 | 完成某课程即取得统一教学资格 |
| 闭关／专修 | 作为独立研究问题，须有具体传承或机构材料 | 闭关地点、许可、指导者、时长和完成标准 |
| 继续深造／转院 | 只能登记有明确传记或机构记录的个案 | 学院与其他寺院之间的学分互认或自动转学 |
| 回乡教学／社会服务 | 有公开个案时记录其具体去向与来源 | 普遍派遣、服务年限或全院毕业分配 |

本页与[阶段变化、转学、离院与还俗](../../13_入门出家与身份路径/09_阶段变化转学离院与还俗/README.md)互链，但不复制人物传记。每条教育路径须注明适用项目、时期、参与者身份、证据定位和未解决问题；“堪布／堪姆”“仁波切”“教师”“教学助理”和“行政角色”不能互相替代。

## R195：从课程完成到教学任命的证据分层

“完成学习后任教”必须拆成不同事件，不能写成一条自动晋升链。现有材料最多支持研究时期的角色并列，以及另一所宁玛学院的任命案例；没有喇荣现行公开聘任制度。

| 环节 | 可登记的证据 | 不能推出 |
|---|---|---|
| 课程与考核完成 | 研究时期项目的课程、考试、论文和委员会评议 | 结业即取得全院教师资格 |
| 教学助理 | 研究时期日程中的教学助理课程／课堂责任 | 教学助理必然转为正式教师、薪酬或任期 |
| 项目内任教 | 特定研究项目中的教师、资深学习者与委员会关系 | 公开的统一申请、投票或聘任表 |
| 教师任命 | Minling 页面所述 Chorpoen 经历、学生投票和行政决定案例 | 喇荣或其他传统采用同一程序 |
| 堪布／堪姆或住持 | 另有资格、戒律、教学年限和传统语境的称谓／职务证据 | 教师任命自动等于堪布、住持或仁波切 |
| 离院后教学 | 有姓名、机构和日期的公开传记才可登记 | 学院统一派遣、毕业分配或学分互认 |

### 证据结论

- S000047 只描述 2017—2019 年研究对象中的教师、教学助理、学生、考试和委员会；它是教育研究记录，不是现行人事制度。
- S-R194-002 是 Minling 学院的单院案例，页面把教师任命与 Chorpoen、学生投票、行政决定联系起来，并列出住持标准；不能外推至喇荣。
- S000001 只提供喇荣学习社区与课程概览，未提供课程完成、聘任、任期或行政岗位名册。
- 因此本百科暂不绘制“课程—教学助理—教师—堪布／仁波切”的统一阶梯；后续只收录带机构、时期和定位的个案或制度文件。

来源：[Liang & Taylor](https://blogs.dickinson.edu/buddhistethics/files/2020/08/Liang-and-Taylor__20_F-1.pdf)（印刷页 237—250） · [Larung Gar 公开介绍](https://www.khenposodargye.org/about/larung-gar/) · [Minling College](https://www.khenchenrinpoche.org/college)

## 待核

- 具体闭关项目的公开介绍、授予条件、指导关系和完成记录。
- 教学助理转为教师的公开制度或项目级记录；现有材料只支持角色并列，不支持转任规则。
- 个案以外的继续深造、回乡教学和社会服务证据。
