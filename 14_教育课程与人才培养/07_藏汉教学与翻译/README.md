## R116｜藏汉学习群体的研究性线索

Liang 与 Taylor 的2020年论文以2017—2019年的田野工作为基础，叙述喇荣在其研究所涉及的历史与教育语境中面向汉地学习者的传播，并写到部分汉族僧众与弟子到达后，有以汉语授课的班级及较快的学术项目。作者把这种安排与学习者既有教育背景联系起来。

这段文字是研究论文对特定历史与田野材料的概括，不是学院发布的双语课程清单。它可支持“藏汉语言与学习背景需要在教育研究中单独处理”的问题意识；不能确认今天有哪些中文课、哪些群体可入学、课程速度、翻译质量或任何身份资格。
