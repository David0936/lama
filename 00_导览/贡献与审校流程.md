# 贡献与审校流程

## 一条资料的最小流程

1. 先确定对象、时期、地区和资料类型，避免同名合并。
2. 保存公开 URL、访问日期和原文定位；PDF 记录页数、大小与校验值。
3. 在正文写清事实、证据性质、适用范围和未知项。
4. 在 `90_资料目录` 建立实体、来源、版本、媒体、主张和关系登记。
5. 运行 JSONL 引用、Markdown 链接和 `git diff --check` 校验。
6. 每批独立提交并推送，保留审校单和剩余缺口。

## 审校重点

- “现任”“正式合作”“全文已取得”“人皮/人骨材料”等高风险表述必须回到一手或馆方证据。
- 历史页面、个人讲记、搜索摘要和转载不能直接代表今天的学院制度。
- 不能确认的内容写入待核或缺口，不用推测填空。

人物档案、受限文本和未来私有资料另行管理；本流程当前只适用于公开资料。
