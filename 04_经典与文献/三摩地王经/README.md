# 《三摩地王经》

## 作品定位（R254）

84000 将作品登记为 *The King of Samādhis Sūtra*（*Samādhirājasūtra*），藏文题名 **ཏིང་ངེ་འཛིན་གྱི་རྒྱལ་པོའི་མདོ།**，Toh 127，德格《甘珠尔》卷 55，1.b–170.b。官方导论说明，题名中的 samādhi 不只指狭义禅定，也涉及行为、禅修、动机与证悟的一组佛教实践。

## 主要表达观点

- **禅定与空性**：84000 将本经介绍为关于禅定、空性和菩萨实践的长篇大乘经；这里保留导论层概括，不替代章节释义。
- **六度与菩萨道路**：官方页面说明文本包含六度等菩萨训练主题，并在后世论典和仪轨中被引用。
- **诵读作为活的实践**：84000 记录安多地区将《三摩地王经》与《八千颂般若经》《善劫经》并读，形成区域性“三经”组合；这属于安多文化记录，不外推为喇荣学院制度。
