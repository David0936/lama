# 《金刚经》／《能断金刚般若波罗蜜多经》

## 作品定位（R253）

84000 将作品登记为 *The Sūtra on the Perfection of Wisdom “The Diamond Cutter”*，梵名 *Vajracchedikā Prajñāpāramitā*，Toh 16。84000 学者专题把它列为般若经“短部”之一，约三百颂／行，场景为舍卫城祇园精舍；须菩提是般若问答的重要 interlocutor。84000 的正式英译页面仍标为“尚未发布”，本库不把页面状态写成已取得英译全文。

## 主要表达观点

- **无我与诸法空性**：Tsadra/Bodhicitta 书目把《金刚经》概括为大乘无我、诸法空性与菩萨乘发心的关键文本；这是目录导读层，不替代逐章释义。
- **问答与修行视角**：公开书目将佛陀与须菩提的对话视为进入菩萨乘的叙事框架；具体“无住布施”等章句需待可靠版本逐段定位后再登记。
- **般若文本家族**：84000 将《金刚经》放在较长般若经压缩形成的短部中，同时指出它有自身独特结构；不把“短本”理解为所有传统的单一源流结论。
