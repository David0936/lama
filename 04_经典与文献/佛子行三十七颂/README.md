### 观点登记原则

官方 PDF 的目录和正文可以支持“前行、菩提心、六度、逆缘转道、观察自心、回向”等**该英文本的章节主题**。这些主题要进入百科主张，必须绑定 PDF 页码或藏／汉版本段落；课程简介、音频标题和二手文字稿不能单独支撑“全书主要观点”。

媒体登记分为三类：**诵读**（经文声音）、**讲解**（教师说明）和**法会实录**（有明确仪式场景）。本批只登记公开入口，不下载或重新发布音频，不把课程讲解误写成念诵或口传。
