# 《月灯三昧经》

## R290｜汉文异译 PDF 入口

本条从《三摩地王经》分出，避免将题名相近的 `Samādhi` 经典混为一经。CBETA 文件记录三种汉文题名：T0639《月灯三昧经》（高齐那连提耶舍译）、T0640《佛说月灯三昧经》（刘宋先公译）与 T0641《佛说月灯三昧经》（刘宋先公译）。三者分别为 167、14、17 页，均完成文件级指纹与首页文本抽样，PDF 本体未入库。

这些文件支持汉文异译版本入口，不直接等同 84000 Toh 127《三摩地王经》；后续需以目录、梵藏题名和章节内容做文本关系核查。详见[R290审校单](../../91_待办与审校/R290-CBETA月灯三昧经三种汉译PDF核验.md)。
