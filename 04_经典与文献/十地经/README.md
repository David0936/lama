# 《十地经》／《十地品》

## 作品定位（R257）

84000 将作品登记为 *The Ten Bhūmis Chapter from the Mahāvaipulya Sūtra “A Multitude of Buddhas”*，梵名 *Daśabhūmika*，藏文 **ས་བཅུ་པ**，Toh 44-31，德格《甘珠尔》卷 36，166.a–283.a。84000 说明该章在部分甘珠尔中也作为独立文本流通。

## 主要表达观点

- **十地作为菩萨道结构**：作品以十个菩萨地组织从发心、修行到成佛的渐进路径；“十地”在本库中作为传统教理结构记录，不改写成现代等级制度。
- **金刚藏与佛陀法会**：公开译本入口把金刚藏（Vajragarbha）作为十地教法的主要说法者，适合与佛陀、菩萨众和《华严经》法会叙事关联。
- **经与论的关系**：十地文本长期与《华严经》及相关论典互相引用；具体汉译、印度梵文和注疏谱系另立版本批次。
