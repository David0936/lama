### 版本状态约定

- **已流式取得**：本地验证下载字节流、校验值与可提取性，但不把受版权保护的全文提交到仓库。
- **链接已核**：官方页面列出可访问下载入口；还没有逐个文件下载、页码及校验值。

这四项是小样本，不表示它们是学院统一必修书目，也不替代授课、灌顶、传承或修持资格的具体要求。
