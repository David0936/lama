### 版本状态约定

- **已流式取得**：本地验证下载字节流、校验值与可提取性，但不把受版权保护的全文提交到仓库。
- **链接已核**：官方页面列出可访问下载入口；还没有逐个文件下载、页码及校验值。
- **待逐版核验**：作品可能有多个文本、译本或讲记，尚未确定哪一件是原文、译文或注释。

## R364｜版本、观点与媒体的分开推进

当前目录已增加多部 CBETA 汉文 PDF 的文件级核验（含页数、字节数和 SHA-256），也保留 84000、馆藏和课程页面级入口。三类工作仍分别推进：

1. **版本层**：确认原文／译文、译者、版本、页码和文件指纹。
2. **观点层**：把主要表达观点绑定到章节、段落或页面，不用搜索摘要代替原文。
3. **媒体层**：把念诵、讲解、法会实录和展览录音分别登记，并记录时间码和权利状态。

文件级 PDF 核验不等于藏汉逐段对勘，也不等于学院课程、课诵或修法资格。当前新增的版本入口继续遵守这一边界。

这些条目是公开资料样本，不表示它们是学院统一必修书目，也不替代授课、灌顶、传承或修持资格的具体要求。

## R379｜作品主张卡与版本关系

每部作品的“主要观点”单独建主张卡，至少保存：作品 ID、章节／品／页码、原文或译文定位、主张类型（叙事、教理、修持、历史说明）、摘要语言、编者或译者、来源 ID和待核项。版本之间使用“原文、译本、异译、注释、讲记、节选、诵本”关系，不把同名页面合并成同一版本。

观点摘要只能引用已定位的段落或页码；没有定位时写“主题线索”，不写成作品明确主张。音频或视频中的观点需附起止时间码，并与文本版本分开登记。
