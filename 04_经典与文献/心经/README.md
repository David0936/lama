# 《心经》

## 作品定位（R250）

84000 将《心经》登记为 **The Heart of the Perfection of Wisdom, the Blessed Mother**，梵名 *Prajñāpāramitāhṛdaya*，藏文题名见 Toh 21 页面，德格《甘珠尔》卷 34。它是般若经传统中的短篇作品，公开导论说明其在东亚与藏地都有长期读诵与解释传统。

## 主要表达观点

- **般若与空性**：文本以观音菩萨与舍利子之间的问答呈现般若教法；84000 说明观音作为对话者在般若文献中具有特殊性。
- **短本与长本**：84000 导论区分汉文、梵文、藏文中的短本与长本；东亚较常流通短本，藏地较偏重长本。这里记录的是版本史入口，不把“短／长”写成不同宗派的唯一教义。
- **“圣母”称谓**：84000 面向公众的解释把“圣母”理解为般若智慧的拟人化表达，不是现实母亲身份，也不等于另一个独立的女性神祇系统。

## 藏传、汉传与印度文本关系

| 层级 | 当前可写 | 不可外推 |

| 汉传 | 84000 导论讨论汉文短本传播及玄奘相关文本史问题 | 不把某一汉译本直接当作所有汉传寺院的统一课诵本 |

| 跨传统 | 共同的般若主题与不同版本形态可并列研究 | 不用“藏传／汉传／印度”三分法抹平内部异译与历史变化 |
