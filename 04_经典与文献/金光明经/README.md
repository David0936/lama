# 《金光明经》

## 作品定位（R246）

84000 的公开翻译说明把《金光明经》放在“业障清净、个人与国家福祉”的大乘经语境中，并说明 Toh 556 是二十九品版本。核心叙事是居士菩萨如意宝（Ruciraketu）梦见发光金鼓，鼓声显出忏悔偈；随后诸天与护法发愿保护经文及持诵者。经末还包含医师 Jalavāhana 救护鱼群、王子 Mahāsattva 舍身救虎母子等前生故事。

这些是 84000 译本的作品摘要和经文导读层，适合做“主要表达观点—人物—故事—版本”入口；不能据护国叙事推断喇荣学院或任何现代寺院承担政治功能，也不能把故事直接改写成法会程序。

## 主要表达观点与故事关系

- **清净与护持**：经文把忏悔、持诵和听闻放进业障清净与护持众生的框架。
- **世间福祉**：文本对国王和国家福祉有明确叙事，但本百科只记录经典内容，不扩展为现代政府、寺院或学院的行政规则。
- **如意宝与金鼓**：梦境把发光金鼓、忏悔偈和听闻者的功德连接起来，是作品主线之一。
- **护法与诸天**：诸天、四大天王等在摘要中作为护持经文及持诵者的关系节点；具体尊名和章节需回到版本正文核对。
- **前生故事**：Jalavāhana 救鱼、Mahāsattva 舍身救虎母子，适合作为布施、慈悲和因果主题的故事入口，不等同于历史传记。
