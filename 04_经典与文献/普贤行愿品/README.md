# 《普贤行愿品》／《善行愿王》

## 作品定位（R255）

84000 将作品登记为 *The Noble King of Prayers of Good Conduct*，藏文 **འཕགས་པ་བཟང་པོ་སྤྱོད་པའི་སྨོན་ལམ་གྱི་རྒྱལ་པོ།**，Toh 1095，德格《甘珠尔》卷 101，262.b–266.a。84000 导论称其在藏传佛教中经常被诵读，全文为 63 颂；前十二颂尤其常被纳入仪轨或修持文本。

## 主要表达观点

- **七支供与发愿**：导论概括全文从礼敬、供养、忏悔、随喜、请转法轮、请佛住世、回向等七支结构展开。
- **利他与遍行愿**：作品继续发愿以教法利益众生、遍历无量世界并从诸佛闻法；这里保持经典自述层，不改写成现代组织使命宣言。
- **诵读功德叙述**：文本包含关于诵读利益、净化业障、往生净土及最终成佛的宗教表述；这些属于经典内部叙事，不当作经验性保证。
