# 《法华经》／《善法白莲经》

## 作品定位（R252）

84000 将通称《法华经》的作品登记为 *The White Lotus of the Good Dharma*，梵名 *Saddharmapuṇḍarīka*，藏文题名 **dam pa’i chos pad ma dkar po**，Toh 113，德格《甘珠尔》卷 51。公开摘要称佛陀在灵鹫山向菩萨等众说法，并出现从地下涌出的菩萨与已入涅槃的多宝佛在浮空佛塔中现身听经等叙事。

## 主要表达观点

- **一乘与方便**：84000 摘要将“一乘”以及方便／究竟教法的区分列为作品的重要大乘主题。
- **佛陀的持续教化**：摘要概括作品把佛陀的出生、觉悟和涅槃解释为超越性佛身的示现，并强调佛陀持续说法的叙事。
- **经典自我定位**：作品多处讲述过去和未来时代对本经的受持、供养与传播；本库登记为文本自身的宗教修辞，不推导现代组织权威。
