# 《宝性论》

## 文本与课程身份

本目录暂以《宝性论》作为中文工作名，英文公开页面使用 *Mahayana Uttaratantra Shastra*。学院关联官网的 2019 年课程公告把它描述为弥勒传给无著的“五部大论”之一，讨论第三转法轮与佛性，并称其可作为显乘与金刚乘之间的桥梁。这些是课程页面的宗教与教学定位，不替代藏文题名、校勘本或学术版本考证。

## 2019 年公开课程案例

公告记录课程约于 2019 年 5 月中旬开始，含休息约一年、每周两次；主要使用普通话，并提供英语、日语同声传译。页面写明对大乘教法有兴趣者可参加，同时区分“参加直播课程”和“观看录音”：要接受页面所称的藏文口传，需要参加直播；课程视频会在课后发布，教学材料只向登记学生提供。

这里登记的是一个**公开课程事件**，不能推成喇荣全院统一学制、所有时期的口传规则或现行报名制度。

## 观点入口（页面级）

- 课程页将本论置于佛性、第三转法轮和大乘道的哲学基础位置。
- 官方讲解页列出七个金刚处相关的音频／讲解分段：背景、七金刚处导论、法界、成佛、功德、事业和利益。
- 这些只是课程页和讲解页的目录级入口；本项目尚未取得藏文底本、汉译定本或逐段对读材料，不从页面目录扩写整部论的章节主张。

## 版本与媒体状态

课程公告列出两种英文参考译本的书目信息，但没有提供本论藏文 PDF 或汉文 PDF。本库暂不把参考译本登记为学院指定版本。官方讲解页有音频入口及英文同传标注，但本批只登记页面级媒体，不填直接文件、时长或完整时间码。
