# 《贤劫经》／《善劫经》

## 作品定位（R256）

84000 将作品登记为 *The Good Eon*，梵名 *Āryabhadrakalpikanāmamahāyānasūtra*，藏文题名 **’phags pa bskal pa bzang po zhes bya ba theg pa chen po’i mdo**，Toh 94。官方导论称它叙述当前贤劫将出现的一千零四位佛，并是多数《甘珠尔》总经部的重要长篇作品。

## 主要表达观点

- **千佛与贤劫**：经文按未来佛的名号、出生、觉悟与说法情境展开，构成佛之间的时间关联和传承想象；不把未来授记当作可验证的历史名单。
- **六度与发心**：84000 摘要说明佛陀在经中讲授禅定与六度，并追溯这些未来佛最初发菩提心的因缘。
- **经典的社会使用**：导论称该经在西藏常被单独抄写、印刷，并由喇嘛在特殊场合朗读、置于家庭佛龛；这是历史／人类学层的公开导读，不等于学院现行制度。
