# 《律藏·出家事》

84000 英文题名：*The Chapter on Going Forth*；藏文标题为 *rab tu ’byung ba’i gzhi*，对应《律藏根本部》（Vinayavastu，Toh 1）第一章（Toh 1-1）。本条目用于解释佛教僧团准入、导师角色和仪式形成的经典背景，不替代现代学院规章。

## R192｜僧团准入与导师角色

84000 的作品摘要把本章描述为《僧律诸章》（四卷、十七章）的第一章，讨论佛教僧团生活的法规和程序。本章追踪从佛陀早期“来，比丘”式邀请，到更完整的“现行仪式”的形成；同时介绍授戒导师与教导者的职责，并讨论年长者与未成熟新人的区分。

这能帮助读者理解“出家”“导师”“受戒仪式”“僧团规则”在律藏中的关系，但不能推出喇荣当前的申请表、剃度安排、受戒资格、介绍人制度、学籍或常住审批。

## 与现代路径的对应边界

| 律藏文本层 | 可用于理解 | 不可直接转换为 |
| --- | --- | --- |
| 出家仪式形成 | 早期僧团如何逐步形成正式准入程序 | 喇荣当前剃度或受戒日程 |
| 授戒导师、教导者 | 受戒与学习关系中的角色分工 | 现代学院“院长—堪布—班主任”组织图 |
| 年长者与新人 | 僧团内部经验和训练差异 | 当代学制、年级、毕业资格 |
| 律藏规则 | 传统僧团生活的规范性背景 | 任何地区今天自动有效的法律或校规 |
