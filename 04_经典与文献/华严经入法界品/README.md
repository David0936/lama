# 《华严经·入法界品》（《入法界品》）

## 作品定位（R247）

84000 将 *The Stem Array*（梵 **Gaṇḍavyūha**，藏 **sdong pos brgyan pa**）登记为《华严经》（*Buddhāvataṃsaka*）第四十五章，Toh 44-45。公开英译的书目说明译者包括益西德、Jinamitra、Surendrabodhi 与 Vairocanarakṣita，并把文本定位在德格《甘珠尔》卷 37—38 的藏文传承范围内。

这里使用“《入法界品》／《华严经·入法界品》”作为中文检索别名，不把 84000 的现代英译、藏文甘珠尔文本和汉文《华严经》译本压成同一文件。汉文版本、梵文材料和藏汉逐段对读仍需另批核验。

## 主要表达观点

- **求法旅程**：84000 的中文导读和英文学术导读都以善财（Sudhana）参访善知识为主线；善知识的身份跨越天神、儿童、妓女、医师和普通劳动者等，不应被改写为现代机构的职位清单。
- **开放的智慧来源**：公开导读把参访过程解释为打破狭隘现实观、从不同身份的导师处学习；这是现代导读的解释层，不代替逐段经文或任何学院课程讲义。
- **普贤行愿收束**：84000 英文导读说明叙事最终以普贤的发愿偈（*Bhadracārīpraṇidhāna*）收束；本库将其登记为作品内部的结尾结构，未把偈颂当作喇荣现行课诵证据。

## 证据边界

- “第四十五章”“Toh 44-45”“译者名单”和德格卷次来自 84000 作品页及其书目；不等同于汉文译本的卷品编号。
- 中文导读提到善财参访五十多位善知识、以及儿童、妓女、医师和劳动者等身份，是 84000 面向公众的导读表述；本库保留其来源定位，不据此制作现实中的身份晋升模型。
- 本条不把善财故事、普贤行愿或 84000 的公开讲解写成喇荣学院的招生、受戒、闭关或法会规则。
