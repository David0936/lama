# 《不忘》／*Always Remember*

## 文类与来源性质

官方页面称此书为纪念法王如意宝圆寂十三周年而编集的教言，并列出因果、各宗教传统、弘法利生、取舍、藏族文化与转世化身等主题。以上是发布方对编集内容的介绍，尚未逐页校核为法王原说、编辑说明或译者文字。
