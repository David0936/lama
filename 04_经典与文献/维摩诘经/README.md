# 《维摩诘经》

## 作品与公开课程入口（R229）

学院关联官网的官方讲解页把《维摩诘经》列入经典讲解，并记录：2018-03-27 开始正式讲授，页面将课程展开为十四章；讲义由翻译团队摘要并与视频入口并列。该页的“章节观点”是讲授者／团队的现代解释层，不替代鸠摩罗什汉译、藏译或梵本校勘。

WCDU 线上课程页又记录 2019-04-14 的续学安排：从第四品“菩萨”开始，约七个月学习后五章，内容围绕维摩诘与文殊等菩萨的对话；课程以英语提供，由来自喇荣的佛法教师依索达吉堪布口传讲授，每个周日安排两场，材料按课次提供。该条是面向公开学习者的历史课程记录，不等于 2026 年仍开放或学院实体课程的统一制度。

## 讲授摘要（证据层）

官方讲解页把第一品概括为“清净心—清净土”的修心主题；第二品强调在家生活中也可以修法，不能因身份而轻视在家修行者；第三至第五品以佛弟子、菩萨和文殊探访维摩诘的对话展开。页面还列出第九品“不二法门”、第十一品菩萨行和第十二品阿閦佛等章名，但没有为每一章提供完整原文、译本对照或课堂时间码。

这些摘要用于建立“作品—章节—讲授观点”索引，不把讲授者的解释写成跨传统唯一教义，也不把维摩诘的在家身份故事直接改写成学院招生、出家或身份路径规则。

来源：[WCDU：《维摩诘经》线上课程](https://khenposodargye.org/teachings/online-courses/the-vimalakirti-sutra/)（2019-04-14 续学说明） · [官方讲解页](https://www.khenposodargye.org/teachings/khenpos-classical-teachings/the-vimalakirti-sutra/)（2018-03-27 起讲、章节摘要与讲义／视频入口）。
