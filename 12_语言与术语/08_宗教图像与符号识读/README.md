## 八吉祥符号试样

公开馆藏和佛教资料将以下八项作为常见组合：法轮、宝伞、无尽结、右旋海螺、宝瓶、双鱼、胜利幢、莲花。史密森学会一件来自西藏中部、19至20世纪的鎏金铜制供具记录了这一组合，但具体象征解释和仪式使用要按传统、地区和物件语境分别核对。

本条只做识读入口，不把八吉祥的含义、排列方向或功德说法推广到所有藏传、汉传或民俗场景。
