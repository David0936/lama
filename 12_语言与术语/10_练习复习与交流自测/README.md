## R132｜基于已登记语料的最小自测

本页只复用本库已登记的公开教材词表、句型和远程音频入口；没有录制新音频，也不把练习成绩解释为色达／喇荣现场交流能力。

### 1. 词形与功能

不看答案，写出下列词的英文或汉文功能，再回到[300词场景词表](../03_300词场景词表/README.md)核对：

| 藏文 | 自测问题 | 答案定位 |
|---|---|---|
| མིང་ | 是“名字”还是“身体”？ | 30词试样第7项 |
| མཚན་ | 教材是否标为敬语？ | [敬语最小对照](../06_敬语称呼与语境/README.md) |
| ཆུ་ཚོད། | 用于询问什么？ | 词表第78项 |
| སང་ཉིན། | 是今天还是明天？ | 词表第100项 |

### 2. 场景句替换

从[基础句子与对话](../04_基础句子与对话/README.md)选择一张卡：D02（星期与课堂时间）、D04（次日自习）或D09（当前活动）。先识别问题类型，再只替换一个已经登记的时间、地点或活动词。替换后应回到原教材核对；不要把教材中的图书馆、住房或课表改写成学院的实际设施和作息。

### 3. 听音核对

可使用词表和句型卡已链接的 Michigan State University 远程 M4A 做“听到的教材词／句是否能对应表格”的核对。记录三项：音频链接、对应词／句编号、是否能辨认；不要把未核听的音频标为喇荣口音、真人认证发音或可再分发资源。
