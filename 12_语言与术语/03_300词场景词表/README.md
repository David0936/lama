# 300词场景词表

状态：配额与制作流程已设计，尚未生成已审校词表。

见[300词配额、场景与验收标准](../../docs/交流背景与藏语入门规划.md)。先30词与12句试样，再100词，最后300词、60句、12段对话；总词数不含句子，不重复统计译名和发音变体。

目标：称呼问候、自我介绍、说明语言水平、询问课程与地点、请重复和基础生活交流。背词数量不等同实际听说能力。
