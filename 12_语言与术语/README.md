# 12_语言与术语

状态：v0.4。已建立300词、60句与12段对话的公开教材入口；发音、目标地区口语变体及敬语实地适用性仍待核。

- [01_使用路线与发音标准](01_使用路线与发音标准/README.md)：从场景与语音入门；确定学习者目标口语变体、敬语和书面语范围，候选语料经本地或熟悉当地用语者核对。
- [02_藏汉英术语总表](02_藏汉英术语总表/README.md)：每个概念一个主档，列藏文、汉文、英语、释义、语境、异译、转写、发音和来源。
- [03_300词场景词表](03_300词场景词表/README.md)：首批300个去重的常用词条，按10类场景分配；详见词表规划。
- [04_基础句子与对话](04_基础句子与对话/README.md)：首批60句、12段短对话的设计目标；含自我介绍、请慢说、听不懂、问时间地点、请教与致谢。
- [05_藏语发音与真人音频](05_藏语发音与真人音频/README.md)：每个发音绑定具体词/句与口语变体，优先授权真人正常速度和慢速音频；没有核听不得标为正确示范。
- [06_敬语称呼与语境](06_敬语称呼与语境/README.md)：见老师、课堂提问、同学交流与生活服务的表达差别；已有教材标注的最小敬语对照，不外推为学院称呼规范。
- [07_藏文字母数字与标点](07_藏文字母数字与标点/README.md)：字母、组合、数字、分节点和句读符号的识读；拼写转写与实际发音分栏。
- [08_宗教图像与符号识读](08_宗教图像与符号识读/README.md)：常见宗教图像、手印、法物标志及图案的解释入口，关联06和08目录，注明传统和使用位置。
- [09_易混词异译与误听](09_易混词异译与误听/README.md)：同音近音、汉译差异、英语多义、不同口语变体和诵读音的差别。
- [10_练习复习与交流自测](10_练习复习与交流自测/README.md)：看词辨义、听音选义、替换造句、对话听答；用完成场景衡量能力，不凭背词数保证交流。
