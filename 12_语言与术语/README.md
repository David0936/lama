## R361｜藏语发音字段的四层区分

| 层次 | 记录内容 | 当前状态 |
|---|---|---|
| 藏文字形 | 原文、分词和拼写 | 可从公开教材或术语表登记 |
| Wylie | 规范化转写和异写 | 作为检索工具，不等于读音 |
| 教材音频 | 页面、直链、词／句对应、录音状态 | 可作跟读入口，方言和录音者待核 |
| 目标地区真人读音 | 正常／慢速录音、核听记录、敬语场景 | 尚未形成喇荣本地授权样本 |

因此，词条的“发音待核”不是缺少 Wylie，而是尚未完成目标地区真人核听。汉语近似读法不得替代藏文音频或母语者复核。

## R387｜语言学习材料的验收顺序

学习卡按“看得懂、读得出、听得辨、用得当”四步验收：

1. **文字层**：藏文、分词、汉文、英文和 Wylie 可相互定位。
2. **教材音频层**：音频链接、词／句对应、录音者或教材章节、时长和抽听状态已记录。
3. **语境层**：句子所属场景、敬语等级、对象关系和是否为教材虚构人物已标注。
4. **地方口语层**：由熟悉目标地区口语者核听后，才可标为“适合当地交流”；此前保持“公开教材工作稿”。

300 词、60 句和 12 段对话是资料覆盖目标，不是能力保证。教材提供的声音可以证明公开课程存在，不自动证明喇荣课堂、色达当地口音或现实交流中的自然表达。
