# 发音核验记录卡模板

| 字段 | 要求 |
|---|---|
| 词/句 ID | 对应 300 词或句型编号，避免同形重复 |
| 藏文与 Wylie | 保留教材拼写和项目转写，不以 Wylie 代替读音 |
| 说话者背景 | 地区、母语、年龄段或教学语境；经本人同意记录 |
| 录音内容 | 单词、自然句、敬语变体和慢速示范分别标记 |
| 音频链接与时间码 | 记录公开 URL、起止时间和文件版本 |
| 发音状态 | 待核、单一示范、多个变体、已母语者复核 |
| 使用范围 | 课堂、日常、宗教语境或地区限制 |
| 许可与隐私 | 发布许可、署名、撤回方式和访问条件 |

汉语近似读法只作学习辅助，不能替代音频。没有母语者或可靠教材音频时，保持“待核”，不把机器合成音频标作真人发音。
