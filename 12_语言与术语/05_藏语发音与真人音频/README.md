# 05_藏语发音与真人音频

每个发音绑定具体词/句与口语变体，优先授权真人正常速度和慢速音频；没有核听不得标为正确示范。

交付时逐项附来源、适用范围与核查状态。目前仅为收录计划。

R015 试样暂没有学院教师或目标地区母语者授权录音，因此所有词句的“发音”字段保持待核；公开教材附带的音频只能作为教材示范，不能自动标为喇荣口音。

## 已发现的公开音频入口

- [Michigan State University Basic Tibetan greetings vocabulary audio](https://openbooks.lib.msu.edu/app/uploads/sites/128/2024/10/AUDIO_Greetings-1.2-vocabulary.m4a)：与公开教材第 4.2 节词表配套，可用于逐词跟读和教材版本核对。
- 当前未知：录音者、录音地点、目标方言、是否包含慢速版本，以及与色达／喇荣口语的差异。
- 使用规则：只登记远程音频链接，不下载或再分发；没有母语者比对前，R015 的发音字段仍保持 `待核`。

## R186｜教材音频的三类入口

本批把三个代表性音频加入媒体索引，分别对应问候词、课堂物品词和课堂日程对话：

| 媒体 | 教材层级 | 可支持 | 不能支持 |
|---|---|---|---|
| Greetings vocabulary | 词表逐词音频 | 教材词条的跟读入口 | 色达／喇荣口音、录音者身份或慢速读法 |
| Classroom vocabulary 1 | 课堂物品词汇 | 词汇与音频入口的对应关系 | 佛学院课堂真实用语或现场发音 |
| Chapter 10 Dialogue | 日程对话 | 教材对话的听力入口 | 学院实际作息、课程安排或学习者交流能力 |

媒体记录见 `M-R186-001`—`M-R186-003`。本批不下载、不剪辑、不重新托管音频；未完成逐音节核听，发音字段继续保持“待核”。

## R259｜9句课堂沟通音频入口

Michigan State University Basic Tibetan 2.1 页面列出 9 句频用表达，并提供同页教材音频：

| 藏文 | 汉译 | 用途 |
| --- | --- | --- |
| བཞུགས་དང་། | 请坐 | 接待、课堂 |
| ཐུགས་རྗེ་ཆེ། | 谢谢 | 致谢 |
| གའི་གནང་གི་མ་རེད། | 不客气 | 回应致谢 |
| ལ་སོ་ལ་སོ། | 好、好的 | 简短回应 |
| ངས་ཤེས་མ་སོང་། | 我没听懂 | 课堂澄清 |
| ཡང་བསྐྱར་གསུངས་དང་། | 请再说一遍 | 请求重复 |
| ག་ལེར་གསུངས་དང་། | 请慢一点说 | 请求放慢 |
| ཤེས་སོང་ངམ། | 听懂了吗 | 确认理解 |
| ངས་ཤེས་སོང་། | 我听懂了 | 回应确认 |

音频入口：[教材页面](https://openbooks.lib.msu.edu/basictibetan/chapter/2-1/) · [Frequent Expression 2.m4a](https://openbooks.lib.msu.edu/app/uploads/sites/128/2024/11/Frequent-Expression-2.m4a)。

边界：这是公开教材示范音频。页面未提供喇荣教师、录音者身份、地区口音或慢速版本证据；不把它写成喇荣标准音。逐音节核听、Wylie 与真人口音对照仍待核。
