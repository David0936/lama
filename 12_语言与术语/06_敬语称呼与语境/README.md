# 06_敬语称呼与语境

见老师、课堂提问、同学交流与生活服务的表达差别；避免只有礼貌词而没有可理解的完整句子。

交付时逐项附来源、适用范围与核查状态。

## R126｜教材标注的最小敬语对照

Michigan State University 的公开《Basic Tibetan》4.2 词表，将下列两组分别标为普通词与 `Honorific` 词。该表同时提供配套教材音频，但未将其标为色达、喇荣或任一学院的口语示范。

| 功能 | 普通词 | 教材标为敬语的词 | 教材英文义 | Wylie | 记录边界 |
|---|---|---|---|---|---|
| 名字 | མིང་ | མཚན་ | name / name (h) | ming / mtshan | 只确认教材的词类标注；实际称呼、搭配和对象待目标口语者核对。 |
| 身体 | གཟུགས་པོ་ | སྐུ་གཟུགས་ | body / body (h) | gzugs po / sku gzugs | 不把词表对照延伸为疾病问候、宗教称谓或仪式用语。 |

教材还列出 `ག་ལེར་བཞུགས།`（Stay well）与 `ག་ལེར་ཕེབས།`（Go well）两条告别表达；本项目只把它们作为后续核对的候选，不自行判定敬语等级、语法条件或面对不同对象时的适用范围。

来源：[Basic Tibetan 4.2 Vocabulary](https://openbooks.lib.msu.edu/basictibetan/chapter/4-2/)（词表第10、15—19项；页面列配套音频并标注 CC BY-NC 4.0）。

## 待核

- 色达／喇荣语境中的称呼、回话、敬语级别与跨代／师生关系差异。
- 教材音频的口语变体、录音者和与本项目目标地区的差异。
- 宗教称谓、僧团称谓与日常敬语的边界；不得以一组词表取代传承内称谓规范。
