# 法会记录卡模板

用于把公开节历、寺院公告、讲记和视频分开记录。

| 字段 | 说明 |
|---|---|
| 活动名称 | 保留原文题名与异译 |
| 主体 | 学院、寺院、社区、个人或平台；无机构证据不写“主办” |
| 地点与日期 | 藏历、公历、换算来源和日期精度分别记录 |
| 活动类型 | 法会、教学、共修、节庆、纪念或线上活动 |
| 公开证据 | 公告、讲义、视频、照片、新闻或口述；附定位 |
| 参与范围 | 仅在来源明确时填写公开对象与限制 |
| 当前性 | 历史样本、当年活动、持续传统或现行公告 |
| 未解决问题 | 场次、仪轨全文、资格、传承和日期换算冲突 |

记录卡只描述公开证据，不把历史活动改写成当前日程，不把个人上传改写为学院正式活动。
