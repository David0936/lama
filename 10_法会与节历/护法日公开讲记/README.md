# 护法日公开讲记

## R070 节历与传说入口

索达吉堪布官网公开 PDF《维摩诘经》第三品第 1421 讲的导言提到，讲授当日翌日为喇荣“护法日”，并以藏历六月二十六日为年度供养护法的日期。讲记随后叙述敦珠林巴（Dudjom Lingpa）与喇荣地方护法的传说及立约故事。

本条把“讲记中的节历说法”和“传统叙事”分开：它不等于学院 2026 年法会公告，也不证明所有地区或宁玛寺院都采用同一日期。传说中的神祇、地点和事件须与其他传承文本及学院公告分栏核对。

来源：[The Vimalakirti Sutra—Chapter 3, Lecture 1421（PDF）](https://khenposodargye.org/content/uploads/2019/07/The_Vimalakirti_Sutra-Chapter-3-Lecture1421.pdf)。
