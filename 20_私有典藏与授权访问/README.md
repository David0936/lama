# 私有典藏与老师授权访问

适用阶段：未来可能上架软件或网页时再考虑。当前公开资料库不启用本页授权、分级或加密要求。

状态：v0.5设计预留。此目录仅存规范，不能作为存放机密经文的保险箱；尚无运行中的权限或加密系统。

- [01_内容分级与老师审定](01_内容分级与老师审定/README.md)：资料的阅读范围由有权限的老师或指定管理者审定；公开来源不自动成为公开展示内容。
- [02_师生身份与加入退出](02_师生身份与加入退出/README.md)：身份核验、邀请、加入、停用、离院与重新核验；系统账号不等于修学资格。
- [03_老师授权与权限范围](03_老师授权与权限范围/README.md)：按人、班组、文献版本、操作和期限授权，可撤销；授予权限不能超出授权者自身管理范围。
- [04_本地机密经文接入](04_本地机密经文接入/README.md)：原件进入仓库外的加密保管区；导入、OCR、整理和审校都在允许的处理环境中进行。
- [05_加密存储与密钥管理](05_加密存储与密钥管理/README.md)：预留成熟加密存储、独立密钥管理、轮换与恢复；本轮不创建密钥或声称已经加密。
- [06_阅读搜索与音视频权限](06_阅读搜索与音视频权限/README.md)：正文、标题、摘要、搜索、图谱、预览和音视频统一鉴权。
- [07_AI处理与派生资料](07_AI处理与派生资料/README.md)：本地受限资料默认禁止外发模型；摘要、译文、OCR、向量及语音继承来源限制。
- [08_审计备份与撤销](08_审计备份与撤销/README.md)：授权、访问与导出记录；加密备份、恢复核验与撤销后的缓存处理。
- [09_公开资料迁移与发布边界](09_公开资料迁移与发布边界/README.md)：现有公开内容与新增机密内容分别处置，私有化不能收回已经分发的副本。

## R365｜当前公开阶段的边界

本仓库当前只处理公开网络资料：公开网页、公开 PDF、公开馆藏目录和公开音视频入口。未来若取得老师授权的本地经文、内部讲义或受限音频，必须在仓库外的受控环境中单独接入，并记录授权主体、范围、期限、处理方式和撤销条件。

本页不接收机密原件、密钥、账号、验证码或未授权 OCR；“预留目录”不等于已经部署权限、加密、审计或私有化系统。
