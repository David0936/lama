# 公开媒体索引模板

| 字段 | 要求 |
|---|---|
| 媒体 ID | 唯一且稳定 |
| 类型 | 念诵、讲解、法会实录、课程或访谈 |
| 作品/活动 | 关联经典版本或法会记录卡；未知则留空 |
| 发布主体 | 机构、寺院、讲者、平台或个人 |
| URL 与平台 | YouTube、官网、SoundCloud 等公开入口 |
| 时间码 | 起止时间；整段才写完整 |
| 语言与字幕 | 藏文、汉文、英文、转写或无字幕 |
| 发布日期与核查日期 | 分开记录，避免把访问时间当发布日期 |
| 版权/访问状态 | 公开、登录、地区限制、下架或待核 |

媒体标题、缩略图和自动字幕只能提供线索；学院主办、传承归属和仪轨完整性必须由页面正文、讲者或机构证据支持。
