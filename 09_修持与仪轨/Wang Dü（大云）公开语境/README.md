# Wang Dü（大云）公开语境

## R068 官网叙述卡

索达吉堪布官网的 [Wang Dü: The Great Cloud of Blessings](https://khenposodargye.org/teachings/khenpos-classical-teachings/wang-du-great-cloud-blessings/) 页面称，Wang Dü 是喇荣重视的法门；页面叙述每次讲法和辅导开始前念诵三遍，后来增加到每天五遍，并提到为僧众念诵作供养。页面同时提供带英文同传的音频入口。

这些句子是官网对传统与学院实践的公开叙述，不等于 2026 年全院统一课表。页面没有给出音频时长、现场录音日期、完整仪轨文本或参加资格，因此本项目只登记媒体入口和叙述范围，不提供修法步骤。
