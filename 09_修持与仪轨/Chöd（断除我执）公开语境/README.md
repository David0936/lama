# Chöd（断除我执）公开语境

## 公开来源入口

大英博物馆将 Chöd（页面英文写作 **Chöd**，并解释为 “Cutting Through the Ego”）与藏传佛教人体材料法器放在同一展览语境中。馆藏对象页把一支西藏人股骨号角 **kangling**（馆藏号 **2016,3040.2**）描述为 Chöd 仪式使用的法器，并提到双面鼓、号角和“观想的身体分解”在馆方说明中的关系。

来源：[British Museum Kangling 2016,3040.2](https://www.britishmuseum.org/collection/object/A_2016-3040-2)

大英博物馆 Tantra 展览页另设 **The Chöd ritual and human remains** 栏目，列出藏传僧人 Lama Rinzin 的删节版仪式录音，以及研究藏族人体遗存的学者 Ayesha Fuentes 的评论和文字稿入口。页面同时提醒，人体材料专题还包含藏人社区成员的个人视角。这里记录的是博物馆策展、仪式录音和访谈的分层，不把它们拼成一套普遍适用的修法说明。

来源：[Tantra content（British Museum）](https://www.britishmuseum.org/tantra-content)

## 阅读边界

- **可核**：馆藏号、材料字段、馆方对 Chöd 的英文释义、展览栏目、录音／文字稿入口。
- **不可由此推出**：灌顶资格、完整仪轨次第、咒语全文、特定学院法会安排或个人修行建议。
- 馆方“观想的身体分解”等说明属于公共展览语境；应与传统文本、师承口传和当代社区解释分栏记录。
- 本页不下载或重发布音频，不复制文字稿全文；后续只登记时间码和短引用。

## R200：术语与跨传统传承语境

FPMT 的公开教法文章把 Chöd 解释为“cut off”或“slay”，并将其公开教法重点放在切断自我珍爱以及对“实有我”的执著。这里记录的是面向公众的解释，不等同于完整仪轨、口传或灌顶内容。

FPMT 的一篇公开采访以 Machig Labdron、Padampa Sangye 和 Ganden Chöd 的叙事说明其传承语境，并提到 Chöd 在宁玛、噶举等传统中出现、在格鲁语境中有不同的公开程度。该段属于受访者及其所属语境的陈述，不能据此拼成所有传承共有的单一谱系，也不能推导喇荣学院现行法会或个人资格。

同一机构的 2007 年公开 PDF 称部分参考文献写作 **gCod**。这只作为拼写线索登记；藏文 Unicode、Wylie 规范、地区发音及不同传承的写法仍待藏文原文和词典核对。

公开解释、传承叙述、灌顶／传承要求和闭关资格分开记录。采访中提到的 initiation、transmission 或特定 retreat prerequisite 只代表该采访的课程语境，不构成一般入门流程。

来源审计：[R200-Chöd术语与传承语境](../../91_待办与审校/R200-Chöd术语与传承语境.md)。
