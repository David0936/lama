# 经典、仪轨与音视频证据标准

本页规定后续资料如何进入百科，避免把经文、仪轨、讲解和法会录像混成同一种证据。

| 类型 | 最低登记字段 | 可支持的结论 |
|---|---|---|
| 经典 PDF | 题名、译者/传统、版本、页数、文件校验值、公开链接 | 文件入口与版本存在 |
| 仪轨文本 | 仪轨名、传承/适用语境、版本、授权状态、章节定位 | 文本内容与出处 |
| 念诵音频 | 发布者、曲目、时长、起止时间、平台链接 | 音频确实包含所标内容 |
| 讲解视频 | 讲者、日期、平台、起止时间、字幕/转写状态 | 讲者在该时间段的公开说法 |
| 法会实录 | 主办/地点/日期、视频时间码、画面与文字证据 | 公开记录中的活动事实 |

## 不得直接推出

- 公开上传不等于获得灌顶、口传或修持资格。
- 视频标题不等于学院正式主办或认可。
- 一段念诵音频不等于完整仪轨，也不自动证明语言版本或传承归属。
- 受限文本只记录书目、访问条件和核验状态，不复制未获授权的正文。

后续每条媒体记录应写入 `90_资料目录/media.jsonl`，并把时间码、来源和转写状态作为可复核字段。
