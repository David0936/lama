# 曼荼罗与灌顶：博物馆教育性背景

## 曼荼罗的公开解释

史密森尼弗里尔与赛克勒馆的术语页说明，曼荼罗（mandala）可由同心圆、方形宫殿和中心尊格构成；在灌顶仪式中，它被描述为引导学习者认识尊格和观想的工具。该说明是博物馆教育性材料，不是某一寺院的仪轨手册。

来源：[Smithsonian Sacred Spaces：mandala](https://asia.si.edu/interactives/sacred-spaces/key-terms.html#mandala)。

## 修持与证据边界

- **公开图像学**：记录形制、中心尊格和馆方说明。
- **仪轨文本**：需要具体续部、仪轨、灌顶仪轨和传承版本支持。
- **实际资格**：是否需要灌顶、口传或指导，不能由博物馆页面判断。
- **学院关联**：喇荣实际使用的曼荼罗、法会和灌顶安排必须另找机构级来源。
