# 02_决策协调与制度变化

谁负责哪些事项，规则怎样公布与变化；区分宗教传统、学院安排与外部制度。

## 公开记录中的决策接口

目前能核对的材料是事件记录，不是学院组织章程：

- 2014年四川省政府考察报道把喇荣寺五明佛学院及管理局列为考察点，并记录围绕依法管理、规划建设、消防安全、功能分区和周边建筑隐患的交流。它能说明省级公开行政活动曾把这些事项列为管理议题，不能证明今天仍由同一机构、同一岗位负责。
- 2021年色达县政府消防会议材料把县级部门、学院党委、喇荣寺管理委员会、洛若镇党委和政府、阿交社区管委会及僧人义务消防队列为安全协作主体。它能说明一次县域安全治理的协作接口，不能替代学院内部决策流程、教学管理或宗教职务名单。

后续记录按“决策事项—公开发布主体—参与单位—日期—可确认范围—不可推断项”建卡；同一单位在不同年份的称谓和职责必须逐次核对。
