# 学院日常运转记录卡模板

| 字段 | 要求 |
|---|---|
| 运转事项 | 住宿、饮食、供养、医疗、交通、清洁、通信或安全 |
| 负责主体 | 学院部门、寺院、社区、志愿者、供应商或未说明 |
| 适用对象 | 僧尼、在家学习者、访客或未说明 |
| 时间范围 | 记录发布日期、实施日期和是否仍有效 |
| 公开规则 | 原文链接、章节或公告定位；没有规则就写“未找到” |
| 个案材料 | 单独标为个人叙述、新闻或田野观察，不外推全院 |
| 空间关联 | 仅链接已核建筑/功能区，不从照片猜用途 |
| 当前性 | 现行公告、历史样本、持续传统或待核 |
| 缺口与冲突 | 费用、资格、服务时间、变更和不同来源冲突 |

供养者叙述、旅行攻略和个人经验可作为线索，不能单独证明学院统一的住宿、收费、饮食或医疗制度。
