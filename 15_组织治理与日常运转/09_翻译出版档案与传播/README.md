## R067 公开版本与数字入口

学院关联官网的《A Journey to the West》作品页列出藏文、英文、繁体中文版本（各两册）和公开讲解入口；这可作为“原文／译本／讲解媒体”分层的版本登记样本。页面没有给出完整出版者、底本校勘、授权条款或逐段对照，因此不能把语言入口写成等值的批校本。

版本关系见 [法王1993年海外讲法整理本](../../04_经典与文献/法王1993年海外讲法整理本_A_Journey_to_the_West/README.md)。
