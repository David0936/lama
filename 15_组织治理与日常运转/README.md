# 15_组织治理与日常运转

状态：v0.3。已加入研究时期作息、供水规划和供养叙述的证据矩阵；以下不代表已核实本院现行制度。

- [01_组织角色与职责](01_组织角色与职责/README.md)：宗教指导、教学、行政与后勤的职责及任期；没有组织图时不虚构科层结构。
- [02_决策协调与制度变化](02_决策协调与制度变化/README.md)：谁负责哪些事项，规则怎样公布与变化；区分宗教传统、学院安排与外部制度。
- [03_僧尼在家者与志愿协作](03_僧尼在家者与志愿协作/README.md)：不同群体如何参与，称谓、职责与历史时期。
- [04_一天一周与一年](04_一天一周与一年/README.md)：作息、课程与法会节律，提供具体日期的观察案例，不冒充统一时间表。
- [05_住宿饮食供水与生活服务](05_住宿饮食供水与生活服务/README.md)：研究住居安排、饮食、能源、供水与卫生等已公开信息。
- [06_供养经费与物资](06_供养经费与物资/README.md)：公开供养方式、经费和物资运转来源；无公开数据时不推测金额或个人收入。
- [07_医疗消防与应急服务](07_医疗消防与应急服务/README.md)：公开服务点与历史建设信息；现行求助渠道须实时核验，设计阶段不提供未核实号码。
- [08_规约礼仪与纠纷处理](08_规约礼仪与纠纷处理/README.md)：公开规约、来访礼仪及可证实的处理机制；地区习俗和本院规定分别标识。
- [09_翻译出版档案与传播](09_翻译出版档案与传播/README.md)：教言如何记录、翻译、出版、数字化与传播，关联原文和媒体登记。
- [10_周边社区与社会联系](10_周边社区与社会联系/README.md)：学院与周边居民、地方服务和跨地区学习网络的关系，保留时间背景。

## R350｜日常运转证据矩阵

| 资料层 | 可以回答 | 不能回答 |
|---|---|---|
| 研究时期田野／论文 | 某一项目的作息、教学分工、假期和生活观察 | 全院统一作息、当前宿舍和服务规则 |
| 政府规划或公共工程页 | 某一时期的供水、消防或区域建设计划 | 工程是否完成、学院当前覆盖和服务质量 |
| 学院关联公开教言／课诵本 | 公开版本、修持叙述与供养语境 | 财务金额、捐赠名册、现行预算和个人收入 |
| 当前公告／服务文件 | 只有在带日期且主体明确时，才能支持当前安排 | 用旧页面拼出今天的制度 |

外来者阅读时，应把“住在哪里、吃什么、如何供水、怎样供养、谁负责服务”拆成独立问题；缺少对应文件时保留“公开资料未核实”，不从照片、旅行文章或个人经历补全。
