## R148 研究时期堪姆项目的日程案例

Liang 与 Taylor 的同行评议论文基于 2017—2019 年研究材料，给出堪姆学生在学期中的一份“大致”日程：

| 时间 | 论文所述活动 |
|---|---|
| 04:00 | 起床 |
| 04:00–08:00 | 禅修、念诵；论文还提到念诵可能构成部分尼众的收入来源 |
| 08:00–11:00 | 上午课程，由大经堂的堪布或主要堪姆／堪布教师授课 |
| 11:00–13:00 | 休息、午餐及下午课准备 |
| 13:00–15:00 | 下午课程，通常由教学助理讲解或延伸上午内容 |
| 15:00–15:30 | 休息 |
| 15:30–17:30 | 教学助理课程 |
| 17:30 以后 | 正式课程结束；晚间用于自学、作业和禅修 |
| 23:00 | 熄灯；准备最终考试者可能学习到更晚 |

论文还称一月、二月有两个月的新年假期，多数学生返乡；课堂通常围绕教师共同阅读注释，根本文本在课外背诵。以上是特定教育项目和研究时期的描述，不能写成全院所有僧尼、在家者或 2026 年的统一作息，也不能由此推断住宿、餐食和当前念诵安排。

来源：[Liang & Taylor, *Tilling the Fields of Merit*](https://blogs.dickinson.edu/buddhistethics/files/2020/08/Liang-and-Taylor__20_F-1.pdf)，PDF 印刷页 245—246。
