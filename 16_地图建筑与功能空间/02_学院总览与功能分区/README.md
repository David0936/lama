# 02_学院总览与功能分区

以有日期的底图与来源标识教学、宗教活动、居住、生活服务及交通空间；这些是待核分类，不预设每区实际存在。

## 公开资料中的功能线索（候选，不等于现行平面）

公开讲座和地图/旅行资料反复出现“山谷底部的经堂、山坡居住区、山顶坛城或转经空间”等描述；这些材料的年代、拍摄点和术语并不统一，因此本目录只把它们作为待核功能分类。一个公开讲座还提到僧众与尼众居住区及经堂出入口的区分，但没有提供可供复核的现行总平面图（见 [A Journey to the West](https://www.khenposodargye.org/books/a-journey-to-the-west/)）。

| 功能层 | 当前登记 | 证据状态 |
| --- | --- | --- |
| 教学与诵经 | 大经堂、汉经堂、觉姆经堂作为公开地图资料中的建筑候选 | 待核，未确认现名与现行用途 |
| 居住 | 山坡密集居住单元作为影像线索 | 待核，不据照片统计数量 |
| 礼仪与巡礼 | 山顶坛城／转经空间作为二手地图线索 | 待核，需区分坛城、佛塔和转经道 |
| 生活服务与交通 | 消防、供水等服务见组织治理批次；道路和商贸功能尚缺一手总图 | 部分已登记，空间位置待核 |

地图卡应同时记录“反映时期”“底图来源”“精度”“许可”和“无法确认项”。
