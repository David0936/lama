## R205：公开到达入口的证据分层

当前可给外来者的地图信息只有三个层次，不能合并成一条“官方步行路线”：

| 层次 | 公开入口 | 可支持 | 不能推出 |
|---|---|---|---|
| 区域锚点 | [KMaps Feature 5224](https://places.kmaps.virginia.edu/features/5224) | Larung Gar 名称、区域级点位和 GIS 资源入口 | 学院大门、边界、建筑位置或当前道路 |
| 导航参考 | [高德地点页](https://www.amap.com/place/B034400YZ4) | “洛若镇喇荣沟”公众检索点与导航入口 | 官方入口、停车点、步行时长、开放时间或安全条件 |
| 行政区域描述 | [色达县区域介绍](https://www.gzzsdxrmzf.gov.cn/seda/c103068/202005/164592834550404f96cbd78c34470c27.shtml) | 洛若镇、喇荣沟和山谷建筑群的文字背景 | 当前道路通行、接驳安排、建筑编号或无障碍设施 |

KMaps 点位为 `32.153269, 100.466955`，高德检索点约为 `32.150521, 100.472477`。两者存在数百米级差异，可能来自要素中心点、导航检索点或底图时期；本库不裁定哪一个是“大门”。KMaps 的 KML、GML、Shapefile 端点尚未取得可解析几何，因此暂不生成步行线、道路面或建筑位置图。

对外来者的路线卡必须另有带日期的官方公告或现场记录，至少写明出发点、交通方式、接驳／步行段、反映日期、许可和无法确认项。来源审计：[R205-公开到达入口证据层](../../91_待办与审校/R205-公开到达入口证据层.md)。
