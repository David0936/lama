# 09_地图来源与图层说明

底图许可、坐标系、精度、来源与更新时间；概念示意不作为实测地图。

## R061 图层使用规则

- **GIS 要素层**：KMaps 页面公开 GML、KML、Shapefile 资源，可作为后续下载、坐标系和版本日期的登记入口；在未核对文件元数据前，不宣称边界精度或许可范围。
- **行政描述层**：色达县政府页面用于记录海拔、沟域和建筑面积的文字口径；这是行政宣传资料，不替代测绘成果。
- **导航检索层**：高德地图只作公众到达与名称检索入口。其坐标与 KMaps 不一致时并列保留，不强行平均或裁定“真实点位”。
- **影像与照片层**：必须注明拍摄／底图时期、方向和来源；不能从航拍或照片推断内部平面、房间用途、人员数量或当前管理边界。

## R109 下载端点复核

KMaps Feature 5224 页面目前列有 KML、GML、Shapefile 链接。2026-09-14 对其 KML 直链的读取返回空响应，未得到可解析 XML 或任何几何要素。故当前状态是“**页面列出 GIS 资源；本库未取得有效几何文件**”。后续重试时须记录响应日期、文件字节数、坐标系、几何类型、许可和版本；只有取得并核对文件后才可建立点、线或面图层。

地图卡最低字段：来源 URL、访问日期、反映时期、坐标系（若有）、精度级别、许可／使用限制、可确认内容、不可确认内容和复核人。当前 R061 尚未下载 GIS 文件，也未建立可发布的边界图层。
