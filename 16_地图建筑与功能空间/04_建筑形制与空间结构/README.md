## R225 现场叙事中的构造线索（2017）

一篇 2017 年建筑旅行研究文章把喇荣住屋描述为一至两层的组合：陡坡下部以石或砖砌墙形成平整基座，上部为木构住屋；部分基座层被作者理解为储藏空间，屋顶可见土和金属板。文章还写到建筑沿盆地环状排列并朝向中心。这里的“一至两层”“储藏空间”和“木构适应高寒环境”等属于现场观察或作者解释，不是测绘图纸、建筑规范或学院正式说明。

因此本条只为建筑类型研究保留材料、层数和空间朝向的候选字段；没有内部照片、结构图和同期测绘时，不建立房间级关系，不确认每座建筑均符合该描述。

来源：[Window Research Institute：The Red Earthenware Bowl: Eastern Tibet, Ser thar, Part 2](https://madoken.jp/en/series/3834/)（2017-12-07；正文第 60—73 行）。
