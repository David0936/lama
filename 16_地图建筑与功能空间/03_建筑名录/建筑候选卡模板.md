# 建筑候选卡模板

用于公开地图、旅行资料、照片或讲义出现建筑名称时的初步登记。

| 字段 | 要求 |
|---|---|
| 候选 ID | 保持唯一，不与已证实建筑共用编号 |
| 原名称 | 保留来源原文、语言和异译 |
| 来源时期 | 标记照片/地图/文章的拍摄或刊载时间 |
| 功能线索 | 只抄录来源明确描述，不从外观猜用途 |
| 空间精度 | 区域、入口、建筑点位或未知 |
| 当前性 | 历史记录、当年记录、持续传统或待核 |
| 交叉核验 | 学院公告、官方地图、同期影像、馆图或 GIS |
| 未解决问题 | 正式名称、坐标、改建、开放范围和当前功能 |

照片和旅行攻略只能产生候选卡；没有学院清单、带日期地图或可靠文字定位时，不升级为已证实建筑。
