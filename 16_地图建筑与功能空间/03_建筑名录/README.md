# 03_建筑名录

每座已证实建筑有主档，含名称、用途、时期、图像与位置精度。

## 后续交付

以来源支持的概述、具体案例或资料卡回答本专题；每条说明适用机构、时期、群体及核查状态。事实未查到时登记缺口，不生成默认答案。

## 首批公共建筑候选卡

以下名称来自公开地图、旅行资料或二手概述，只用于建立核查队列。没有学院发布的建筑清单、带日期平面图或现场文字定位前，不把候选卡写成“已证实建筑”。

### 大经堂（Great Sutra Hall）— B000001

- 候选依据：公开地图/旅行资料把山谷底部的大型经堂称为 Great Sutra Hall 或类似译名。
- 当前状态：`review_required`；中文正式名称、建造/改建时间、坐标、当前功能均待核。
- 不确定项：不能仅凭照片判断是否仍使用、是否与其他经堂为同一建筑。

### 汉经堂（Han Sutra Hall）— B000002

- 候选依据：二手公开概述将其列为谷底经堂之一。
- 当前状态：`review_required`；汉文名称、服务对象和现行功能均待学院或可靠图录核对。

### 觉姆经堂（Nuns’ Sutra Hall）— B000003

- 候选依据：二手公开概述将其列为尼众经堂候选名称；公开讲座支持僧众与尼众空间存在区分，但未提供现行建筑名录。
- 当前状态：`review_required`；不据“觉姆”称谓推断行政归属、开放范围或当前使用情况。

### 山顶坛城／转经空间— B000004

- 候选依据：公开全景和旅行资料中的山顶几何构筑物线索。
- 当前状态：`review_required`；“坛城”“佛塔”“转经道”等名称尚未消歧，暂不建立确定建筑关系。
