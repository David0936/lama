# 16_地图建筑与功能空间

状态：v0.2 框架扩编。以下是待研究问题与收录边界，不代表已核实本院现行制度。

- [01_区域位置与地形](01_区域位置与地形/README.md)：区域定位、山谷与地形、地名异译；地理位置与机构边界分开。已加入 R061 公开位置卡。
- [02_学院总览与功能分区](02_学院总览与功能分区/README.md)：以有日期的底图与来源标识教学、宗教活动、居住、生活服务及交通空间；这些是待核分类，不预设每区实际存在。
- [03_建筑名录](03_建筑名录/README.md)：每座已证实建筑有主档，含名称、用途、时期、图像与位置精度。
- [04_建筑形制与空间结构](04_建筑形制与空间结构/README.md)：公开立面、屋顶、材料、层数和室内空间；结构图、平面图与示意图分别标识，无图纸不得从照片猜内部结构。
- [05_教学宗教与生活空间](05_教学宗教与生活空间/README.md)：解释公开可证实空间在学习、仪轨、居住中的用途，并链接建筑主档，避免重复建档。
- [06_道路步行与公共到达](06_道路步行与公共到达/README.md)：公开道路、入口与交通节点；地图存在道路不代表当下可通行。
- [07_历史地图与建设变迁](07_历史地图与建设变迁/README.md)：不同年份地图、影像与建筑变化，保留旧名称和功能沿革。
- [08_照片全景与视频导览](08_照片全景与视频导览/README.md)：收录公开影像、拍摄时点、拍摄方向与建筑关联；不以下载时间代替拍摄时间。
- [09_地图来源与图层说明](09_地图来源与图层说明/README.md)：底图许可、坐标系、精度、来源与更新时间；概念示意不作为实测地图。已加入 R061 图层使用规则。
