# 天葬专题：公开资料核验模板

本模板用于后续逐条收录，不预设所有地区、时代或家庭都采用同一做法。

## 必填字段

| 字段 | 记录要求 |
|---|---|
| 地区与群体 | 县域/社区、族群或寺院语境；不只写“藏区” |
| 时间 | 事件或记录年代；区分历史材料与当代报道 |
| 来源类型 | 田野研究、地方志、寺院说明、新闻、影像、口述或博物馆记录 |
| 参与角色 | 家属、僧侣、天葬师、管理者等；仅在来源明确时填写 |
| 观念与叙事 | 区分佛教教义解释、地方习俗和个人说法 |
| 过程描述 | 只抄录来源支持的步骤；不从照片或标题补全 |
| 当代变化 | 法规、卫生、旅游、城市化或社区实践变化，逐项给来源 |
| 未知项 | 明确未找到或存在冲突的字段 |

## 表述规则

- “天葬”是研究对象名称，不自动等于学院制度或某一教派专属仪轨。
- 公开报道中的个案只能证明该个案，不外推为全体藏族。
- 涉及遗体、现场影像或家属隐私时，优先登记文字来源和访问条件，不复制敏感影像。
