# 06_天葬

明确收录：名称、观念、参与角色、历史与地方差异、公开记录及当代变化；资料不足时不编造统一流程。

正文须附地区、时期、出处、证据性质及未知项。

## 首批公开记录

“天葬”在藏文研究中常以 *jhator*（སྦྱིན་གཏོང，常见转写为 *bya gtor*）等名称出现，但不同地区、时期和记录者的译法并不一致。公开馆藏记录显示，20世纪初拉萨地区的照片材料涉及遗体运往处置地点及相关人员；另一件英国博物馆影像记录了 Reting 地点的公开描述。它们是具体地点和时期的记录，不代表所有藏区或今天的统一流程。

学术资料指出，印度、尼泊尔和中国藏区的天葬实践存在变化，研究应区分地方、时代、参与角色和制度环境。天葬与藏传佛教的无常、布施等观念常被联系讨论，但宗教解释、生态条件和社会制度不能互相替代。

## 证据边界

- 本专题不记录具体遗体影像，不提供前往处置地点的路线，也不把猎奇叙述当作仪式说明。
- 尚无公开证据证明喇荣学院组织天葬或拥有统一天葬规约；学院周边习俗须另有来源。
- 后续需补充当事人／地方社区自述、法规和当代变化资料。
