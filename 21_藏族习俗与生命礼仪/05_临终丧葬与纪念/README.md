# 05_临终丧葬与纪念

研究生命观、临终照护、悼念与纪念活动，区分教义、仪轨和地方实践。

正文须附地区、时期、出处、证据性质及未知项。

## R125｜从葬俗类型到临终与纪念的记录边界

Smithsonian Research Repository 收录的 Chandra L. Reedy 研究，将藏区历史材料中的天葬、土葬、水葬、塔葬、火葬及少量遗体保存并列讨论；摘要也区分完整遗体、骨骸或火化遗存、衣物与接触遗物。该文可作为“遗体处置／遗物／纪念”三类材料的研究入口。

本目录只据此建立分类和检索边界，**不**从摘要补写临终照护、悼念程序、念诵内容、遗物来源或任何地区的当代选择。涉及某一家庭、寺院、学院或个别法物时，仍需补充带地区、时期和证据定位的社区材料、仪轨文本或馆藏记录；其中“进入装藏或开光语境”也只是研究摘要所说的可能情形，不能倒推为单件器物的材料鉴定。

来源：[Smithsonian Research Repository｜Body Relics in Tibetan and Mongolian Traditions](https://repository.si.edu/server/api/core/bitstreams/09ce017d-c2db-4f1b-a816-4524554f6ea3/content)。本批未取得或逐页核验 PDF，故暂不作段落级转述。

## 待核

- 与临终陪伴、悼念、纪念有关的公开社区自述或学术田野资料。
- 各类型在何地、何时、由谁选择；不得把比较研究的类型表改写为统一流程。
- 遗物与法物的单件材料、来源履历和宗教语境；先看馆方字段或检测资料。
