# 09_禁忌象征与口述传统

记录谁在何处如何解释；口述与历史事实分栏，保留异说。

正文须附地区、时期、出处、证据性质及未知项。

## R134｜概述页中的禁忌清单，不是通行规则

西藏自治区外事办公室的《藏族民俗概述》以列表形式列出若干禁忌，其中一项是“外人不能当着已故人的亲属的面提已故人的名字”。该页面没有为每一项标注地区、群体、年代、家庭实践或宗教依据，因此本库只把它登记为一份**概述性资料中的表述**。

| 可记录 | 不可推断 |
|---|---|
| 该概述页在“禁忌”小节列出对逝者亲属提名的限制。 | 色达、喇荣或全部藏区当前均有同一禁忌；这是一项学院规约或宗教戒律。 |
| 页面还将禁忌与衣物、家务、餐具、居家和出行等日常情境并列。 | 任一条目的起源、普遍性、惩罚、适用性别／身份或仪式含义。 |

后续收录须优先补充地方社区自述、民族志或具地区信息的材料；涉及逝者称呼时也应尊重当事人和家属的表达，不把习俗清单变成猎奇叙事。

来源：[西藏自治区外事办公室｜藏族民俗概述](https://wsb.xizang.gov.cn/xzjx/mzfq/201107/t20110713_100925.html)（页面日期2024-01-16，禁忌小节第6项）。

## 待核

- 不同地区、家庭、时代与宗教传统中的称名、避讳和悼念表达。
- 口述叙事的讲述者、场景与版本；不以转述替代当事人说明。
- 与学院来访礼仪、僧团规约或法会仪轨的关系；必须有独立且带日期的资料。
