# 01_地域群体与时代差异

按地区、群体、时代与来源区分习俗；藏族生活、宗教教义与学院规定分开，不把个案概括为全体藏族。

正文须附地区、时期、出处、证据性质及未知项。

## R078 地区差异示例：藏历新年

西藏自治区外事办公室公开介绍以拉萨地区为主线，记录藏历十二月开始准备卡赛、切玛、古突和吉祥水等年俗，并另列后藏、安多、工布、草地、嘉绒、白马和冕宁等地区在祭神对象、迎新日期或节庆形式上的差异。该页面是地方政府面向公众的民俗概述，适合做“地区差异”索引，不等于所有藏族社区的统一传统，也不直接说明喇荣学院的法会或生活制度。

记录时应把四个维度分开：**节日名称／日期、家庭活动、社区或寺院活动、叙事解释**。例如工布年十月初一的起源故事属于地方传说层，不能和日期事实混写；拉萨年俗中的祭神、煨桑与经幡也应另查其宗教语境和当代变化。

来源：[西藏自治区外事办公室：藏历新年](https://wsb.xizang.gov.cn/xzjx/mzfq/201107/t20110713_100934.html)（页面显示日期 2024-01-16；访问日期 2026-09-14）。
