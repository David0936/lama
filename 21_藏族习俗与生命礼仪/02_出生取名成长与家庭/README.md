# 02_出生取名成长与家庭

出生、取名、成长、亲属与家庭生活的相关记录；称谓关联12术语目录。

正文须附地区、时期、出处、证据性质及未知项。

## R133｜命名材料必须带地区

公开资料中，取名可由宗教人士、长者或家庭愿望等不同因素参与；但这不是一套跨藏区、跨时代的统一规则。中国人大网转载的一篇命名概述列举了出生日期、星期、祝愿词和请宗教人士或长者命名等叙述。四川若尔盖县政府的地方民俗页则特别记录本县宗教界“徒从师名”、部分在俗者使用骨系、父名、房名或寨名等情形。

| 资料范围 | 可登记的命名线索 | 不应外推 |
|---|---|---|
| 2009年转载的概述性材料 | 出生日期／星期、祝愿词、宗教人士或长者参与命名，均作为所述类型。 | 所有藏族人均无姓、所有儿童均由活佛命名，或这些做法仍普遍有效。 |
| 若尔盖县地方民俗页 | 该县宗教界的师名、在俗者的骨系／父名／房名／寨名等区分线索。 | 色达、喇荣或其他地区的命名制度；单个名字的家庭、戒师或身份。 |

对学院相关人物，俗名、法名、师名、尊称、行政职务和出版署名必须分栏登记，不能仅凭名称结构推断其受戒、师承或身份。本页不把地方民俗材料写成喇荣学院的命名规约。

来源：[中国人大网转载：藏族的名字](https://www.npc.gov.cn/WZWSREL3pncmR3L25wYy96dC9xdC94emRidGNmb3ovMjAwOS0wMy8xOC9jb250ZW50XzE3MjE1NjEuaHRt) · [若尔盖县政府：藏族风俗习惯](https://www.ruoergai.gov.cn/regxrmzf/c100135/202105/891934a1108f41d8bdbebb46f5596ab6.shtml)。

## 待核

- 色达、喇荣及周边社区的具日期命名、法名或称呼材料。
- 儿童、在家者、出家者与不同性别／代际称呼的实际使用语境。
- 藏文拼写、Wylie和当地发音；汉字译写不能代替原名。
