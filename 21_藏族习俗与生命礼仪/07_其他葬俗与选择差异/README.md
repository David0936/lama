# 07_其他葬俗与选择差异

火葬、水葬、土葬、塔葬等作为待核研究入口，逐项确认语境；不预设每种方式在所有地区或时期均适用。

正文须附地区、时期、出处、证据性质及未知项。

公开研究将火葬、水葬、土葬、塔葬等作为不同地区和家庭可能采用的葬俗类型；它们的适用条件、仪式参与者和宗教解释不能由天葬材料直接推导。本目录暂只登记比较维度，待逐项找到地方研究或社区自述后再写具体流程。

## R072 地区比较研究入口

Erberto Lo Bue 2009 年会议论文记录其在拉达克（2002—2003）、拉胡尔／斯皮提／库努瓦尔（2003）和中国藏区中部（2004）的田野资料，并以这些材料比较印度、尼泊尔和中国藏区的葬俗变化。该记录可支持“地区、时期、田野项目”三维索引，不能单凭摘要重建火葬、水葬、土葬或天葬流程。
