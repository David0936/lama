## R179：周边实践与学院生活的证据分层

“喇荣周边的藏族习俗”不能由一张照片、一个旅游称呼或学院课程简介直接填满。现有公开材料适合按主体和时期分层：

| 证据层 | 可登记内容 | 不能直接推出 |
|---|---|---|
| 区域与社区 | 色达县页面对洛若镇、喇荣沟及山谷建筑群的区域描述 | 社区家庭的婚丧、饮食、禁忌或当代人口结构 |
| 学院生活研究 | 2017—2019 年研究对堪姆项目作息、返乡和学习关系的观察 | 研究时期之外的周边民俗、今日全院生活或统一习俗 |
| 历史／媒体叙述 | 2012 年选文对经堂、居住区、坛城和转经空间的描述 | 当前建筑、社区活动、法会安排或开放路线 |
| 习俗专题 | 天葬、命名、节庆、服饰等各自的地区和时期材料 | “藏族”作为单一、跨地区且不变的生活方式 |

后续每条材料至少写明：地区、群体、时期、记录者或机构、证据类型、是否直接观察、学院关联状态和未知项。只有来源明确提到喇荣或周边具体实践时，才建立 `institution_links`；区域相近不等于由学院组织，也不等于所有居民共享同一传统。

本页不提供参访者应执行的习俗步骤，不把研究论文、馆藏照片或政府概述改写成现行社区规约。有关学院内部作息和公共服务，分别回到[组织治理与日常运转](../../15_组织治理与日常运转/README.md)；有关仪轨，回到[修持与仪轨](../../09_修持与仪轨/README.md)。
