## R355｜习俗与生命礼仪的最小记录单元

每条材料至少拆成五个字段：

1. **地区**：村落、县域、文化区或跨地区研究范围。
2. **时期**：历史年代、田野年份、出版年份或当代观察日期。
3. **主体**：家庭、社区、寺院、学院、博物馆、研究者或政府机构。
4. **证据类型**：社区自述、馆藏目录、历史影像、民族志、教义文本、媒体报道或网络转载。
5. **学院关联**：直接提到学院、周边地区线索、无关联或待核。

天葬、火葬、水葬、唐卡、服饰、节庆和供献不能因为都被称为“藏族习俗”就合并成统一传统；也不能从地区相近推断由学院组织。

## R372｜敏感习俗与人体材料线索的证据阶梯

天葬、遗骨、人体材料法器、所谓“人皮唐卡”等内容先作为待核线索处理。记录时分开：馆方或研究者的正式题名、材料检测或技术报告、历史文字记载、口述或新闻转述、图像标题和编辑推测。只有在来源明确说明材料与语境时，才使用确定性材料名称；仅凭外观、标题或网络转载不得下结论。

正文优先解释地区、时期、功能、持有者和证据等级，避免展示猎奇细节或把个案写成普遍习俗。若涉及受限图像、遗骸或仪轨，仅保留书目、馆藏号、访问条件和核查状态，不复制未经授权的文件。
