# 21_藏族习俗与生命礼仪

状态：v0.7。第01、03、05—08项已有小批次公开来源入口；其余仍待专题检索，不代表对任何具体实物或习俗普遍性的确认。

- [01_地域群体与时代差异](01_地域群体与时代差异/README.md)：按地区、群体、时代与来源区分习俗；藏族生活、宗教教义与学院规定分开，不把个案概括为全体藏族。
- [02_出生取名成长与家庭](02_出生取名成长与家庭/README.md)：出生、取名、成长、亲属与家庭生活的相关记录；称谓关联12术语目录。
- [03_婚姻待客饮食与服饰](03_婚姻待客饮食与服饰/README.md)：服饰馆藏对象与后续婚礼、待客、饮食研究入口；对象资料不替代地方生活史。
- [04_节庆历法与社区活动](04_节庆历法与社区活动/README.md)：民间节庆、藏历与社区活动；宗教法会主档留在10目录，建立关联。
- [05_临终丧葬与纪念](05_临终丧葬与纪念/README.md)：研究生命观、临终照护、悼念与纪念活动，区分教义、仪轨和地方实践；已有葬俗分类与遗物语境的研究入口。
- [06_天葬](06_天葬/README.md)：明确收录：名称、观念、参与角色、历史与地方差异、公开记录及当代变化；资料不足时不编造统一流程。
- [07_其他葬俗与选择差异](07_其他葬俗与选择差异/README.md)：火葬、水葬、土葬、塔葬等作为待核研究入口，逐项确认语境；不预设每种方式在所有地区或时期均适用。
- [08_朝圣转经供献与日常实践](08_朝圣转经供献与日常实践/README.md)：日常宗教活动与民间习俗的关联；具体法物与仪轨分别链接08和09目录。
- [09_禁忌象征与口述传统](09_禁忌象征与口述传统/README.md)：记录谁在何处如何解释；口述与历史事实分栏，保留异说。
- [10_学院周边实践与社会变化](10_学院周边实践与社会变化/README.md)：仅在有证据时讨论本院或周边的具体关系；不因地理相近推定某习俗由学院组织。
