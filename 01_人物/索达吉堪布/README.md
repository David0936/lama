## 人物定位

索达吉堪布（Khenpo Sodargye）是与色达喇荣五明佛学院、宁玛传统和藏汉佛教文本传播密切相关的当代佛教教师、译者与作者。官方传记称其 1985 年进入喇荣深造，1987 年开始承担藏汉译经与汉语教学；公开讲座和课程页面显示，他长期把经论学习、心性训练、翻译、大学讲学和线上多语传播连接起来。

这一定义支持的是“公开资料中的人物角色组合”，不等同于对其宗教资格或当前机构职务的独立认证。

## 女娲提炼出的核心镜片

1. **闻思修的连续链**：听闻、理解、反复思考，最后落实为修持和行为；不能用知识量替代内在转化。
2. **忠于原义，同时让人读懂**：翻译和教学既不能僵硬复古，也不能为了迎合现代话语而牺牲经典核心。
3. **传统核心与现代入口分层**：科学、教育、心理、环境和大学讲座是沟通入口，不是用现代流行概念替换传承本身。
4. **先调心，再行动**：把压力、幸福、关系和社会问题先还原为心与行为的训练问题，再讨论外部行动。
5. **从经典到公共教育的扩展**：以注释、翻译、讲座、线上课程和同步翻译，把学院型经论转成跨语言、跨场景的学习路径。

## 公开求学与工作路径

官方传记记录的个人路径为：师范教育 → 受戒 → 道明寺学习 → 1985 年进入喇荣 → 取得堪布学位 → 译经、讲学和跨文化传播。它是索达吉个人的公开传记叙述，不是喇荣现行招生制度，也不能推出所有修学者都必须走同一条路。
