# 法王如意宝（晋美彭措）

状态：`researching`。本页先收录公开来源能够直接支持的基础事实；宗教称谓、传记叙述和历史事件继续分开核查。

## 名称与身份

公开英文资料常写作 **Jigme Phuntsok Rinpoche**、**Khenchen Jigme Phuntsok** 或 **Khenpo Jigphun**。Lotsawa House 将其列为宁玛传统的教师与伏藏师，并将生卒年记为 1933–2004；名称、尊称与藏文写法需要在藏文目录或本人作品题记中继续核对，不能只用英文异写反推唯一藏文形式。

## 目前可确认的基础事实

喇荣五明佛学院官网英文介绍称，学院于 1980 年由法王如意宝创建，地点在四川省甘孜州色达县喇荣沟；同一介绍将其描述为兼具修学、教育和居住功能的佛教学院。学院官网的相关讲座又将其置于宁玛与大圆满传统的语境中。

这些是来源中的机构与传统描述，不等于本页已经完成学院历年组织、课程或现行制度的核验。
