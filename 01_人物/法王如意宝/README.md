# 法王如意宝（晋美彭措，1933–2004）

## 一句话介绍

晋美彭措（藏文：མཁན་ཆེན་འཇིགས་མེད་ཕུན་ཚོགས།；Wylie：*mkhan chen 'jigs med phun tshogs*）是20世纪宁玛传统的教师和伏藏师；公开机构资料称他于1980年创办色达喇荣五明佛学院。其作品、学院教育实践及后续传播共同构成此条目的研究对象。[S000001](../../90_资料目录/sources.jsonl) [S000002](../../90_资料目录/sources.jsonl)

本页把三类材料严格分开：可独立核验的文献与机构事实、学术研究的解释、以及传承内部的称谓和认定。后者应按其所属传统理解，不作为可由外部史料单独证明的结论。

## 教言与作品：先从版本可追溯处阅读

### 《心要·心语》（*The Heart Essence: My Heart’s Advice*）

这是目前最适合公开阅读、且可追到藏文集成版本的作品入口。译页说明该作以23偈归纳从依止善知识、戒律、闻思，到发菩提心及大圆满相关修持的路径，并在页末给出2002年三卷本《文集》的书目信息和 BDRC 记录。[S000046](../../90_资料目录/sources.jsonl)

就人物思想研究而言，作品中至少反复呈现以下可验证的主题：

1. **闻思与修持不可割裂**：文本既劝学广博教法，也反对只会复述而未入心的“鹦鹉式”博学。
2. **戒律与日常自省是基础**：文本将戒律、正念和警觉置于修行前提，而非仅作为制度装饰。
3. **利他发心优先于自我求乐**：文本明确把众生之苦与自利欲、善乐与愿他人得乐相联。
4. **教法次第与大圆满顶点并陈**：这是一份宗教文本中的自我表述，不能被简化成一套脱离传统语境的普适人生方法。

## 教育实践与喇荣

学院官网称喇荣五明佛学院由其于1980年创立，含修学与居住功能，学习者包括藏族、汉族的僧尼及在家持戒者。[S000001](../../90_资料目录/sources.jsonl) 这支持“创办人与地点”的基础判断，但不足以说明任何时期的完整组织架构或当下制度。

关于女性高阶佛学教育，梁珏与 Andrew S. Taylor 的同行评议研究将喇荣堪姆项目视为系统授予女性高阶佛学学位的重要案例，认为其制度设计挑战了女性不适于高阶学习的成见。文章还记录课程考试、论文与戒律考察等制度线索；这些是研究者基于访谈和材料的分析，应与学院一手制度文件区分。[S000047](../../90_资料目录/sources.jsonl)
