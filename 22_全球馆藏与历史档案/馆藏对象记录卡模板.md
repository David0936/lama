# 馆藏对象记录卡模板

| 字段 | 要求 |
|---|---|
| 机构与馆藏号 | 使用馆方目录中的唯一编号和官方链接 |
| 馆方题名 | 保留原文、译名与旧题名 |
| 类型与材料 | 依馆方字段填写；缺失写“未说明” |
| 年代与地区 | 记录馆方定年、依据和不确定范围 |
| 制作/使用语境 | 区分馆方说明、题记、学术研究和推测 |
| 来源流转 | 收藏、购藏、捐赠、发掘或来源不明；不由所在地推断 |
| 数字资源 | 图像、扫描、3D、展览页和下载许可 |
| 争议与修订 | 旧目录、不同定年、归属争议或返还讨论 |
| 核查日期 | 记录页面访问和目录版本日期 |

馆方展签是机构解释，不能自动替代材料检测、历史题记或学术共识；跨馆对象只有在馆藏号、来源或目录明确关联时才合并。
