# 22_全球馆藏与历史档案

状态：v0.8。已建立对象级馆藏字段和来源分层；具体史实、馆藏与来源仍需逐件核实。当前基于网上公开资料建设。

- [01_欧美博物馆与美术馆](01_欧美博物馆与美术馆/README.md)：以欧洲、北美馆藏为优先研究范围，按机构建立公开目录入口，核查机构名称、馆藏号和数字资源状态。
- [02_其他地区与中国馆藏](02_其他地区与中国馆藏/README.md)：扩展中国及其他地区博物馆、美术馆、寺院公开收藏；避免将欧美收藏当成全部历史文物。
- [03_图书馆与手稿文献](03_图书馆与手稿文献/README.md)：古籍、经卷、手稿、刻本与题记；文献主档及版本保留在04目录。
- [04_档案书信游记与旧照片](04_档案书信游记与旧照片/README.md)：档案馆、旅行记录、书信、地图和影像；注明作者、形成时点、观察范围及档案编号。
- [05_展览图录与策展记载](05_展览图录与策展记载/README.md)：展览目录、展签、专题文章、讲座与研究出版物；展签是机构解释，不自动等于学界共识。
- [06_文物来源流转与收藏史](06_文物来源流转与收藏史/README.md)：制作、使用、转手、捐赠、购藏、发掘和历史流转，按已知事实与空白分别记录，不由所在地推断取得方式。
- [07_年代题记材料与鉴定](07_年代题记材料与鉴定/README.md)：比较馆方定年、文字题记、材料报告与不同归属意见，保留旧说和修订记录。
- [08_文物流失争议与返还记录](08_文物流失争议与返还记录/README.md)：有出处的流失、取得争议与返还事件，明确提出者、证据和处理状态。
- [09_跨馆对象与数字资源索引](09_跨馆对象与数字资源索引/README.md)：同一对象的别号、借展、旧藏、图片及3D资源关联；不因外形相似合并文物。

## R356｜馆藏对象的最小核验字段

每件对象先建立唯一卡片，再讨论历史意义：

| 字段 | 核验要求 |
|---|---|
| 馆藏号与官方链接 | 以馆方目录为准，保留访问日期和页面版本 |
| 馆方题名、类型、材质 | 区分原题、译名、旧题名和未说明字段 |
| 年代与地区 | 保留馆方范围、题记、检测或学术研究依据 |
| 来源流转 | 区分购藏、捐赠、发掘、旧藏和来源不明，不从所在地推断取得方式 |
| 展陈与数字资源 | 区分当前展出、借展、历史展览、图像许可和 3D／扫描状态 |
| 争议与修订 | 并列旧目录、归属争议、材料争议和返还讨论 |

馆方展签可证明馆方如何编目和解释，但不能自动替代材料检测、历史题记或学术共识；跨馆对象只有在馆藏号、来源或目录明确关联时才合并。
