# 09_跨馆对象与数字资源索引

同一对象的别号、借展、旧藏、图片及3D资源关联；不因外形相似合并文物。

## R154 三种关联层级

跨馆检索先把“对象”“数字资源”和“主题”分成三层。只有第一层能在机构记录中明确指向同一实体时，才允许使用“同一对象”关系。

| 关联层级 | 最低证据 | 可以写什么 | 不能写什么 |
|---|---|---|---|
| 同一对象 | 同一机构馆藏号，或馆方明确说明旧号、借展号与现号的对应关系 | 同一件文物的别号、当前馆藏和旧目录入口 | 不能因题名相同、造型相似或同一作者标签合并不同馆藏 |
| 同一数字资源 | 资源链接、IIIF manifest、下载或3D入口明确回指同一馆藏号 | 对象页、图像、IIIF和展览页的资源关联 | 可见缩略图或搜索结果不能单独证明是同一对象图像 |
| 同一主题 | 机构题名、策展文章或图像学字段共享尊格、仪式或材料词 | 把莲花生、Hevajra、观音等作为跨馆检索主题 | 主题相同不代表年代、制作地、传承、仪轨用途或来源流转相同 |

### 已登记对象的示例

- **S2014.18a-b**：Smithsonian对象页同时给出馆藏号、IIIF入口和展签；可把这些资源挂在同一对象下，但图像使用条件仍按馆方条款处理。
- **L.2020.3**：The Met的 *Hevajra and Nairātmyā* 是另一件有独立馆藏号的藏地雕塑；它可以与S2014.18a-b共享“金刚乘艺术”主题，不能合并为同一件莲花生像或同一来源链。
- **1943.53.61**：Harvard的唐代观音是汉地对象；馆方Gallery Text提供跨区域传播背景，只能形成比较主题关系，不能改写成藏传对象或西藏出土地。

本页只登记关系规则和公开入口，不做图像反向识别，不从相似构图推断作者、传承或寺院来源。后续新增关系时必须写明馆藏号、关系类型、来源定位和审校状态。
