## R105 英国图书馆数字手稿入口

### 敦煌莫高窟藏文手稿数字化项目

国际敦煌项目（英国图书馆）介绍，馆藏有300余件来自莫高窟藏经洞（第17窟）的藏文手稿，1906—1908年斯坦因第二次中亚考察期间取得。项目页说明材料多与佛教有关，形态包括残片、卷轴局部、折叠册与贝叶式装帧；2023年起的项目同时进行数字化、保存处理和目录增强。

这是一条**馆藏与数字化项目**记录：它支持手稿数量级、来源地点、取得叙述、形制和项目状态的查询，不支持把某一件手稿当作藏文大藏经定本，也不以数字化图片替代文字校勘、题记释读或版权／使用条件判断。

来源：[International Dunhuang Programme｜Tibetan Manuscripts Digitisation Project](https://idp.bl.uk/about/projects/tibetan-manuscripts/)

### Gangtey寺手稿数字目录

英国图书馆濒危档案项目目录将 **EAP039/1 Gangtey Monastery Collection** 登记为藏文馆藏，记录一套100卷 *bKa’ ’gyur*、两套46卷 *rNying ma rGyud ’bum*、一部《八千颂般若经》及约百种其他题名；目录给出原件年代 **1690—1692**、485卷和135,785张 TIFF 图像等字段。它是目录级范围信息：书写体、卷数、图像数量和年代均须回到具体系列或文件级记录核验；“可数字化检索”不等于已下载、可OCR、可自由转载或与本库作品条目逐段对应。

来源：[British Library Archives Catalogue｜Gangtey Monastery Collection EAP039/1](https://searcharchives.bl.uk/?f%5Blanguage_ssim%5D%5B%5D=Tibetan&f%5Bproject_collections_ssim%5D%5B%5D=Digital+documentation+of+manuscript+collection+in+Gangtey&f%5Brelated_subjects_ssim%5D%5B%5D=Buddhist+Monasteries&f%5Burl_stub_si%5D%5B%5D=eap.bl.uk&per_page=10&sort=hierarchy)

## 登记规则

| 字段 | 先记录什么 | 不能省略的限制 |
| --- | --- | --- |
| 馆藏号／架号 | 机构原字段，如 EAP039/1 | 不用俗名替代架号 |
| 文本层级 | 藏品、系列、卷、叶或图像 | 系列说明不能替代单页内容 |
| 数字资源 | 图像、目录、下载、API 的实际状态 | 可见网页不等于全文可提取或可再发布 |
| 来源流转 | 馆方明示的取得、捐赠或考察叙述 | 不由现藏地推断所有权、伦理或返还结论 |

## 待核

- 为具体手稿补架号、题名、叶码、书写体、图像许可、目录修改日期与下载条件。
- 对涉及版本关系的作品回到[经典与文献](../../04_经典与文献/README.md)建立原文、译本、PDF页码和校验值，不能从馆藏集合反推定本。
- 来源流转争议若有，单独进入“文物来源流转与收藏史”并以机构记录、当事方陈述和研究分层。
