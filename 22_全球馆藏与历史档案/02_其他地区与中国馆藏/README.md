# 02_其他地区与中国馆藏

扩展中国及其他地区博物馆、美术馆、寺院公开收藏；避免将欧美收藏当成全部历史文物。

## R071 哈佛馆方对象卡：唐代观音（比较入口）

哈佛艺术博物馆对象 **1943.53.61** 的馆方记录题名为 *Standing Bodhisattva Avalokiteshvara (Guanyin Pusa)*，定年为中国唐代早期 8 世纪，材质为鎏金青铜，馆藏号和展厅位置均公开。馆方 Gallery Text 说明丝绸之路贸易者、来自南亚与中亚的佛教传播者及赴印度朝圣者，把绘画、经文和小型铜像带入中国与西藏；这段文字适合作为跨区域艺术史背景，不等于该件作品曾到过西藏或代表藏传图像。

对象页还提供 IIIF、下载和馆方 API 刷新日期；图片复用、借展和研究引用必须遵守对象页权限字段。

来源：[Harvard Art Museums 1943.53.61](https://harvardartmuseums.org/collections/object/204071)。

## R216 中国国家博物馆对象卡：铜金刚铃、金刚杵

中国国家博物馆馆方对象页将这套器物题名为“铜金刚铃、金刚杵”，归入藏传佛教法器，并描述金刚铃、金刚杵的造型、纹饰和铜质。馆方定年为明宣德时期（1426—1435），并称其为宣德时期官造藏传佛教法器；对象页还叙述其曾由明廷布施给拉萨寺院，后在乾隆皇帝六十岁生日时由达赖喇嘛作为礼物送入清宫。

中国国家博物馆研究文章《汉藏友好的见证》补充了对象尺寸和一条不同叙述粒度的流转说明：铜铃通高 19.5 厘米、口径 9.5 厘米，铜杵通高 12.7 厘米；文章把乾隆四十五年（1780）六世班禅进献礼物的场景与“达赖喇嘛委托转送”联系起来。这里保留“馆方叙述”标签，不把两页文字扩写成已独立核验的完整来源链，也不将该对象卡写成喇荣学院法物或现行仪式证据。

对象级记录：馆方题名、年代、材质、尺寸和馆方叙述的历史流转分别登记；图片、复制和再发布遵守中国国家博物馆页面的版权与使用条件。后续如能取得正式馆藏号、展签图像、修复或来源档案，再单独补充，不以网页缺失字段推断。

来源：[中国国家博物馆对象页](https://www.chnmuseum.cn/zp/zpml/csp/202008/t20200826_247445.shtml) · [《汉藏友好的见证》](https://www.chnmuseum.cn/yj/xscg/xslw/201812/t20181224_33247.shtml)

## R224 故宫对象卡：铜鎏金金刚萨埵坐像

故宫博物院数字藏品页将对象登记为“铜鎏金金刚萨埵坐像”，文物号 **新00115317**，定年明永乐，通高 26.5 厘米，来源字段为清宫旧藏。馆方描述造像左手持金刚铃、右手持五股金刚杵，并记录莲座正面“大明永乐年施”阴刻款。

页面还给出金刚萨埵、金刚铃、金刚杵和“五佛五智”的公共图像学解释。这里将它们作为馆方说明层登记，不把“金刚萨埵是各派本尊”“铃杵象征”或修持功效扩写成喇荣学院现行仪轨、传承认定或实践指令。对象卡支持宫廷造像、法物形制和馆方术语的交叉索引；不能单独证明制作工坊、原始寺院供奉或完整来源链。

来源：[故宫博物院：铜鎏金金刚萨埵坐像](https://www.dpm.org.cn/collection/religion/232917.html)

## R219 中国国家博物馆对象卡：绿地粉彩番莲纹喇嘛塔

中国国家博物馆对象页题名为“绿地粉彩番莲纹喇嘛塔”，说明其为佛教用器，形制仿藏传佛教喇嘛式塔：塔顶宝瓶、华盖、十三层塔刹，塔肚为覆钵式并设佛龛，塔基为方形束腰座。页面还记录绿地粉彩、番莲纹、兽首、璎珞纹、矾红彩和松石绿釉等装饰字段。

馆方将其放在清乾隆时期佛教用器与景德镇御窑烧制瓷质喇嘛塔的背景中，并以乾隆粉彩艺术风格作概述。该卡支持“汉地瓷器仿藏传塔式形制”的对象级例证，不等于寺院实际供奉、喇荣学院法物或某一固定仪式配置；页面未给出正式馆藏号、尺寸、窑口档案或完整来源链。

来源：[中国国家博物馆：绿地粉彩番莲纹喇嘛塔](https://www.chnmuseum.cn/zp/zpml/201812/t20181218_23920.shtml)

## R241 故宫馆藏：《维摩诘所说经》乾隆写本

故宫博物院专题页登记一部《维摩诘所说经》三卷本：后秦释鸠摩罗什译，清乾隆二十九年（1764）王际华写本。馆方描述其为经折装、藏经笺、墨笔楷书，每半开五行十五字，开本 22.1 × 11.1 厘米；末署“乾隆二十九年岁在甲申秋七月臣王际华薰诰敬书恭进”。页面还记录白描佛说法图、韦驮像和“乾隆御览之宝”等七方印记。

故宫页面的专题说明把维摩诘经放在大乘“不可思议解脱”、在家修行与三种汉译的传播背景中，并列举支谦、鸠摩罗什、玄奘三种译本及慧远、智顗、吉藏等注疏线索。这些是馆方说明层，适合连接中国宫廷写本、版本传播和收藏史；不能据此推断该写本曾在喇荣使用、属于藏传仪轨，或代表学院现行课程。

本条只记录故宫公开页面的对象信息与馆方解释。页面未在本批提供独立馆藏号、完整入藏档案、纸张检测或数字全文下载；后续若取得高清图像或目录记录，再补图像页码、题记和版本关系。

来源：[故宫博物院：《维摩诘所说经》（清乾隆二十九年王际华写本）](https://www.dpm.org.cn/ancient/special/179803.html)。
