# 02_其他地区与中国馆藏

扩展中国及其他地区博物馆、美术馆、寺院公开收藏；避免将欧美收藏当成全部历史文物。

## R071 哈佛馆方对象卡：唐代观音（比较入口）

哈佛艺术博物馆对象 **1943.53.61** 的馆方记录题名为 *Standing Bodhisattva Avalokiteshvara (Guanyin Pusa)*，定年为中国唐代早期 8 世纪，材质为鎏金青铜，馆藏号和展厅位置均公开。馆方 Gallery Text 说明丝绸之路贸易者、来自南亚与中亚的佛教传播者及赴印度朝圣者，把绘画、经文和小型铜像带入中国与西藏；这段文字适合作为跨区域艺术史背景，不等于该件作品曾到过西藏或代表藏传图像。

对象页还提供 IIIF、下载和馆方 API 刷新日期；图片复用、借展和研究引用必须遵守对象页权限字段。

来源：[Harvard Art Museums 1943.53.61](https://harvardartmuseums.org/collections/object/204071)。
