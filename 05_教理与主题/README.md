## R380｜教理主题的主张层级

主题页将内容分为四层：

| 层级 | 证据 | 记录方式 |
|---|---|---|
| 根本文本 | 具体作品、章节、页码或段落 | 逐条引用或准确转述，标明版本 |
| 传统注释 | 注疏、讲记、课程或传承说明 | 标明讲授者、传统、时间和文本关系 |
| 现代研究 | 学术论文、专著、馆方或机构研究 | 保留作者、出版信息、论证范围和争议 |
| 编辑导航 | 本库的目录、交叉链接和学习提示 | 明确是编辑归纳，不冒充经论原文 |

同一主题存在不同传统解释时并列记录，先说明来源和语境，再归纳共同点；没有原文定位的搜索摘要、百科转载或模型生成内容只进入待核清单。
