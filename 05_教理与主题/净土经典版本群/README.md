## 使用边界

- 这些条目是不同作品或译本的目录关系，不是同一文本的逐句对勘。
- 观点、仪轨、念诵和学院教学用途须另建有页码或时间码的证据记录。
- 藏文版本、梵文材料和现代讲授待后续批次补充。
