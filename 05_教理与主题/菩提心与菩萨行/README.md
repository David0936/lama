## 读法：三个层次不能混写

1. **文本层**：某个版本在哪一章、哪一页出现何种标题或段落。
2. **注释层**：译者、讲者或编辑怎样解释该段，必须标出人、版本、日期和语言。
3. **实践层**：学院课程、个人修持、念诵、仪轨或传授条件，需要带日期的机构说明或相应文本支持。

因此，本库可以说这两部作品各自提供了菩提心、菩萨行、六度与回向等主题的**阅读线索**；不能把不同文本的目录并合为唯一教义公式，也不能由作品进入课程网页推断全院的现行学习次第。
