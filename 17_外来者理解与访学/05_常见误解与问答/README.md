# 05_常见误解与问答

例如能否直接来出家、学习多久成堪布、仁波切是否更高一级；以对应主题的证据回答。

## 后续交付

以来源支持的概述、具体案例或资料卡回答本专题；每条说明适用机构、时期、群体及核查状态。事实未查到时登记缺口，不生成默认答案。

## R064 误解澄清：非景区 ≠ 永久开放或永久关闭

公开材料只能支持这样的回答：学院的宗教／教育性质与旅游景点标签不同；访问、听课、朝圣和临时防疫措施需要分别查当期公告。2021 年的两份公告存在不同发布时间和表述，不能据二手攻略推导 2026 年的预约、门禁或拍摄规则。

## R106 外来者最常见的五个问题

### 1. 能否直接到现场“出家”或“入学”？

**现有公开资料不能确认2026年的通用申请流程。** 学院公开介绍可支持僧尼、在家持戒者及不同语言背景学习者并存；2021年材料只说明当时的访问语境。它们均不提供今天的入学、剃度、受戒、常住、旁听或审批步骤。应按[公告核查顺序](../03_如何查找现行公告/README.md)寻找带日期的一手信息，未找到前不把个人经历或旧通告当作申请指南。

### 2. 是不是从普通学习者一步步“升”为堪布？

**不是可公开确认的统一晋升阶梯。** 公开讲座将堪布／堪姆放在教学与考核语境中，提供口试、笔试和背诵考试的线索；但现有资料没有给出今天统一的年限、课程、考试大纲或自动授予规则。受戒身份、学习资格、教学称号和行政职务应分开看，详见[堪布堪姆与教学资格](../../13_入门出家与身份路径/05_堪布堪姆与教学资格/README.md)。

### 3. 仁波切／活佛是堪布之后的更高“级别”吗？

**不能这样排序。** 本库把仁波切、活佛、祖古等放在尊称、传承身份和转世认定的不同语境中；堪布／堪姆则另按教学资格记录。一个人的称谓不能反推其考试、受戒、行政任职或学习时间，详见[仁波切活佛与转世认定](../../13_入门出家与身份路径/06_仁波切活佛与转世认定/README.md)。

### 4. 公开线上课程等于线下入学或常住资格吗？

**不等于。** 2019年公开英语线上课程可证明曾有面向公开学习者的《入菩萨行论》课程；它不提供实体学院招生、住宿、学籍或资格授予。课程入口与长期学习、出家、常住分别需要不同证据，详见[《入菩萨行论》](../../04_经典与文献/入菩萨行论/README.md)。

### 5. “不是旅游景点”是否等于永久不能到访？

**不能从旧公告得出永久结论。** 2021年材料所说的宗教／教育性质、疫情措施和访问限制有明确时间背景。到访、朝圣、听课与求学是不同问题，当前状态必须由当期官方公告确认；本库不提供预约、门禁或拍摄建议。

## 阅读顺序

1. 先判断问题属于访问、学习、受戒、教学资格、转世认定还是行政角色。
2. 再查带日期的机构公告、课程页、版本说明或可定位传记。
3. 将个人个案、教育性背景和现行制度分栏；任何一栏缺证，都写“公开资料未核实”。
