## R169：外来者证据阅读路线

| 阅读顺序 | 先看什么 | 形成的认识 | 仍需单独核查 |
| --- | --- | --- | --- |
| 1. 机构 | 官网介绍与学院主档 | 学院作为宗教教育社区的公开定位 | 当前人数、组织图、现行制度 |
| 2. 学习 | 五明／课程矩阵、语言入口、作品版本 | 课程框架、研究时期案例和公开线上入口 | 当前课程表、招生、资格和教材定本 |
| 3. 空间 | 区域点位、建筑候选、地图图层状态 | 公开地点与历史／二手建筑线索 | 边界、坐标、室内平面、开放范围 |
| 4. 生活 | 作息、参与者角色、生活服务 | 特定研究时期的运转案例与公开缺口 | 宿舍、饮食、供水、财务和志愿者规则 |
| 5. 访问与身份 | 公告核查、入门路径、称谓维度 | 参访、学习、受戒、常住、教学资格和转世认定是不同问题 | 当期访问公告和个人身份确认 |

这条路线是资料导航，不是到访路线、出家申请流程或修持指导。任何“现在能否进入”“如何入学／出家”“怎样成为堪布或仁波切”的问题，都必须回到带日期的机构来源；找不到就保留“公开资料未核实”。

## R351｜外来者入口分流矩阵

| 入口 | 资料可回答 | 不能自动推出 |
|---|---|---|
| 普通参访／朝圣 | 公开地点、历史介绍、礼仪和地图线索 | 当前开放时间、内部区域权限、现场接待承诺 |
| 短期听课／线上学习 | 公开课程页面、语言和媒体入口 | 实体学籍、常住资格、传法或考试资格 |
| 长期求学 | 历史研究项目的学习对象、课程和作息案例 | 现行录取条件、学制、宿舍和毕业规则 |
| 皈依／受戒／出家 | 传统身份概念与已公开个案 | 学院当前准入、剃度安排或保证收留 |
| 常住／任教 | 特定来源所述角色与职责 | 完成学习即自动任教、取得堪布或仁波切称号 |

本矩阵只帮助读者提出正确问题。每个入口都要另查主体、日期、对象范围和发布渠道；个人经历、旅行文章和历史论文不能互相替代。

## R395｜外来者来源判断四级

| 来源 | 能证明 | 不能证明 |
|---|---|---|
| 学院或管理机构的带日期公告 | 特定时间、地点、对象和事项的安排 | 没有写出的长期规则或其他区域安排 |
| 馆方目录、图书馆或公开教材 | 对象、版本、语言、页码和公开访问状态 | 学院采用、传承资格或现场允许 |
| 学术论文、田野记录和出版物 | 作者在特定时期的观察、论证和引用链 | 当前制度、全院普遍性或个人身份判定 |
| 转载、旅行文章、社交媒体和个人经验 | 线索、体验或传播方式 | 官方许可、当前开放状态、统一流程 |

外来者提问时先记录“我看到的来源属于哪一级”，再检查日期、主体、对象范围和是否有原文链接。来源等级高不等于内容覆盖范围广；一份公告也不能替代课程、受戒、常住、建筑或法会的专门证据。
