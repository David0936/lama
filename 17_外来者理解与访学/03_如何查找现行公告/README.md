# 03_如何查找现行公告

登记招生、出家、常住、访问与活动公告的发布主体及日期；没有最新依据就写现状未核实。

## 后续交付

以来源支持的概述、具体案例或资料卡回答本专题；每条说明适用机构、时期、群体及核查状态。事实未查到时登记缺口，不生成默认答案。

## R064 公告核查顺序

先看学院／喇荣寺管理机构、色达县政府或民族宗教部门的原文与发布日期，再看媒体或组织翻译。2021 年通告的例子显示，“不是旅游景点”“疫情期间不开放”“宗教活动暂停”是不同命题；记录时须分别标注发布主体、时间范围和措施，不能用旧公告回答当前能否进沟。
