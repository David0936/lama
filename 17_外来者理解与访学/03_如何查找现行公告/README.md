# 03_如何查找现行公告

登记招生、出家、常住、访问与活动公告的发布主体及日期；没有最新依据就写现状未核实。

## 后续交付

以来源支持的概述、具体案例或资料卡回答本专题；每条说明适用机构、时期、群体及核查状态。事实未查到时登记缺口，不生成默认答案。

## R064 公告核查顺序

先看学院／喇荣寺管理机构、色达县政府或民族宗教部门的原文与发布日期，再看媒体或组织翻译。2021 年通告的例子显示，“不是旅游景点”“疫情期间不开放”“宗教活动暂停”是不同命题；记录时须分别标注发布主体、时间范围和措施，不能用旧公告回答当前能否进沟。

## R393｜公告记录卡

每条公告保存：标题原文、发布主体、发布日期、适用地点、对象范围、事项类型（访问／听课／招生／出家／常住／法会）、生效时间、失效或复查日期、原文链接、转载关系、核查日期和当前状态。只看到转载或截图时，状态保持“二手线索”，不当作机构正式公告。

“当前有效”需要明确的生效范围和未失效证据；没有失效日期的旧公告仍只能说明发布时点。公告之间冲突时并列记录版本和适用范围，不能用较新的发布日期自动覆盖不同主体的规定。
