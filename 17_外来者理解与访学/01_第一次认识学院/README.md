# 01_第一次认识学院

学院是什么、谁在这里、学什么、怎样生活，以及学院、寺院与聚落怎样区分。

## 后续交付

以来源支持的概述、具体案例或资料卡回答本专题；每条说明适用机构、时期、群体及核查状态。事实未查到时登记缺口，不生成默认答案。

## R147 认识学院的四层入口

第一次查阅时，先把不同尺度和证据类型分开：

| 层级 | 当前公开资料能支持的认识 | 不能直接推出 |
|---|---|---|
| 机构 | 官网介绍称喇荣五明佛学院 1980 年由法王如意宝创建；学习社区包括僧尼、在家持戒者以及藏族和汉族学习者 | 2026 年在册人数、招生名额、统一学籍或内部管理图 |
| 区域 | KMaps 将 Larung Gar 作为宗教聚落地点要素；色达县公开介绍把喇荣置于洛若镇、喇荣沟及山谷建筑群语境 | 学院边界、当前建筑数量、入口路线或每座建筑的现行功能 |
| 学习 | 官网课程概览把经乘、密乘和若干世间课程并列为课程描述 | 具体班级、学制、考试、修持资格或所有学习者的共同路径 |
| 数字项目 | WCDU 页面把线上项目描述为面向英语学习者的虚拟大学，按周直播并配合讨论和引导式禅修 | 线上参加等于实体入学、常住、出家或取得教学资格 |

因此，“学院是什么”应先回答机构性质和公开课程语境；“我能否到访、学习或出家”则必须另查带日期的一手公告和具体制度来源。本页只提供理解路径，不替代现行访问或招生信息。
