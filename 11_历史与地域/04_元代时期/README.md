## 首批历史线索

元代（1271–1368）是中国历史与藏传佛教关系研究的重要时期。大都会艺术博物馆的历史概述指出，蒙古统治者在元代宫廷采用藏传佛教为官方宗教；与此同时，净土、天台、禅等既有汉传传统仍在中国本土社会保持重要位置。该表述支持将“宫廷宗教政策”与“地方佛教实践”分开书写。

史密森学会的一项教育对象说明提到忽必烈（1215–1294）与藏传佛教的关系。后续需要用中文、藏文和制度史料补充实际行政制度、人物网络与不同地区的情况，不能把单一宫廷概述推广为全部社会经验。
