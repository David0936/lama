# 08_中华人民共和国时期与当代

按有来源的事件记录机构、教育、文化保护、传播及社会变化；当前制度需带核查日期。

## 首批政策入口

国务院令第686号《宗教事务条例》于2018年2月1日起施行；本库将其作为宗教事务、宗教院校和宗教活动场所的通用法规入口。该条例本身不证明喇荣学院的法律性质、具体审批状态或某项地方执行，涉及学院的事实仍须另有有日期的公开材料。
