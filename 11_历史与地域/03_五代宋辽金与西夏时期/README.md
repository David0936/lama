# 03_五代宋辽金与西夏时期

分别梳理并存政权、区域传播和藏地宗教发展，不把并存时期排成单一替代序列。

## R157：先建立跨区域时间轴，再补各政权专题

“五代、宋、辽、金、西夏”是东亚与内亚不同区域的并存标签，不能直接当作一条从前到后的单线朝代表。当前先建立一个**非政策、非统一政治叙事**的时间轴入口，后续再分别接入藏地、河湟、敦煌、西夏、辽金和宋代的专门史料。

| 时间入口 | 馆方时间线可核信息 | 本库使用边界 |
|---|---|---|
| 约630—850 | The Met 将西藏 Yarlung dynasty 标为 630—850 | 作为藏地早期王朝时间轴入口，不替代藏文年表或区域考证 |
| 约750—797 | 馆方概述将 Khri-srong-Ide-btsan 时期与佛教赞助、藏地艺术家接触和田／敦煌绘画传统联系起来 | 是艺术史概述，不单独证明某件作品、寺院或具体译师的行程 |
| 约842—850 | 页面记录朗达玛遇刺后帝国开始碎片化、王朝瓦解与佛教衰落的概述 | 保留为馆方时间线说法；事件细节需回到藏文史料和年代学研究 |
| 约950以后 | 馆方时间线称中部西藏佛教开始复兴，并出现赴印度、尼泊尔寻求经教与传承的活动 | 只作为后续“后弘期与跨区域传播”检索入口，不推出统一复兴起点或全部地区同步 |

### 不纳入本批的内容

- 不把宋、辽、金、西夏写成单一替代关系，也不在本页处理各政权政策。
- 不用一条博物馆时间线替代西夏文、藏文、汉文、敦煌和考古材料的对读。
- 不把“佛教复兴”“艺术接触”直接改写为某个现代教派、学院或人物的连续传承。
