# 11_历史与地域

状态：v0.9。唐、元、明、清、民国与当代已有最小公开资料入口，并补充五条并行历史时间轴；具体史实、馆藏与来源仍待逐条检索核实。当前基于网上公开资料建设。

## R368｜历史年表的五轴分期

本目录不把“中国朝代”“藏地历史”“教派传承”“学院机构史”和“跨区域传播”压成一条单线。每条事件至少记录所属轴线、日期精度、地点、主体、事件类型、史料语言或类型、原始出处和争议状态；一条轴线的分期不能替代另一条轴线的史实。

| 轴线 | 记录对象 | 使用边界 |
| --- | --- | --- |
| 中国王朝与国家时期 | 唐、五代宋辽金西夏、元、明、清、民国及当代的制度、交通、寺院、文物与出版事件 | 记录发生时的政权称谓和日期，不把王朝标签直接当成藏地内部分期 |
| 藏地自身分期 | 前弘期、后弘期、地方政权、区域寺院网络与近现代社会变化 | 以藏地史料和研究定义为准，不强行与中国王朝一一对应 |
| 教派与译传史 | 译经阶段、教派形成、传承节点、论典与仪轨流通 | 记录文本、人物、寺院和传承关系；“教派”不自动等于行政实体 |
| 喇荣机构史 | 创建、扩展、教育组织、公共建筑和空间变化 | 只写有机构或档案来源的阶段；历史功能不直接推定为当前功能 |
| 跨区域传播 | 印度、于阗、中亚、中国、藏地及海外的译传、旅行、收藏和交流 | 记录路线、媒介和证据等级；个人活动不直接写成机构合作 |

分期页与事件页应同时保留“公开资料未核实”或“存在争议”的状态。历史分期用于组织材料，不直接推出现代行政、政策或现行学院制度结论。

- [01_多线年表与分期方法](01_多线年表与分期方法/README.md)：中国王朝纪年、藏地历史分期、教派传承史和机构史并列，以具体事件连接。
- [02_早期背景与唐代时期](02_早期背景与唐代时期/README.md)：吐蕃资助、桑耶寺与唐蕃条约的最小年表；宗教、寺院与政治事件分开核查。
- [03_五代宋辽金与西夏时期](03_五代宋辽金与西夏时期/README.md)：分别梳理并存政权、区域传播和藏地宗教发展，不把并存时期排成单一替代序列。
- [04_元代时期](04_元代时期/README.md)：研究宗教人物、帝师等制度、寺院、经典、艺术与区域关系，具体称谓和职能依来源解释。
- [05_明代时期](05_明代时期/README.md)：研究不同地区与教派的发展、往来、封授、寺院和艺术资料，区分名义称谓与实际活动。
- [06_清代时期](06_清代时期/README.md)：研究制度、人物、寺院网络、宫廷文物、典籍和跨区域联系，保留不同时期的变化。
- [07_民国时期](07_民国时期/README.md)：研究近代人物、教育、旅行档案、出版、机构变化和区域交往。
- [08_中华人民共和国时期与当代](08_中华人民共和国时期与当代/README.md)：按有来源的事件记录机构、教育、文化保护、传播及社会变化；当前制度需带核查日期。
- [09_藏地分期与教派发展](09_藏地分期与教派发展/README.md)：先后弘期等历史概念及各教派分期的待核说明，关联03目录，避免强行一一对应王朝。
- [10_制度称谓与政教关系](10_制度称谓与政教关系/README.md)：以原始称谓、时代语境和实际职能解释宗教与政治制度，不以现代术语替代所有历史含义；含[历代政府政策与学院公开记录](10_制度称谓与政教关系/历代政府政策与学院公开记录/README.md)的首批索引。
- [11_经典艺术与跨区域传播](11_经典艺术与跨区域传播/README.md)：从版本、人物、寺院、译者和实物追踪传播，关联04、08、18和22目录。
- [12_史料对读与争议问题](12_史料对读与争议问题/README.md)：藏汉及其他语言记录并列，记录作者立场、形成时间、证据与分歧，不以单一来源填满空白。
