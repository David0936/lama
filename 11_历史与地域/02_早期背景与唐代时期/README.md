# 02_早期背景与唐代时期

研究早期传播、吐蕃时期及与唐朝等同时代地区的往来，逐项核对年代、文献与叙事层次。

## R119｜吐蕃与唐代并行时期的最小年表

大都会艺术博物馆的喜马拉雅区域历史年表将吐蕃统治者对佛教的资助、约779年桑耶寺建立和822年唐蕃和平条约列为约750—822年的关键事件。该页提供的是博物馆面向公众的区域史时间线，适合把“宗教资助”“寺院建设”“政治条约”先分为不同事件类别。

| 时间线索 | 页面所列事件类型 | 本库的证据边界 |
| --- | --- | --- |
| 约750—797 | 吐蕃统治者对佛教的资助 | 区域历史背景，不能概括全部制度、社会群体或具体经典传播。 |
| 约779 | 桑耶寺建立 | 年表事件线索，仍需用题记、考古与藏汉史料核对细节。 |
| 822 | 唐蕃和平条约 | 政治史线索，不由条约直接推断每一寺院、教派或学院的关系。 |

这三项并非同一种证据：资助是宗教史概述，桑耶是寺院史节点，条约是政治史节点。它们不能拼成“唐代已经形成今天学院制度”或“现代学院直接隶属某一古代机构”的结论。

来源：[The Met｜Himalayan Region, 500–1000 A.D.](https://82nd-and-fifth.metmuseum.org/toah/ht/06/ssh.html)，见Overview与Key Events中约750—797、约779、822年条目。

## R400｜早期事件卡的分栏

早期材料按“宗教赞助、寺院／建筑、译经与文本、使节／条约、艺术与物质文化、地方社会”分栏。每张事件卡保留日期精度、地点、参与主体、原始语言或史料类型、现代研究定位和争议；同一年代的不同事件不因时间接近而合并。

博物馆年表只支持其自身的概述范围；要写具体译者、寺院沿革、条约文本或社会影响，必须另接碑刻、文书、考古报告、经录或学术研究。没有对象级证据时，状态保持“区域背景”或“待核”。

## 待核

1. 各事件的藏文、汉文及其他语言原始材料、年代精度和争议。
2. 桑耶寺的考古、建筑与宗教史资料，和后世宁玛传统叙事分别登记。
3. 唐蕃关系与具体译经、使节、寺院或地方社会之间的可证实连接。
