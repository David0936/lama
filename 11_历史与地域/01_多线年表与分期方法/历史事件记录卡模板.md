# 历史事件记录卡模板

| 字段 | 要求 |
|---|---|
| 事件名称与日期 | 标注日期精度：年、月、日或约年 |
| 地点与政权语境 | 分开中国王朝、藏地政权、寺院和地方社会层次 |
| 参与者与机构 | 保留原称谓、身份和来源用语 |
| 事件性质 | 传播、译经、建寺、教育、封授、艺术、冲突或交流 |
| 史料类型 | 碑铭、文书、编年史、传记、档案、馆藏或现代研究 |
| 原文定位 | 页码、章节、馆藏号或数字档案编号 |
| 叙事差异 | 藏文、汉文及现代研究之间的不同说法 |
| 与学院关系 | 只有来源明确时才建立机构史关系；否则留空 |
| 未解决问题 | 日期、人物消歧、因果关系和史料可靠性 |

王朝纪年、藏地分期、教派传承和喇荣学院史是并行时间线；不能用一个时间线替代另外三者。
