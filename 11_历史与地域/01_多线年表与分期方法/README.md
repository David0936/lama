## R171：多线历史入口矩阵

本页只建立检索顺序，不把王朝、藏地分期、教派史和喇荣机构史压成一条直线：

| 线索 | 已有入口 | 史料性质 | 当前边界 |
| --- | --- | --- | --- |
| 吐蕃／唐代 | 桑耶、佛教赞助、唐蕃条约 | 博物馆区域时间线 | 需藏汉史料、题记和考古对读 |
| 五代宋辽金西夏 | Yarlung、碎片化、后弘期检索入口 | 博物馆艺术史时间线 | 并存政权不能排成单线替代序列 |
| 元代 | 宫廷艺术与帝师／藏传关系入口 | 馆藏和展览叙述 | 不代表所有地区、寺院或社会群体 |
| 明代 | 官方历史概述与馆藏艺术线索 | 政府概述／馆藏对象 | 不在本批评价政策或执行效果 |
| 清代 | 多语宫廷对象、乾隆与藏传艺术语境 | 馆藏对象与教育说明 | 具体对象不能替代清代全域史 |
| 民国 | 机构、旅行档案与近代教育入口 | 官方历史概述与档案线索 | 机构名称和权限需逐档核对 |
| 当代 | 喇荣机构史、教育、空间与全球传播 | 官网、研究、地图与馆藏资料 | 现行事实必须附核查日期 |

每一条年表记录至少保留：日期精度、地点、主体、事件类型、史料语言／类型、原始来源和争议状态。艺术史时间线可以提供研究入口，但不能单独证明具体人物行程、文本译本或现代学院连续传承。
