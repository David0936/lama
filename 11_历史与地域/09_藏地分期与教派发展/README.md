## R178：分期、教派与跨区域传播的三层读法

“藏地历史分期”“教派形成”“印度—藏地往来”是相互关联但不能互相替代的三条线：

| 层次 | 公开资料可支持的入口 | 不能直接推出 |
|---|---|---|
| 时间分期 | 早期传播、帝国时期、后弘期等公共历史框架；博物馆术语页把早期传播与后弘期并列说明 | 某一现代教派在更早时期已经以今天的组织形态存在 |
| 教派／传承 | 公开教育材料将宁玛、噶举、萨迦、格鲁作为藏传佛教主要传统，并分别连接早期传播或后弘期的研究线索 | 四派是完全封闭、互不往来的宗派；共同尊格或经典自动等于同一传承 |
| 跨区域传播 | The Met 以 11—12 世纪印度教师赴藏、藏地僧人赴北印度学习、手稿翻译和艺术互动建立研究入口 | 某位现代教师、学院或单件馆藏已经被证明直接继承某一古代路线 |

因此，年表应至少保存：日期精度、地点、主体、传统／机构、事件类型、史料语言与来源层级。遇到“宁玛早期”“新译传统”“那烂陀传统”等词时，先记录来源的原始语境，再与藏文、汉文、梵文材料和具体传记对读。博物馆教育性分类适合做检索入口，不替代教派自述、谱系文本、寺院档案或学院现行课程。

本目录暂不把这一历史框架写成喇荣学院的直接建制来源；学院关联必须另有带日期的机构材料。

## 待核

- 早期传播、后弘期和各传统形成的藏文、汉文、梵文史料与年代争议。
- 各传统内部支系、共同寺院网络和跨派学习案例。
- 印度—藏地翻译、教师与文本关系的对象级证据；不能只靠展览概述补全。
