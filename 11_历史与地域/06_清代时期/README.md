## 首批历史线索

1777 年，班禅喇嘛向乾隆帝献上一组“过去佛”图像；大都会艺术博物馆保存的其中一件后续版本带有汉、满、蒙、藏四种文字的颂词。该具体对象说明清代宫廷艺术中存在多语言、藏传佛教相关的制作与呈现语境。

史密森学会收藏的“乾隆帝作文殊菩萨像”页面则以宫廷肖像和题记说明乾隆与藏传佛教语境、蒙古与藏地关系的政治及宗教层面。两项材料都只说明特定宫廷对象和馆方解释，不可替代对清代全部地区、寺院或教派关系的全面结论。
