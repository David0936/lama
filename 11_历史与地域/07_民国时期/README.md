研究近代人物、教育、旅行档案、出版、机构变化和区域交往。

## 首批历史线索

国家民委2018年“藏族历史沿革”网页称，民国历届政府在中央设有管理蒙藏事务的专门机构，并记载1929年国民政府设蒙藏委员会、1934年决定在拉萨设蒙藏委员会驻藏办事处、1939年建西康省。这里登记的是该官方概述的机构与年份线索；各机构的权限、实际运作、地方差异和同时代不同立场仍需查档案与研究文献。

来源：[国家民委：藏族历史沿革](https://www.neac.gov.cn/seac/ztzl/201806/1066630.shtml)（第30—31段）
