## 首批历史线索

国家民委2018年“藏族历史沿革”网页以政府历史概述的形式称，明朝对西北、西南涉藏地区基本承袭元代管理办法；对西藏地区施行其所称“多封众建”，并提及三大法王、五大地方之王、朝贡与回赐。该页可记录一个官方历史叙述和相关术语，不能替代明代档案、藏文史料或不同学术解释，也不能把概述中的制度名称自动对应到每一地区或寺院。

来源：[国家民委：藏族历史沿革](https://www.neac.gov.cn/seac/ztzl/201806/1066630.shtml)（第26段）
