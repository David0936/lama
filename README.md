# Lama · 藏传佛教学习百科

状态：整体框架 v0.8，持续填充中（2026-09-15）。已完成多轮公开资料检索、来源登记、主张／关系登记与独立推送；当前仍是研究资料库，不宣称各专题完成。

从门措上师、法王如意宝与色达喇荣五明佛学院相关资料起步，逐步扩展人物、经典、思想、佛菩萨与尊格、故事、法物、仪轨、法会、传承和历史。长期目标是可追溯、可阅读、可检索的百科，不以条目数量代替材料可靠性。

当前定位：基于网上公开信息建设研究资料库，正常开展检索、整理与来源审校。私有化、老师授权和加密只为未来可能上架软件或网页预留，不作为当前整理的前置条件。
